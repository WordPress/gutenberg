# Core Data UI

UI components for WordPress core data entities. This package provides the user-facing components — such as the "review changes" entities-saved-states panel — that operate on [`@wordpress/core-data`](https://github.com/WordPress/gutenberg/tree/HEAD/packages/core-data/README.md) entities.

It exists so that generic entity-save UI can be shared across editors and other surfaces without depending on the higher-level `@wordpress/editor` package.

## Installation

Install the module

```bash
npm install @wordpress/core-data-ui --save
```

_This package assumes that your code will run in an **ES2015+** environment. If you're using an environment that has limited or no support for such language features and APIs, you should include [the polyfill shipped in `@wordpress/babel-preset-default`](https://github.com/WordPress/gutenberg/tree/HEAD/packages/babel-preset-default#polyfill) in your code._

### useEntitiesSavedStatesIsDirty

Custom hook that determines if any entities are dirty (edited) and provides a way to manage selected/unselected entities.

_Returns_

-   `Object`: An object containing the following properties: - dirtyEntityRecords: An array of dirty entity records. - isDirty: A boolean indicating if there are any dirty entity records. - setUnselectedEntities: A function to set the unselected entities. - unselectedEntities: An array of unselected entities.
