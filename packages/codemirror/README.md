# `@wordpress/codemirror`

CodeMirror 6 bundle and re-exports for WordPress. Distributed as a WordPress Script Module; the named exports of `@codemirror/{autocomplete,commands,lang-css,lang-html,language,lint,search,state,view}` are flat-re-exported from this package.

## Installation

Install the module:

```bash
npm install @wordpress/codemirror --save
```
