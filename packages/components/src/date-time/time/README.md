# TimePicker Component 
 
## Description 
The `TimePicker` component allows users to select a time. 
 
## Installation 
```javascript 
import { TimePicker } from '@wordpress/components'; 
``` 
 
## Usage 
```jsx 
``` 
 
## Props 
- currentTime (string) - The initial time (HH:mm format). 
- onChange (Function) - Called when the time changes.
