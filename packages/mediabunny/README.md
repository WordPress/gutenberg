# `@wordpress/mediabunny`

WebCodecs-based media wrapper used by `@wordpress/upload-media` to convert animated GIFs to MP4/WebM during media upload.

This package is not used directly. When an animated GIF is uploaded, its frames are decoded using the browser's native `ImageDecoder` API and re-encoded with the [mediabunny](https://github.com/Vanilagy/mediabunny) library, which delegates encoding to the browser's native WebCodecs (`VideoEncoder`). All processing runs inside a Web Worker to keep the main thread responsive.

## Installation

Install the module:

```bash
npm install @wordpress/mediabunny --save
```

## Requirements

-   **WebCodecs support**: the browser must expose `ImageDecoder` and `VideoEncoder` (available in Chromium-based browsers and Safari 16.4+).
-   **Web Workers support**: the browser must support Web Workers.
