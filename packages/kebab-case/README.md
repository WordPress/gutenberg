# Kebab Case

Converts any string to kebab-case.

The conversion follows the semantics of WordPress Core's [`_wp_to_kebab_case()`](https://developer.wordpress.org/reference/functions/_wp_to_kebab_case/) function (and, transitively, Lodash's [`_.kebabCase()`](https://lodash.com/docs/4.17.15#kebabCase)), which differ from other kebab-case implementations in how numbers are handled (`'a11y'` becomes `'a-11-y'`, `'MyPlugin2'` becomes `'my-plugin-2'`). WordPress uses these semantics when generating slugs for CSS class names and preset CSS custom properties (`--wp--preset--*`), so use this package whenever a generated slug needs to match one generated by WordPress.

## Installation

Install the module

```bash
npm install @wordpress/kebab-case --save
```

## Usage

```js
import { kebabCase } from '@wordpress/kebab-case';

kebabCase( 'whiteToWhite' ); // 'white-to-white'
kebabCase( 'white2white' ); // 'white-2-white'
kebabCase( 'font2xl' ); // 'font-2-xl'
```
