# Field Optionality Guidelines

When designing forms with DataForm, it's important to clearly communicate which fields are required and which are optional. This guide explains best practices for marking field optionality to create clear, scannable forms.

## Main Rule: Mark the Minority

For mixed forms (where some fields are required and some are optional), mark the minority to reduce visual noise:

-   If **most fields are optional** → mark only the required fields
-   If **most fields are required** → mark only the optional fields

## Uniform Forms: Use Card Description

When all fields are either required or optional it can be helpful to state this somewhere above the form. This provides a cleaner, more scannable interface.
