# Tabs

## Usage

### Uncontrolled Mode

`Tabs` can be used in an uncontrolled mode, where the component manages its own state. In this mode, the `defaultValue` prop can be used to set the initially selected tab.

```jsx
import { Tabs } from '@wordpress/ui';

const MyUncontrolledTabs = () => (
	<Tabs.Root
		onValueChange={ ( tab ) => console.log( 'New selected tab: ', tab ) }
		defaultValue="tab2"
	>
		<Tabs.List>
			<Tabs.Tab value="tab1">Tab 1</Tabs.Tab>
			<Tabs.Tab value="tab2">Tab 2</Tabs.Tab>
			<Tabs.Tab value="tab3">Tab 3</Tabs.Tab>
		</Tabs.List>
		<Tabs.Panel value="tab1">
			<p>Selected tab: Tab 1</p>
		</Tabs.Panel>
		<Tabs.Panel value="tab2">
			<p>Selected tab: Tab 2</p>
		</Tabs.Panel>
		<Tabs.Panel value="tab3">
			<p>Selected tab: Tab 3</p>
		</Tabs.Panel>
	</Tabs.Root>
);
```

### Controlled Mode

Tabs can also be used in a controlled mode, where the parent component uses the `value` and `onValueChange` props to control tab selection. In this mode, the `defaultValue` prop will be ignored if it is provided. To indicate that no tabs are selected, pass `null` to the `value`.

```tsx
import { useState } from 'react';
import { Tabs } from '@wordpress/ui';

const MyControlledTabs = () => {
	const [ selectedTabId, setSelectedTabId ] = useState<
		string | undefined | null
	>( null );

	return (
		<Tabs.Root
			value={ selectedTabId }
			onValueChange={ ( newSelectedTabId ) => {
				setSelectedTabId( newSelectedTabId );
				console.log( 'Selecting tab', newSelectedTabId );
			} }
		>
			<Tabs.List>
				<Tabs.Tab value="tab1">Tab 1</Tabs.Tab>
				<Tabs.Tab value="tab2">Tab 2</Tabs.Tab>
				<Tabs.Tab value="tab3">Tab 3</Tabs.Tab>
			</Tabs.List>
			<Tabs.Panel value="tab1">
				<p>Selected tab: Tab 1</p>
			</Tabs.Panel>
			<Tabs.Panel value="tab2">
				<p>Selected tab: Tab 2</p>
			</Tabs.Panel>
			<Tabs.Panel value="tab3">
				<p>Selected tab: Tab 3</p>
			</Tabs.Panel>
		</Tabs.Root>
	);
};
```

### Using `Tabs` with links

Do not use `Tabs` for links, even when the links look like tabs. `Tabs` shows panels in place on the same page. Links that go to different URLs are navigation, and navigation needs different semantics:

-   Assistive technology announces each tab as a control for a panel, not as a link to a different URL.
-   Users expect to reach each link with the Tab key. `Tabs.List` is a [composite](https://w3c.github.io/aria/#composite) widget with a single tab stop, and users move between its tabs with the arrow keys.

When you build an admin screen with the [`Page`](?path=/docs/admin-ui-page--docs) component from `@wordpress/admin-ui`, use its `navigation` prop for tab-style links to the sections of the screen.

### Panel and sidebar tabs

When tabs sit at the top of a panel or sidebar (below a screen header and above padded content) use a **full-bleed tab list with a light bottom border**. The border should span the full width of the panel. The tab labels should stay only as wide as their text.
