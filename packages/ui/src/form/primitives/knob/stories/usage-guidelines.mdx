# Knob

Use a knob when the position of a dial helps someone choose a number, such as the direction of a gradient. Click or tap to choose a nearby step, or drag around the center to keep turning. For precise entry, a numeric field can share the same controlled value.

## Choose the range

By default, the dial spans 0 to 100 with a gap between its end stops. Use `min`, `max`, and a positive `step` to set the selectable values. The steps start at `min`. If the range does not divide evenly, the last selectable value is the last step at or below `max`. A step larger than the whole range selects between its two endpoints.

Set `wrap` when the first value follows the last. For whole degrees, use `min={ 0 }`, `max={ 359 }`, and `step={ 1 }`. Zero points up and 90 points right. Both endpoints are selectable, so each direction has one value.

## Count turns

Set `unitsPerTurn` when dial positions have a physical meaning. The dot shows the heading on a full circle. Zero points up. With `unitsPerTurn={ 360 }`, a clockwise turn adds 360 degrees and a quarter-turn adds 90 degrees. With `min={ -720 }` and `max={ 720 }`, the dial can turn twice in either direction from zero. A positional tap picks the closest heading among selectable steps within one turn of the current value in either direction. When two values point the same way, the nearer value wins. Clicking three o'clock from −300° selects −270°. Clicking the same position from 390° selects 450°.

`min` and `max` bound the total value. Add `wrap` to repeat that range indefinitely. For a seamless loop, include one step per position. With whole degrees, use 0 to 359 for one turn or 0 to 719 for two turns before the value returns to zero.

The range can end partway through a turn. With 0 to 500 and 360 units per turn, 500 points 140° clockwise from the top. A bounded dial stops there. On a wrapping dial, the next step returns to zero at the top. Clicking six o’clock from 500 selects 180, the only available value at that position. Omit `unitsPerTurn` to fit all 501 values around one continuous loop.

For values measured in turns, use `unitsPerTurn={ 1 }`. A step of 0.25 allows quarter turns. If one step spans an entire turn or more, tap the left half to subtract a step or the right half to add one. The same gesture applies to half-turn steps when several values share the two headings. Dragging still follows the physical scale. Include a visible value and describe the tap gesture in these cases.

Pair the dial with a number field when users need to enter an exact rotation or see how many turns they have made. This example keeps the override in the parent. Clearing the field restores an inherited 45°. Entering zero sets an explicit 0°.

## Label the dial

Place the knob in `Field.Root` with a visible `Field.Label`. Add `Field.Description` when the setting needs an explanation. For standalone use, provide `aria-labelledby` or `aria-label`. Use `format` to include the unit in the slider's accessible value, or supply `getAriaValueText` for values with custom names.

Pass `value` and `onValueChange` to keep a readout or another control in sync. For an uncontrolled dial, pass `defaultValue`. To restore a form’s defaults with a Reset button, control the value and restore it in the form’s `onReset` handler. The `ref` points to the outer element. Use `inputRef` to focus the range input.

## Keyboard interaction

Tab focuses the slider. Up and Down change the value by one step. Right and Left follow the reading direction. Page Up, Page Down, and Shift with an arrow key use `largeStep`, which defaults to 10 units. The dial rounds this increment to the nearest whole number of steps, with a minimum of one step. Home and End go straight to the first and last selectable values.
