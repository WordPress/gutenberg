# Knob

`Knob` is a dial for choosing an angle. It is internal to `@wordpress/ui` and is not exported. Use it to build a control that pairs the dial with an input, where the input shows the exact number and the dial shows the direction.

Do not use a knob on its own. A small dial is hard to set to an exact value, so there must always be an input beside it that edits the same value.

## Choose the range

Without `min` and `max`, the dial covers one turn and wraps. Zero points up, 90 points right, and one step past 359 returns to 0. Use this for a direction, such as a gradient angle.

<Canvas of={ KnobStories.Default } />

Set `min` and `max` together when the number of turns matters. The dial stops at both ends and counts the turns in between. With −720 to 720, the dial can turn twice in either direction from zero. A click picks the heading on the turn nearest the current value, so clicking three o'clock from 390° selects 450°. A drag keeps counting when it passes twelve o'clock.

<Canvas of={ KnobStories.Bounded } />

`unitsPerTurn` sets how many units make a full turn. It defaults to 360 for degrees. Use 400 for gradians, 1 for turns, and `2 * Math.PI` for radians. Set `step` to the smallest change the value should take. Steps count from `min`, so choose a `min` that is a whole number of steps away from zero.

<Canvas of={ KnobStories.WithUnits } />

## Pair it with an input

The input owns the value. It decides which numbers it accepts and what gets saved. The dial reads that value and reports changes with `onValueChange`.

A wrapping dial shows a value outside one turn at the same heading. The field below can hold 450 while the dial points where 90 does. A bounded dial shows a value outside its range at the nearest end. The dial never calls `onValueChange` to correct a value it was given. Give `name` to the input only, so the form submits the number the user sees.

<Canvas of={ KnobStories.WithNumberInput } />

### Label both controls

Both controls stay in the Tab order, so each needs its own name. Let the visible label name the input. Give the dial an `aria-label` that starts with the same words, such as “Rotation dial”. Use `format` to include the unit in the slider's accessible value, or supply `getAriaValueText`.

### Show an unset value

Pass `value={ null }` when no angle is set. The dial draws a hollow dot at `placeholder`, which is where an inherited or default angle goes. Turning the dial from there sets a value. Clicking the heading it already points to sets that value too.

A slider always has a number, so assistive technology reads the placeholder as the dial's value. The input is where an unset value shows as empty. `undefined` does not mean unset. It makes the dial uncontrolled, starting from `defaultValue`.

## Keyboard interaction

Tab focuses the dial. Up and Down change the value by one step. Right and Left follow the reading direction. Page Up, Page Down, and Shift with an arrow key use `largeStep`, which defaults to ten steps. Home and End go to the first and last selectable values. A wrapping dial continues past either end.
