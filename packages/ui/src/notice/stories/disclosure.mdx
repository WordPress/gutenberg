# Notice with disclosed details

Compose `Notice` with `Collapsible` to keep a short message visible and let users reveal supplementary details. This example follows the text-button approach in [Gutenberg PR #82496](https://github.com/WordPress/gutenberg/pull/82496).

See [Error messages](?path=/docs/design-system-patterns-error-messages--docs) for guidance on writing actionable errors and deciding when to offer copying.

<Canvas of={ DisclosureStories.WithDetails } />

## Composition

`Collapsible.Root` renders `Notice.Root`, so the message, actions, and panel remain direct children of the notice's grid. `Collapsible.Trigger` renders a `Notice.ActionButton`. The panel renders `Notice.Description` as a `div`, preserving the notice's typography and alignment without nesting block content inside a span.

The main message and details are separate plain-text strings. Convert server-provided HTML to plain text in the application before passing it to this composition.

## Copying the message and details

The text button uses "Copy error" for an error notice and "Copy message" for other intents. It copies the main message, a blank line, and the supplementary details, even while the panel is collapsed. The application supplies the exact text to `useCopyToClipboard`; `Notice` does not inspect its children or choose the clipboard contents.

After a successful copy, a separate "Copied" message provides visible confirmation. This message is also a `role="status"` region, which announces updates politely. The region stays mounted and empty before success. Confirmation clears after four seconds or when the message or details change. The button keeps its label and accessible name. The static notice has no automatic announcement. See [Notice announcements](?path=/docs/design-system-components-notice-announcements--docs) for dynamic messages.

## Trying the example

Use Enter or Space on "Show details" to expand the panel. The trigger keeps focus. Tab to "Copy error", activate it, and paste into a text field to inspect the copied message and details. Copying also works while the panel is collapsed. Change the intent to check the "Copy message" label.

Use the story controls to try a longer message or multiline details, and resize the canvas to check wrapping before and after copying. The "Copied" confirmation can wrap below the buttons in a narrow container. The panel uses `hiddenUntilFound`, so browser find-in-page can reveal a matching detail in browsers that support `hidden="until-found"`.
