# Notice with disclosed details

Keep a short message visible and let users reveal supplementary details with native `<details>` and `<summary>` elements.

See [Error messages](?path=/docs/design-system-patterns-error-messages--docs) for guidance on writing actionable errors and deciding when to offer copying.

The controls below configure the example. `intent` is passed to `Notice.Root`; `message` and `details` supply the example content and are not `Notice.Root` props.

## With details

The copy button follows the details. The browser supplies the disclosure marker and manages the open state. No additional `Notice` prop is needed.

`Notice.Description` renders a `<details>` element, preserving the notice's typography, color, and grid alignment. Its first child is a `<summary>` labeled "Details", followed by the supplementary text. `Notice.Actions` follows the disclosure, so the copy button remains at the bottom of the notice in both states.

## Copying the message and details

The example uses separate plain-text strings for the main message and details. Convert server-provided HTML to plain text in the application before passing it to the composition. Empty or whitespace-only details omit the disclosure and copy only the message, without a trailing blank line.

The text button uses "Copy error" for an error notice and "Copy message" for other intents. When details are available, it copies the main message, a blank line, and the supplementary details, even while they are collapsed. The application supplies the exact text to `useCopyToClipboard`; `Notice` does not inspect its children or choose the clipboard contents.

After a successful copy, a separate `Notice.Description` shows "Copied" in the notice's typography and text color. This message is also a `role="status"` region, which announces updates politely. The region stays mounted and empty before success. Confirmation clears after four seconds or when the message or details change. The button keeps its label and accessible name. The static notice has no automatic announcement. See [Notice announcements](?path=/docs/design-system-components-notice-announcements--docs) for dynamic messages.

## Trying the example

Use Enter or Space on the "Details" summary to expand the details. The disclosure control keeps focus. Tab to "Copy error", activate it, and paste into a text field to inspect the copied message and details. Copying also works while the details are collapsed. Change the intent to check the "Copy message" label.

Use the controls below the example to try a longer message, multiline details, and empty details. Resize the canvas to check wrapping before and after copying. The "Copied" confirmation can wrap below the button in a narrow container.
