# Theme Docs

This folder contains consumer-facing documentation for `@wordpress/theme`.

| File                | Audience          | Purpose                                                                  |
| ------------------- | ----------------- | ------------------------------------------------------------------------ |
| `token-guidance.md` | Package consumers | Canonical guidance for choosing semantic design tokens.                  |
| `tokens.md`         | Package consumers | Generated reference of all available design tokens. Do not edit by hand. |

The package README at [`../README.md`](https://github.com/WordPress/gutenberg/blob/trunk/packages/theme/README.md) is the consumer entry point for the package. Maintainer-facing token source documentation lives in [`../tokens/README.md`](https://github.com/WordPress/gutenberg/blob/trunk/packages/theme/tokens/README.md).
