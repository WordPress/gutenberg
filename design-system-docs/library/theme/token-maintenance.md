# Token maintenance

Token maintenance is for people changing the system's token source files, not for normal component consumers.

## Rules

- Store token definitions in the `packages/theme/tokens` JSON files.
- Follow the DTCG token format and keep Figma-specific metadata in `$extensions`.
- Keep primitive tokens internal and semantic tokens public.
- Generated artifacts under `src/prebuilt` must be regenerated by the package build process, not hand-edited.
- Update token documentation when token names, scopes, or public semantics change.
- Preserve Figma scopes so variables appear in relevant design-tool fields.

## Naming changes

Renaming public tokens is an API change. Use it only when the old name encodes the wrong semantics, and update docs, tests, generated artifacts, and migration guidance together.
