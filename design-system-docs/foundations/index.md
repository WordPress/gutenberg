# Foundations

Foundations are the shared decisions that components should not re-invent: tokens, color semantics, spacing and sizing, motion, overlay behavior, and accessibility.

Use foundation pages when authoring or reviewing a component. Component pages should link here instead of restating token naming, contrast, focus, or motion rules.
