## Body

**Describe the bug**

When instantiating a basic editor using the block list and provider components, toolbar icons can appear oversized in some Admin and frontend contexts

<img width="376" alt="Screenshot 2019-07-15 at 21 47 09" src="https://user-images.githubusercontent.com/58855/61248013-21eb5480-a74a-11e9-8e32-d5ffe62e0689.png">

I expected this:

<img width="359" alt="Screenshot 2019-07-15 at 21 47 38" src="https://user-images.githubusercontent.com/58855/61248040-32033400-a74a-11e9-8091-26fa30b76b25.png">

I've temporarily corrected the behaviour by applying a `max-width` and `max-height` of `20px` to `.components-toolbar__control.components-button > svg` but this doesn't explain the discrepancy and is a crude fix.

Reproduced in Chrome 75 and Firefox 67 on MacOS Mojave in Gutenberg 6.1.
