# Issue #75205: UI: ConfirmDialog component

## Body

## What problem does this address?

Existing components do not make it easy to implement ["actions that cannot be done" pattern](https://wordpress.github.io/gutenberg/?path=/docs/design-system-patterns-destructive-actions--docs#use-modal-with-destructive-button) in the guidelines introduced in #74778. This is true with `@wordpress/component`'s `Modal`, and even more true with the `@wordpress/ui` `Dialog` component introduced in #75183.

## What is your proposed solution?

We should build a `@wordpress/ui` equivalent to `@wordpress/components`'s `ConfirmDialog` component in `@wordpress/ui`, which extends `Dialog` with patterns supporting destructive actions, including those where a destructive button should be used.
