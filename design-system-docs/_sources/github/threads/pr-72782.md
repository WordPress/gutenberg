## Body

## What?

Expands on the work started in #72305 to create a new range of color tokens for "caution" states.

## Why?

These are intended to be used in themed components to convey a distinct severity level within warning states, similar to what's seen in some other design systems (e.g. [IBM Carbon](https://carbondesignsystem.com/patterns/status-indicator-pattern/#icon-indicator-statuses)).

## How?

- Adds new color ramp for caution
- Alters existing warning colors for more visual distinction

## Testing Instructions

Verify in Storybook:

1. Run `npm run storybook:dev`
2. Go to http://localhost:50240/?path=/docs/design-system-theme-provider-color-scales--docs
3. See color ramps for "caution", "warning", and "error" which are perceptually distinct
