# Issue #35940: Allow `FormTokenField` to be selected and copied

- URL: https://github.com/WordPress/gutenberg/issues/35940
- Author: coreyworrell
- Created: 2021-10-26T01:08:24Z
- Updated: 2025-12-17T08:06:36Z

## Body

## What problem does this address?
<!--
Please describe if this feature or enhancement is related to a current problem
or pain point. For example, "I'm always frustrated when ..." or "It is currently
difficult to ...".
-->
It can be very useful to copy a list of tokens from a field and paste into another. Right now that is not possible to do though, as tokens are unselectable, and `ctrl+a` does not do anything.

## What is your proposed solution?
<!--
Please outline the feature or enhancement that you want and how it addresses any
problem identified above.
-->
Allow tokens to be selectable, and/or allow `ctrl+a` to select all and `ctrl+c` to copy (or just copy shortcut always copies all without need to first select, but selecting could be useful for deleting all at once).
