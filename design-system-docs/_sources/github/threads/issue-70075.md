# Issue #70075: ColorPicker: dropdown shows incorrect RGB/HSL labels when alpha transparency is enabled

## Body

### Description

The `ColorPicker` component displays "RGB" and "HSL" labels in the format dropdown even when alpha transparency is enabled. This mismatch between dropdown labels and actual input fields creates confusion. The dropdown labels should match the input formats being displayed to maintain UI consistency and clarity.

Expected behavior should be that it matches the inputs below and has "RGBA" and "HSLA" in the dropdown when alpha is enabled.


### Step-by-step reproduction instructions

1. Run `npm run storybook:dev`
2. Navigate to the `ColorPicker` component
3. Enable alpha transparency
4. Notice that the dropdown shows "RGB" and "HSL" options instead of "RGBA" and "HSLA"
