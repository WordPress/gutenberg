## What?
Adds a visible edit icon next to the "No color selected" text in the color picker to improve discoverability of the custom color option.

<!-- In a few words, what is the PR actually doing? -->

## Why?
In usability testing, 3 out of 5 users struggled to figure out how to select a custom color. The checkerboard swatch that opens the custom color selector wasn't clearly interactive, so users didn't realize they could click it to choose a custom color.

## How?
<!-- How is your PR addressing the issue at hand? What are the implementation details? -->

- Added a pencil icon button next to the color name/value text in the custom color picker area
- The icon is functional and opens the color picker dropdown when clicked
- Styled with proper focus states for accessibility

## Testing Instructions

1. Open a post or page in the editor
2. Insert a block that has color options (e.g., Paragraph, Heading)
3. Open the block settings sidebar and find a color control (e.g., Text color)
4. Observe the color palette UI - there should now be a pencil/edit icon visible next to "No color selected" text
5. Click the edit icon - it should open the custom color picker dropdown
6. Verify the icon also appears when a color is selected (showing color name instead)
7. Verify keyboard focus states work on the edit button
