# Issue #73096: Theme: Add full typings for all entrypoints

- URL: https://github.com/WordPress/gutenberg/issues/73096
- Author: aduth
- Created: 2025-11-07T16:33:15Z
- Updated: 2025-12-30T16:39:34Z
- Comments: 0 of 0

## Body

## What problem does this address?

Currently, if an external project that uses TypeScript tries to import some of `@wordpress/theme`'s entrypoints, they will emit an error because there are no types associated with those files.

```ts
import tokenList from '@wordpress/theme/design-tokens.js';
// error TS7016: Could not find a declaration file for module '@wordpress/theme/design-tokens.js'
```

## What is your proposed solution?

All of the `@wordpress/theme` entrypoints should be fully-typed.

In practice, this means that the `design-tokens.js` should define an object of exports including `types`, similar to what's done with the primary entrypoint.

https://github.com/WordPress/gutenberg/blob/154a95a1e0a14ed1e5976d7c3279926007fc8f84/packages/theme/package.json#L28-L34
