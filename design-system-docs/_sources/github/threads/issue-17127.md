# Issue #17127: ToggleControl label misalignment when used outside of InspectorControls

- URL: https://github.com/WordPress/gutenberg/issues/17127
- Author: simonhammes
- Created: 2019-08-21T16:13:22Z
- Updated: 2019-12-02T10:43:39Z
- Comments: 2 of 2

## Body

**Describe the bug**
When a ToggleControl element is used outside of an InspectorControls element, the supplied label is slightly heightwise misaligned. I discovered this bug using Gutenberg 6.3, but it occurs in 5.4 (is that the version shipped in WP 5.2.2?) as well.

**Code**
``` jsx
<ToggleControl
    label="Display authors"
    checked={ props.attributes.isToggled }
    help={ props.attributes.isToggled ? 'Authors will be displayed' : 'Authors will not be displayed' }
    onChange={ () => props.setAttributes( { isToggled: ! props.attributes.isToggled } ) }
/>
<InspectorControls>
    <PanelBody title="Settings">
        <ToggleControl
            label="Display authors"
            checked={ props.attributes.isToggled }
            help={ props.attributes.isToggled ? 'Authors will be displayed' : 'Authors will not be displayed' }
            onChange={ () => props.setAttributes( { isToggled: ! props.attributes.isToggled } ) }
        />
    </PanelBody>
</InspectorControls>
```

## Issue comments

### simonhammes on 2019-09-29T19:38:41Z

URL: https://github.com/WordPress/gutenberg/issues/17127#issuecomment-536334023

It seems like the cause of this behaviour is related to #17129. 
Again, the inheritance of style properties from the '.editor-styles-wrapper' class causes issues, namely the line-height of the text (in this case 'Display authors') being set to 1.8. If the element wouldn't inherit this property, the line-height would be set to 1.4em which fixes the issue (for me at least).
Maybe someone else can double check  that.

### glendaviesnz on 2019-11-29T03:29:54Z
