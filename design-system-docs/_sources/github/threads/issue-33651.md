## Body

## Description
After update to WordPress 5.8 version FontSizePicker doesn't support value with type of number.

## Step-by-step reproduction instructions
https://github.com/NasKadir123/textBlock here is example of a custom block. This block is working in previous versions, but not in the new one. When you change Font Size in FontSizePicker for example to "large" it works, but if you insert number inside Custom input, for example "24" then update and refresh the page it will throw the error. It has the same effect even if you don't want to use HOCs and will just have a value attribute with type number.





## Expected behaviour
It should work correctly.

@NasKadir123 

Here's temporary fix for the issue:

```js
<FontSizePicker
	fontSizes={ fontSizes }
	fallbackFontSize={ fallbackFontSize }
	value={ fontSize.size }
	onChange={ ( value ) => {
		const fontSizeValue = value ? parseInt( value, 10 ) : undefined;

		if ( ! Number.isNaN( fontSizeValue ) ) {
			setFontSize( fontSizeValue )
		}
	} }
/>
```

I will try to create PR for `withFontSizes` HOC shortly.
