# Issue #57206: Tooltip doesn't hide when its anchor loses focus

- URL: https://github.com/WordPress/gutenberg/issues/57206
- Author: ciampo
- Created: 2023-12-19T10:27:45Z
- Updated: 2024-01-12T18:03:49Z

## Body

While the tooltip correctly shows when its anchor receives focus, it doesn't seem to hide correctly when its anchor loses focus:

https://github.com/WordPress/gutenberg/assets/1083581/9b4e4913-90d4-4896-a67d-ce1b00766933

I've also added a few more unit tests in https://github.com/WordPress/gutenberg/pull/57204 to make sure that the component is not behaving as expected.

### diegohaz on 2023-12-19T23:33:33Z

URL: https://github.com/WordPress/gutenberg/issues/57206#issuecomment-1863615985

> cc @diegohaz, in case you know the reason for this behavior — is there any reason why `Tooltip` doesn't hide on anchor blur without an explicit `onBlur` handler?

Yes, Ariakit popups using the [`hideOnInteractOutside`](https://ariakit.org/reference/tooltip#hideoninteractoutside) prop only close when you interact with something else in the same window. The rationale is briefly explained here: https://github.com/ariakit/ariakit/issues/3031#issuecomment-1802273326

We might be able to do something about iframes though.
