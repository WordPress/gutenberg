# Issue #33617: Deleting Focal Point Value Setting Crashes Block

- URL: https://github.com/WordPress/gutenberg/issues/33617
- Author: mrwweb
- Created: 2021-07-21T23:30:01Z
- Updated: 2021-07-23T05:23:04Z
- Comments: 1 of 1

## Body

## Description
When deleting the value in a focal point input for the Media & Text or Cover block, the block crashes with the error "This block has encountered an error and cannot be previewed."

## Step-by-step reproduction instructions
1. Insert a Cover or Media & Text Block
2. Delete the value of the "Left" or "Top" focal point setting using `Backspace` or `Delete` keys
3. Block Crashes

## Expected behaviour
Block does not crash. Ideally, the focal point uses the default value of 50% rather than 0% when there is no value in the Left or Top settings field.

## Actual behaviour
Block crashes with error:

> "This block has encountered an error and cannot be previewed."
