In order to enable the UI, you need to enable it in Gutenberg experiments page.

![Screenshot 2024-08-28 at 12 13 23](https://github.com/user-attachments/assets/4cc00a85-35ff-4d37-accc-a90967fc5413)

Then I recommend a PHP snippet to register a meta field. With something like this:

```
add_action( 'init', 'test_block_bindings' );

function test_block_bindings() {

	register_meta(
		'post',
		'pokemon_attack',
		array(
			'show_in_rest'      => true,
			'single'            => true,
			'type'              => 'string',
			'default'           => 'Scratch',
			'object_subtype' => 'page',
		)
	);
	register_meta(
		'post',
		'pokemon_type',
		array(
			'show_in_rest'      => true,
			'single'            => true,
			'type'              => 'string',
			'default'           => 'Plant',
		)
	);
}
```

After that, create a post, add a paragraph, and it should appear on the right sidebar.
![Screenshot 2024-08-28 at 12 16 35](https://github.com/user-attachments/assets/801559a9-3867-4cf7-9ba1-a5b55aa07b67)

This PR https://github.com/WordPress/gutenberg/pull/64570 will eventually move the Gutenberg experiment to a settings field, I'll let you know when is updated.
