## Body

Follow up to https://github.com/WordPress/gutenberg/pull/75204, separating `DataViews` and `Theme` concerns.

Bump the contrast target for `stroke1` from 2.6 to 2.9 which makes `--wpds-color-stroke-surface-neutral-weak` match the legacy `$gray-100` sass var.

Regenerates the prebuilt outputs (CSS, JS fallbacks, color.json, default-ramps, snapshot).

The main place to observe this change is in DataViews table layout. The strokes between rows are marginally lighter, and now match the appearance before #75204 was merged.
