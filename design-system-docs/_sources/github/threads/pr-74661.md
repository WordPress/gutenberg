## Body

## What?

Part of #74178

Add `Select` primitive component to `@wordpress/ui`.

## Why?

Based on [Base UI](https://base-ui.com/react/components/select), this is a low-level primitive that will build up to an `SelectControl` equivalent. It's also customizable enough to replace `CustomSelectControl` (v1 and v2).

## Testing Instructions

See stories in Storybook. Styling-wise, is should work in light/dark themes, as well as forced colors mode.
