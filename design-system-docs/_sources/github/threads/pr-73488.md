By the way the answer to your original question, "can this work without a `form`" is technically yes. I think you can pass a `ref` to the `ValidatedInputControl`, and call `ref.current.reportValidity()` imperatively to force validation to be reported to the user.

But the code smell of "if it can't be wrapped in a `form` maybe it shouldn't use validation" still holds. If `LinkControl` is really sometimes rendered inline in a random parent `form` node, that parent form can potentially trigger validation behaviors in `LinkControl`, which doesn't sound like something we want to happen here.
