## What?

Updates the `PaletteEditListView` component to satisfy the `exhaustive-deps` eslint rule

## Why?

Part of the effort in https://github.com/WordPress/gutenberg/pull/41166 to apply `exhaustive-deps` to the Components package

## How?

Add the `onChange` prop & `slugPrefix` to the `useCallback` dependency array.

2. Confirm that the linter returns no errors
3. Confirm unit tests still pass

### chad1008 on 2022-09-14T19:49:42Z

URL: https://github.com/WordPress/gutenberg/pull/43911#issuecomment-1247230835

> It looks the changes from this PR make the cleanup function from useEffect run immediately after a color is added, which results in the color being immediately deleted.

It looks like this is happening because:
- `onChange` [is being passed a `setThemeColors` method](https://github.com/WordPress/gutenberg/blob/a5ef504432e34afc0792eae62e44d71590c031eb/packages/edit-site/src/components/global-styles/color-palette-panel.js#L53), which my brain tries to tell me should be stable, because it's a state updater. However:
- `setThemeColors` is itself [returned from the `useSetting`](https://github.com/WordPress/gutenberg/blob/a5ef504432e34afc0792eae62e44d71590c031eb/packages/edit-site/src/components/global-styles/color-palette-panel.js#L16) hook, not from a `useState`. (I found that interesting @ciampo, because you and I saw something very similar to this in our pairing session earlier!)
- [Within that hook](https://github.com/WordPress/gutenberg/blob/fc3252fb4a9b86cd3ad61962bc09933c0651eac4/packages/edit-site/src/components/global-styles/hooks.js#L49), the `setSetting` method that's being returned (and destructured out into `setThemeColors`) isn't memoized. I think that's what's causing the problem.

To test this theory, I tried quickly wrapping `setSetting` in a `useCallback`. It helps, but not completely. When you first click on the button to add a new color the `ColorPalette` opens and closes, adding a basic black to the `PaletteEditListView`. From there, it's possible to use the `PaletteEdit` normally for additional colors:


https://user-images.githubusercontent.com/13856531/190247678-930d96f1-473c-4bf3-bb54-0a12be0a349a.mov

Sorting out that first usage of the `+` button felt like it was outside the scope of this PR or the Components package in general, but hopefully this helps as a starting point for future investigations 🤞
