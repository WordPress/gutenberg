# Issue #73779: Add support for custom "free text" CSS units

## Body

## What problem does this address?
<!--
Please describe if this feature or enhancement is related to a current problem
or pain point. For example, "I'm always frustrated when ..." or "It is currently
difficult to ...".
-->
Currently Gutenberg restricts spacing, sizing and other dimensional controls to a fixed set of units, typically px, rem, em, %, vh and vw. This limits the freedom to use CSS like calc(), clamp() and var(). Other builders like [Elementor](https://developers.elementor.com/elementor-3-10-beta/#:~:text=Introducing%20Custom%20Units%20%E2%80%93-,A%20new%20way%20to%20choose%20any%20unit%20you%20want%2C%20including%20CSS%20Math%20Functions,-Many%20elements%20in) and [Divi](https://www.elegantthemes.com/blog/theme-releases/advanced-units-for-divi) support flexible unit input:

<img width="2400" height="1260" alt="Image" src="https://github.com/user-attachments/assets/d5f95af4-b9e6-449f-8d9c-5c13c7c04514" />

## What is your proposed solution?
<!--
Please outline the feature or enhancement that you want and how it addresses any
problem identified above.
-->
Enable free-text CSS value input alongside the unit dropdown so developers can enter any valid CSS expression. This improves flexibility for modern responsive design.
