## Body

Part of #46741

## What?

Adds a `__next32pxSmallSize` prop to opt into the new 32px sizes when `isSmall=true`.

## Why?

To ensure a smooth transition from the current small size (24px) to the new small size (32px).

## Testing Instructions

1. `npm run storybook:dev`
2. For the "Primary" and "Icon" stories for Button, toggle the control for the `__next32pxSmallSize` prop. This should have no effect when `isSmall=false`.
