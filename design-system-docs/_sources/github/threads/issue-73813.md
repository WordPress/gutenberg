# Issue #73813: Shorten timeout duration for `Snackbar` component

- URL: https://github.com/WordPress/gutenberg/issues/73813

- Updated: 2025-12-09T01:15:04Z

## Body

## What problem does this address?

At the moment, the `Snackbar` component lingers for a long time, precisely 10s which appears to be a bit too long. The industry standard sort of sits around 5-6 seconds.

Previously, I had created an [issue](https://github.com/WordPress/gutenberg/issues/71153) for introducing a `duration` prop to regulate this, but after much push back based on UX concerns, @mirka [suggested](https://github.com/WordPress/gutenberg/issues/71153#issuecomment-3432749033) it would be better to create an issue to shorten the timeout duration, perhaps.

## What is your proposed solution?

Reduce the timeout duration based on @jasmussen [feedback](https://github.com/WordPress/gutenberg/issues/71153#issuecomment-3191209539).
