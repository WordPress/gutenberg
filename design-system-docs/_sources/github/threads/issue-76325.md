# Issue #76325: Design issue with Quick edit and `DateCalendar`

- URL: https://github.com/WordPress/gutenberg/issues/76325
- Author: ntsekouras
- Created: 2026-03-09T15:16:32Z
- Updated: 2026-03-10T15:59:28Z
- Comments: 6 of 6

## Body

DataForm uses [DateCalendar](https://wordpress.github.io/gutenberg/?path=/story/components-selection-input-time-date-datecalendar--default) private component which internally use [react-day-picker](https://daypicker.dev/). 

Right now in Quick edit the design is not great (see screenshot below) because there is a min-width for the dialog and a smaller `max-width` for the calendar itself.

I've already tried a few things to expand it by adding some styles and a new `month` classname [here](https://github.com/WordPress/gutenberg/blob/trunk/packages/components/src/calendar/utils/constants.ts#L17) but the problem is more convoluted because the internal library renders the months grid as a `table` element.  It [seems](https://daypicker.dev/guides/custom-components) we can provide custom components though if we want to.

I'd expect the end design to be more like [DateTimePicker](https://wordpress.github.io/gutenberg/?path=/story/components-datetimepicker--default) which expands by default and uses a `grid` that handles well the alignment of navigation arrows for months, the days header (e.g M, T, etc..) and the days number.

Hey @ntsekouras , the `DateCalendar` and `DateRangeCalendar` components, in their current iteration, have a fixed (ie. not "fluid") width.

With this limitation in mind, I think that currently the best workaround could be to center the calendar, if indeed the dialog can't be narrower.

Separately, since this is not the first time that a need for a more fluid calendar UI is shared (cc @PanosSynetos), we could look at enabling a "stretch" behaviour on the component's side — although that will potentially require some design work to understand whether we should just tweak width/horizontal spacing, of if whether height/vertical spacing should be affected too, somehow (cc @WordPress/gutenberg-design )
