Hi @intelligence, have you tried adjusting the CSS first?

Please try increasing the `max-width` (beyond `48px`) or remove it entirely on the `components-unit-control__select` class to see if the desired outcome can be achieved purely through CSS. This might help us avoid adding a new prop and the associated development overhead.

|Before|After|
|-|-|
| <img width="1156" height="470" alt="Image" src="https://github.com/user-attachments/assets/773e1961-e2f4-4093-87ef-7dc89a82ca2c" /> | <img width="1156" height="528" alt="Image" src="https://github.com/user-attachments/assets/1addeecb-5e35-43da-87e2-35a682a6d540" /> |

As you can see, I have removed the `max-width` and it clearly shows the whole label, if we can do it purely via CSS could be the best option.

One potential approach (least possiblity) could be to introduce a new prop to `UnitControl`, such as `maxUnitWidth`, which would accept either a `string` or `number` value (e.g., `48` or `48px`). This value could then be passed to `UnitSelect` to dynamically adjust the width based on developer preference, updating the `max-width` defined in `baseUnitLabelStyles` accordingly. I’m not in favor of this approach as it might be specific use case.
