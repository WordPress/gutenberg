# Issue #58850: Make Ariakit `Composite` API standard

- URL: https://github.com/WordPress/gutenberg/issues/58850
- Author: andrewhayward
- Created: 2024-02-08T16:51:59Z
- Updated: 2024-09-05T15:38:18Z

## Body

Reakit is now gone (#53278) and `Composite` is implemented entirely with Ariakit. However, Ariakit's API is only exported as a private `V2`, and the public (albeit `__unstable`) export is a legacy implementation designed to maintain Reakit's API.

We need to monitor usage, and decide when to...
- [x] ...export and stabilize the new version of the component https://github.com/WordPress/gutenberg/pull/63564
- [x] ...move all consumers away from the private API export and remove the private API export #63569
- [x] ...deprecate the `__unstable` legacy implementation #63572

## ✍️ Dev Note

- see [this dev note](https://github.com/WordPress/gutenberg/pull/58620#issuecomment-1976663196)) for the unstable component's refactor
- see the dev note in https://github.com/WordPress/gutenberg/pull/63569 for the stabilization of the new `Composite` component
