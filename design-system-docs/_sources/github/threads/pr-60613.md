## ✍️ Dev Note

## TimePicker: Time input can be used in isolation

The time input of the `TimePicker` component can now be used in isolation as `<TimePicker.TimeInput />`. In this case, the `value` will be passed as an object in 24-hour format (`{ hours: number, minutes: number }`).
