## Body

**Describe the bug**
The Spinner is misaligned in RTL locales.

**To Reproduce**
1. Change your WordPress settings to a RTL locale.
2. Make it so a `<Spinner>` is visible (I just modified a block to make it always render a spinner).
3. Notice the circles are misaligned.
