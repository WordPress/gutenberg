## Description
Original ticket on trac at https://core.trac.wordpress.org/ticket/51245. Businesswoman Dashicon isn't currently rendering within the Block Library. The SVG version of the icon is the only SVG Dashicon within WordPress Dashicons that has two paths inside the SVG. This pull request alters the .js version of the SVG code to a single path, so that the Dashicon for businesswoman can be rendered in the Block Library.

## How has this been tested?
Equivalent code has been run locally using a fresh download of WordPress 5.5.1 and manually inserting the icon code into wp-includes/js/dist/components.min.js. According to the message from @ocean90 on trac, this updated code will make it into core wp-includes/js/dist/components.min.js following a package update.
