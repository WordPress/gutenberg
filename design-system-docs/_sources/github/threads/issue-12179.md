# Issue #12179: Cover Image Styled Incorrectly

- URL: https://github.com/WordPress/gutenberg/issues/12179
- Author: desrosj
- Created: 2018-11-21T15:05:47Z
- Updated: 2018-11-30T15:00:30Z
- Comments: 0 of 0

## Body

**Describe the bug**
When the components stylesheet is output before the block library stylesheet, the cover image block is black (making the text unreadable) and too tall.

![sgxish1zmi](https://user-images.githubusercontent.com/359867/48848833-fa86e800-ed72-11e8-9456-50e155958911.png)

In the plugin, the block library stylesheet has always been printed out before the components one, so this issue has not come up. But in WordPress Core, the stylesheets are being loaded in a different order.

The order can be enforced in Core using dependencies, but that is not really the correct solution.

For more context, see [Core Trac 45279](https://core.trac.wordpress.org/ticket/45279)

**To Reproduce**
Using any of the WordPress 5.0 betas, insert a cover image. You can also [add `wp-components` as a dependency of `wp-block-library`](https://github.com/WordPress/gutenberg/blob/master/lib/client-assets.php#L442) to force the stylesheets to reorder in the plugin.

**Expected behavior**
The block should be styled like so:
![screen shot 2018-11-21 at 10 04 13 am](https://user-images.githubusercontent.com/359867/48849674-daf0bf00-ed74-11e8-82f1-85fa20cc3193.png)
