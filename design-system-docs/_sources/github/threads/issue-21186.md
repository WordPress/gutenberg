## Body

**Describe the bug**
When a value of `0` (zero) is entered, the number input does **not** show `0`, but rather, the previous value.

**To reproduce**
Steps to reproduce the behavior:
1. Find/use a `RangeControl`
2. Slide to a value greater than `0` (zero)
3. Slide to `0` (zero)
4. Notice the input number
