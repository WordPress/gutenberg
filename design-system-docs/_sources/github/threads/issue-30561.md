## Body

## Description

The inline text colour spectrum picker does not stay static. 

## Step-by-step reproduction instructions

1. Go to Posts/Pages > Add New
2. Add a title
3. Add a paragraph block > Add text
4. Highlight text > click the more options arrow button
5. Select Text Colour
6. Select Custom colour
7. Move the colour spectrum picker bar to change colour spectrum
8. Text Colour options close

## Expected behaviour

For the Text Colour box to stay open and I can change the colour.

## Actual behaviour

The Text Colour closes and I am unable to select a colour.
