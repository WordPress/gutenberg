# Issue #67747: Make Button and ItemGroup 'Item as a button` focus indication consistent

- URL: https://github.com/WordPress/gutenberg/issues/67747
- Author: afercia
- Created: 2024-12-09T14:02:45Z
- Updated: 2025-03-05T09:51:27Z

## Body

### Description

Splitting this out from https://github.com/WordPress/gutenberg/pull/67513#issuecomment-2528005378

The Button component uses [:focus](https://github.com/WordPress/gutenberg/blob/f6d8c69efa9ebd7c3dd1fdd02cddde779c970319/packages/components/src/button/style.scss#L39-L44) for the focus state, so that the focus style is shown also when using the mouse.

Instead, when the ItemGroup item is rendered as a button via the `as` prop, it uses [:focus-visible](https://github.com/WordPress/gutenberg/blob/f6d8c69efa9ebd7c3dd1fdd02cddde779c970319/packages/components/src/item-group/styles.ts#L31-L42) so that the focus style is supposed to be shown only when using the keyboard.

As such, the focus indication behavior is inconsistent. I'd tend to think all the components from the `components` package should use a consistent focus indication behavior.

### Step-by-step reproduction instructions

- Edit a post, select an Image block and go to the block settings panel > Styles.
- Click and hold your mouse on the 'Duotone' button.
- Note: this button element is a Button component.
- Observe the focus style is visible while holding the mouse pressed.
- Switch to this PR's branch https://github.com/WordPress/gutenberg/pull/67513 if it hasn't been merged yet.
  - Edit. Note: the Duotone button example is no longer a good example because https://github.com/WordPress/gutenberg/pull/68672 changed the implementation to use a `ToolsPanel`.
- Repeat the steps above.
- Note: the Duotone button is now an ItemGroup > Item component rendered as a button element.
- Observe the focus style is not shown when holding the mouse pressed on the button.
- Observe the focus style is only shown when using the keyboard.
