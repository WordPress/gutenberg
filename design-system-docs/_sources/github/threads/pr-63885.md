## Body

## What?
Updates the design of the `Placeholder` component when passed the `hasIllustration` flag.

## Why?
Moving to a darker design based on the UI colour so that you can more easily see any `Spinner` placed on top. See https://github.com/WordPress/gutenberg/pull/63643#discussion_r1684103899.

## How?
I did what @jameskoster suggested in https://github.com/WordPress/gutenberg/pull/63643#discussion_r1684103899 😀

I also removed the `placeholder-style` mixin because it isn't really doing anything in most of the places it's used. The mixin adds `&::before` styling and we're often including it into a `&::before` or `&::after` which means there is no effect.

As far as I can tell this styling is only used in `<Placeholder hasIllustration>` which is the media blocks when not selected or when uploading.

### noisysocks on 2024-07-26T02:14:45Z

URL: https://github.com/WordPress/gutenberg/pull/63885#issuecomment-2251837131

Sorry, think there's some confusion. What do you mean by overlay? In [my comment above](https://github.com/WordPress/gutenberg/pull/63885#issuecomment-2249197772) I used overlay as a synonym for the `<Placeholder />`.

When an image that the browser can render (JPEG) is being uploaded, we show that image with the `is-transient` class which sets the opacity of the image to 0.3 with a `<Spinner />` on top.

When an image that the browser can't render (HEIC) is being uploaded, we show a `<Placeholder hasIllustration />` with a `<Spinner />` on top.

When an Image block with no image selected is deselected, we show a `<Placeholder hasIllustration />` by itself.

When `<Placeholder>` has the `hasIllustration` prop, it shows a diagonal line and we place some `&::before` styling on it that gives the `Placeholder` a solid background. 

So I think things are currently working as you expect? There's no overlay on top of the `<Placeholder />` or image. The `<Spinner />` appears either directly on top of the `<Placeholder />` or directly on top of the image with its opacity reduced. This PR changes the `<Placeholder />` to be a colour that doesn't make it too hard to see any `<Spinner />` that is on top.
