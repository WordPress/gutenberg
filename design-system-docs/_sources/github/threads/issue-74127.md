# Issue #74127: UI: Enhance Text and typography tokens with presets

## Body

## What problem does this address?

As of #73931, the `Text` component supports interfacing with typography tokens to control font family, size, line-height, and font weight. 

While these provide low-level control over individual style properties, more value could be derived from the design system providing preset combinations of typographical styles, like `body-sm` - `body-xl` and `heading-sm` - `heading-xl`. 

## What is your proposed solution?

This would require:

- Enhancements to existing `@wordpress/theme` typography design tokens to define the presets
   - The DTCG token specification supports these groupings explicitly through [`"$type": "typography"`](https://www.designtokens.org/tr/2025.10/format/#typography-component-references)
- A prop option on the `@wordpress/ui` `Text` component to consume these presets (e.g. `variant` or `preset`)
