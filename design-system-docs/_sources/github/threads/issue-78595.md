# Issue #78595: `Button.Icon` will clip certain icons

- Updated: 2026-05-29T20:09:31Z

## Body

## Problem

We currently have a somewhat hacky viewbox tweak in `Button.Icon` to fit `@wordpress/icons` icons nicely into a 16px square.

https://github.com/WordPress/gutenberg/blob/1c3f7baa123ba5fb950ea58b75417ebfb59bb9a7/packages/ui/src/button/icon.tsx#L11

Certain library icons have visible portions outside this 4px-inset view box, and thus will be clipped.

With some raster tests, I was able to identify a list of affected icons.

<img width="515" height="336" alt="List of affected icons" src="https://github.com/user-attachments/assets/dbdb4d8c-9ae8-49bd-8e3d-c542b3848f11" />
<br />

(☝️ This is just a preview, see the full list on [StackBlitz](https://stackblitz.com/edit/he2zfypu?file=src%2FApp.tsx))


While there are some clipped icons that are less noticeable and we can maybe let slide, there are still dozens of icons that will not be usable in the current state.

## Proposed fix

Two possible strategies to address:

1. Find a better compromise (e.g. drop the viewbox hack and add a margin offset in CSS, or tweak the viewbox hack so they're less problematic with these flagged icons).
2. Redraw the flagged icons.

### jasmussen on 2026-05-26T10:26:32Z

URL: https://github.com/WordPress/gutenberg/issues/78595#issuecomment-4543384865

They are not always expected to have 4px padding, because the guidelines are **optically** balanced, not physically. E.g. three icons, one square, one horisontal rectangle, one vertical rectangle, can be optically balanced because of their perceived volume, while still have different dimensions. It sounds like the negative margin approach might allow the contents to go outside the overflow, in which case that would adhere to the optical spirit, probably.

I will note that a few of those icons will need to be redesigned regardless. These are hurriedly ported dashicons we never got to replace:

* keyboardClose (darker than keyboard)
* insertBefore
* insertAfter

These icons are not designed according to wordpress icon principles, and may be material icons:

* offline

There are more icons in both those two categories above, but for the moment I focused only on those you flagged as clipped.
