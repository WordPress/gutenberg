## Body

Part of #55023

## What?

Renames `CustomSelect` and `CustomSelectItem` to the names we actually want to ship with:

- `CustomSelectControlV2`
- `CustomSelectControlV2.Item`

## Why?

I have been discussing this with @ciampo and @brookewp, and we now have the guidelines documented in the [Contributing guide](https://github.com/WordPress/gutenberg/blob/trunk/packages/components/CONTRIBUTING.md#naming).

We chose dot notation (`Component.Subcomponent`) over flat namespacing (`ComponentSubcomponent`) for better ergonomics on the consumer side, when doing things like unlocking private APIs and importing components with multiple subcomponents.

## Testing Instructions

✅ Internal naming makes sense
✅ Documentation (readme and Storybook) is consistent
