# Issue #60975: Components: remove Framer Motion

- URL: https://github.com/WordPress/gutenberg/issues/60975
- Author: DaniGuardiola
- Created: 2024-04-22T22:04:18Z
- Updated: 2024-10-17T09:19:55Z
- Comments: 4 of 4

## Body

This is a tracking issue. There has been some discussion of removing Framer Motion (the use of `motion` especially), citing a few arguments:

- It's chunky: just the `motion` component [is 40.2kb](https://bundlejs.com/?q=framer-motion%4011.1.7&treeshake=%5B%7B+motion+%7D%5D) or [about x13 production `react`s](https://bundlejs.com/?q=react%4018.2.0&treeshake=%5B*%5D) (all gzipped and minified!).
- Pure CSS animations are more performant.
- CSS is advanced enough to make most animation use-cases simple enough to implement and maintain.
- [Often, it costs more effort than just implementing the vanilla CSS alternative.](https://github.com/WordPress/gutenberg/pull/60560#issuecomment-2078109937)
- [It seems like it won't support React 19 for a good while, as the maintainers have run into a lot of trouble](https://github.com/framer/motion/pull/2667)

## Current situation

Framer Motion is wrapped in the components package (`packages/components/src/animation/index.tsx`). A few utilities are re-exported from it, including the `motion` component.

Those wrappers are then used both internally and externally in a few places. This issue tracks those instances as we transition out of them.

## Strategy

A good start would be removing all instance of internal usage within the components package.

In a second stage, external uses within Gutenberg could be removed as well.

Then, we should set the component as deprecated and nudge potential consumers (if any) towards either using CSS directly (preferred), using a lightweight alternative like [motion.dev](https://motion.dev/), or at least using framer-motion directly, as we don't want to officially support it anymore from the components package.

Finally, the re-exports should be deleted, or if we feel like an intermediate phase is useful, replaced by mock functions that throw errors asking users to migrate before completely deleting a few versions after.
