# Issue #52210: Unit Control crashes with certain units

- URL: https://github.com/WordPress/gutenberg/issues/52210
- Author: TimothyBJacobs
- Created: 2023-07-02T03:14:05Z
- Updated: 2023-07-24T14:51:33Z

## Body

### Description

The `<UnitControl>` component does not escape the units used to build the `firstCharacters` regular expression, see https://github.com/WordPress/gutenberg/blob/9a6958e6a3e69ecda18b8deb4e1b3cec352e30a0/packages/components/src/unit-control/index.tsx#L82

This causes the component to crash with RegExp syntax errors like `Nothing to repeat` when units are used that contain regex control characters.

There is a [`escapeRegExp`](https://github.com/WordPress/gutenberg/blob/9a6958e6a3e69ecda18b8deb4e1b3cec352e30a0/packages/components/src/utils/strings.ts#L81) helper that I think could be applied to the `first` character value.

This looks to be a bug introduced in #39303.

### Step-by-step reproduction instructions

1. Use the `UnitControl` in a block or any React environment with the following code.

```js
<UnitControl
	value={value}
	onChange={onChange}
	units={[
		{
			label: '+',
			value: '+',
		},
		{
			label: '-',
			value: '-',
		},
	]}
/>
```
