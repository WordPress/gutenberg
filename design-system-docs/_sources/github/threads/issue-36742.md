## Body

## What

Following up on #34817, we should add more unit tests to `NumberControl` and `RangeControl`

## Why

The work done in #35020 and #34542 showed how these components can be quite tricky to iterate on. We should add more unit tests to ensure that we don't introduce regressions when working on them

## Acceptance Criteria

- [ ] Go through past issues and PRs (starting with #35020 and #34542) to take note of the different nuances and regressions found while working on these components
- [ ] Introduce unit tests to the `NumberControl` and `RangeControl` components

https://github.com/WordPress/gutenberg/pull/47246 this PR has gone a step further by checking the behavior of the component in both controlled and uncontrolled environments. Additionally, it has improvements in the following ways:

- Basic rendering:

1. Tests actual input and typing functionality, not just visibility
2. Verifies value updates after user interaction 

- Validation:

1. Better tests for in-range values (verifies they don't change when valid)
2. More thorough checking of input states before and after validation
3. Clearer distinction between valid/invalid input test cases

- Key UP/DOWN interactions:

1. More detailed setup of test scenarios with valid inputs first
2. Better testing of initial state before key interactions
3. Clearer expectations for decimal handling

- Custom spin buttons:

1. More comprehensive parameter testing via `test.each`
2. Better testing of edge cases (undefined values, boundary conditions)
3. Tests expected callback values more thoroughly


@ciampo the PR https://github.com/WordPress/gutenberg/pull/47246 can be carried forward as it improves the rigorousness of the testing and would enhance the quality of tests.

I believe there is scope to work on this PR and make the `NumberControl` tests more specific and deeper. While I'm not entirely sure about the controlled vs uncontrolled component testing approach, overall the tests in this PR are more thorough in their validations and edge case handling.
