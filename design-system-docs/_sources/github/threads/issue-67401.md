# Issue #67401: Position Toggle Button Not Taking Full Height

## Body

### Description

In the WordPress block editor, the “Position” toggle button options in the Group block settings do not take up the full height of the settings panel. This results in a visual inconsistency, as users must scroll to view the full options.

Related Trac ticket: https://core.trac.wordpress.org/ticket/62605

### Step-by-step reproduction instructions

1. Open the WordPress block editor.
2. Add a “Group” block to the page.
3. Select the “Group” block.
4. In the block settings panel on the right, locate the “Position” toggle button.
5. Observe that the “Position” toggle options do not extend to fill the full height of the settings panel.
6. Attempt to interact with the toggle options

### ciampo on 2024-12-03T15:45:21Z

URL: https://github.com/WordPress/gutenberg/issues/67401#issuecomment-2514926383

Thank you all for reporting.

The popover's height adapts to the available viewport space without causing — so, in that sense, it's working as intended.

At the same time, I understand that the behaviour may be inconvenient and disorienting.  As explained in https://github.com/WordPress/gutenberg/pull/67403#pullrequestreview-2476049731, our preferred solution would be to enable the popover to `flip` — although at the moment we're not able to enable such behavior, since it would cause the bug flagged in https://github.com/WordPress/gutenberg/issues/63180 to happen. Ideally, we'd first fix https://github.com/WordPress/gutenberg/issues/63180 and then enable the popover to `flip` when there isn't enough space.
