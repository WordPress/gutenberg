## Body

## What?

See https://wordpress.slack.com/archives/C02QB2JS7/p1768612969553299

Adds `displayName` to all components that use `forwardRef` and enforces the `react/display-name` ESLint rule for component packages.

## Why?

Components using `forwardRef` without a `displayName` show up as `ForwardRef` or `React.ForwardRef` in:

-   React DevTools, making debugging difficult
-   Storybook source code examples, showing confusing component names instead of the actual component name

## How?

1. Added `displayName` property to ~60 components that use `forwardRef`
2. Converted anonymous arrow functions in HOCs to named function expressions
3. Added `react/display-name` ESLint rule for `packages/components/src`, `packages/dataviews/src`, and `packages/ui/src` (excluding test and story files)

## Testing Instructions

1. Run `npm run storybook:dev`
2. Navigate to Components > Actions > Button
3. Check the source code which should show `<Button>` instead of `<ForwardRef>`

## React DocGen (for README auto-generation)

### For `forwardRef` Components

When using `forwardRef`, add a `displayName` to ensure React DevTools and Storybook identify the component correctly:

```tsx
// Good - JSDoc on the unforwarded function, displayName on the forwarded component
/**
 * Component description here.
 */
function UnforwardedButton( props, ref ) {
  // ...
}

export const Button = forwardRef( UnforwardedButton );
Button.displayName = 'Button';
```

### For Function Declarations

Regular function declarations do **not** need `displayName` - the function name is preserved:

```tsx
// Good - no displayName needed
/**
 * Component description here.
 */
function BoxControl( { ... } ) {
  // ...
}

export default BoxControl;
```

### For Re-exported Components

When a file has multiple exports (including re-exports), ensure the JSDoc is on the main component function:

```tsx
// Good - JSDoc on the component function
/**
 * A control for box values.
 */
function BoxControl( { ... } ) {
  // ...
}

export { applyValueToSides } from './utils';
export default BoxControl;
```
