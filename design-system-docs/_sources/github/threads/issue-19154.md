# Issue #19154: getBoundingClientRect error in Popover Component for anchorRef prop

- URL: https://github.com/WordPress/gutenberg/issues/19154
- Author: bfintal
- Created: 2019-12-15T23:45:04Z
- Updated: 2019-12-16T11:12:06Z
- Comments: 3 of 3

## Body

**Describe the bug**
Popover's `anchorRef` prop throws the following error when passed a prop:

> Uncaught TypeError: r.getBoundingClientRect is not a function

**To reproduce**
I have a button, that when clicked opens a Popover Component. A `ref` to the button is passed in the Popover's `anchorRef` prop. Here's the trimmed down Component with the relevant code:

```js
class ButtonIconPopoverControl extends Component {
	constructor() {
		super( ...arguments )
		this.buttonRef = createRef()
	}
	render() {
		return (
			<BaseControl>
				<IconButton ref={ this.buttonRef } />
				{ this.state.open && (
					<Popover anchorRef={ this.buttonRef } />
				) }
			</BaseControl>
		)
	}
}
```

On Gutenberg 7.1.0 throws the error on `getBoundingClientRect()`: https://github.com/WordPress/gutenberg/blob/bd8436f9f94656e8adc00dc1fdb3bbc6307f00af/packages/components/src/popover/index.js#L65

Related: #17867

**Expected behavior**
No error since I passed a ref

**Additional context**
- Error on Gutenberg plugin 7.1.0
