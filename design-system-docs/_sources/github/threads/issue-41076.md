## Body

### Description

When you edit the post date clicking on the post date into the Post sidebar, you get this warning when the DateTimePicker is loaded: 

```
Legacy context API has been detected within a strict-mode tree.

The old API will be supported in all 16.x releases, but applications using it should migrate to the new version.

Please update the following components: withStyles(CalendarDay), withStyles(CalendarMonth), withStyles(CalendarMonthGrid), withStyles(DayPicker), withStyles(DayPickerNavigation)
```

### Step-by-step reproduction instructions

1. Start a new post
2. Click on the Publish date/mention of the Post sidebar
