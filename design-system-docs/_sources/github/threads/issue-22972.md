# Issue #22972: Text field components - Add character (or word) counter and/or limit properties

- URL: https://github.com/WordPress/gutenberg/issues/22972
- Author: cliffordp
- Created: 2020-06-06T12:59:39Z
- Updated: 2023-04-24T04:56:31Z
- Comments: 3 of 3

## Body

**Is your feature request related to a problem? Please describe.**
I need to restrict a text field to be no more than 30 characters, although others might like a _word_ limit.

**Describe the solution you'd like**
A component prop like _characterLimit_ and _characterCount_, like https://github.com/WordPress/gutenberg/issues/16685 suggested, although I think I'd prefer naming more along the lines of _characterDisplay_

Again, others might want _word_ variations of the above, possibly even combining _characterLimit_ (validation) with _wordDisplay_ (UI)

**Describe alternatives you've considered**
I guess an uncontrolled input form field but then I wouldn't be using WP's TextControl and related components any longer.

@cliffordp I think some of this would be possible by wrapping `TextControl` in a custom component and applying the character limit in the `onChange` handler:
```
const [ value, setValue ] = useState( '' );

// ...

<TextControl
    onChange={ ( newValue ) => { setValue( newValue.substring( 0, 30 ) } }
    value={ value }
/>
```

but granted there's no real functionality built-in to text control for this. I'll label as an enhancement.
