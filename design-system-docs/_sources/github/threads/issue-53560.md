# Issue #53560: Button: Replace deprecated isSmall property with size="small" property

## Body

Related to #53472

The deprecated `isSmall` property is being used in the Button component and in the component that wraps the `Button` component.

I believe that the `isSmall` property should be replaced with `size="prop"` to officially deprecate it, as mentioned in [this comment](https://github.com/WordPress/gutenberg/pull/53472#issuecomment-1673643125).
