# Issue #64666: Components: Apply consistent placeholder color

- URL: https://github.com/WordPress/gutenberg/issues/64666
- Author: t-hamano
- Created: 2024-08-21T02:53:02Z
- Updated: 2025-01-21T13:13:24Z

## Body

Found this while researching #56388

## What problem does this address?

The placeholder color of form elements changes depending on the component and whether or not WordPress form styles have been applied.

### `Inputcontrol`

This component does not have an explicit placeholder color applied to it, so the placeholder color changes depending on the browser type or whether WordPress form styles are applied.

When this component is present in WordPress, [form styles are applied](https://github.com/WordPress/wordpress-develop/blob/5c19fa13699e409fd11b37db3af9b4bc440bcf7e/src/wp-admin/css/forms.css#L225) (`#646970`), so that it has a contrast ratio of `5.53:1` against a white background:

https://webaim.org/resources/contrastchecker/?fcolor=646970&bcolor=FFFFFF

![image](https://github.com/user-attachments/assets/2aba9aa6-8079-4c5e-9106-912dc0754faf)


On the other hand, if WordPress form styles are not applied, the browser default styles will be applied. In Chrome, the placeholder color is `#757575`, so the contrast ratio is `4.6:1`:

https://webaim.org/resources/contrastchecker/?fcolor=757575&bcolor=FFFFFF

![image](https://github.com/user-attachments/assets/32498f91-9d9a-4a67-8396-d3c52034f791)

### `SearchControl`

This component has a light gray background color (`#f0f0f0`).

When WordPress form styles are applied: The contrast ratio is `4.85:1`:

![image](https://github.com/user-attachments/assets/af31c46a-daf9-41cd-8e3f-c384bb82336f)

https://webaim.org/resources/contrastchecker/?fcolor=646970&bcolor=F0F0F0

When WordPress form styles are not applied: The contrast ratio is `4.04:1`:

![image](https://github.com/user-attachments/assets/f2d45309-1260-464b-94aa-d1c01cd14ef9)

https://webaim.org/resources/contrastchecker/?fcolor=757575&bcolor=F0F0F0

### `TextControl`

This component uses [the `input-control` mixin](https://github.com/WordPress/gutenberg/blob/2719bc8129c7b15d64933cde5cc63a43fe6b15d1/packages/components/src/text-control/style.scss#L19). This mixin applies the `#1e1e1e9e` color and has a contrast ratio of `4.67:1`:

![image](https://github.com/user-attachments/assets/7fca1a85-ed9f-47ba-b0eb-c3aa415f8c9a)

## What is your proposed solution?

- Placeholder color should be defined at the component level.
- I think removing the background color of the `SearchControl` component should be discussed as part of [#56388](https://github.com/WordPress/gutenberg/issues/56388), but at the very least, it should meet a contrast ratio of 4.5.1.
