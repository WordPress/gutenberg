## Body

## What?

Follow up to #65751

Remove the deprecated `__next40pxDefaultSize` prop from `TextControl`, making the 40px default size the permanent default.

## Why?

The soft deprecation was introduced in WP 6.7 and scheduled to be removed in WP 7.1. This is the first hard-deprecation PR in a per-component rollout.

## How?

- Remove runtime handling of `__next40pxDefaultSize` from `TextControl` and merge the 40px styles into the default.
- Keep a `@deprecated` `@ignore` type stub for external callers.
- Remove all monorepo usages of the prop on `TextControl`.
- Remove `TextControl` from the `components-no-missing-40px-size-prop` ESLint rule and add a restricted-syntax rule for passing the prop to `TextControl`.

## Testing Instructions

1. Open Storybook and smoke test `TextControl` (default and with label/help).
2. In the editor, exercise a few screens that use `TextControl` (e.g. block settings with text fields, site editor search).
3. Confirm `TextControl` inputs render at 40px height without the prop.
