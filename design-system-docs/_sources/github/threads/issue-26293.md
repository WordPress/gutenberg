# Issue #26293: RadioControl: Focus styles need attention in Firefox

- URL: https://github.com/WordPress/gutenberg/issues/26293
- Author: sarayourfriend
- Created: 2020-10-19T18:44:42Z
- Updated: 2023-12-25T11:17:03Z

## Body

**Describe the bug**
I'm not sure what the intention for the focus styles are ([the CSS rules for them are here](https://github.com/WordPress/gutenberg/blob/f8e10e05f6b6e98a34b1e901badcb155c196227d/packages/base-styles/_mixins.scss#L375)) but they look completely different in Chrome and Firefox (and especially bad in Firefox):

<img width="816" alt="Captura de Tela 2020-10-19 às 11 39 14" src="https://user-images.githubusercontent.com/24264157/96497705-ee766000-11ff-11eb-8a2e-0b658edf120a.png">
<img width="880" alt="Captura de Tela 2020-10-19 às 11 39 01" src="https://user-images.githubusercontent.com/24264157/96497721-f2a27d80-11ff-11eb-8734-c27da231a28f.png">

**To reproduce**
Visit https://wordpress.github.io/gutenberg/?path=/story/components-radiocontrol--default in **Chrome and Firefox on macOS** and observe the differences in default styles as well as focused styles (by tabbing into the control).

**Expected behavior**
Styles should be the same across browsers or at the very least there shouldn't be the triple halo in Firefox.

**Additional context**
Found while working on CSS-in-JS conversion of the `RadioControl`
