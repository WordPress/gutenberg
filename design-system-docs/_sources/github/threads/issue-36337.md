### Description

When someone changes the color, suddenly it gets stuck and the pointer inside the picker starts blinking automatically. 

![](https://media.giphy.com/media/Q5kGxXHI7aY7R2iJlS/giphy.gif)

### Step-by-step reproduction instructions

1. Open ColorPicker
2. use `enableAlpha` true
3. Change alpha slider for few times
4. Keep moving the color pointer inside the color picker, it will start blinking suddenly
