## What?
Migrates `Spacer` away from Emotion styles and onto an SCSS Module.

## Why?
This is the prop-driven layout pilot. It validates replacing many spacing interpolations and the Emotion-based `rtl` helper with CSS custom properties and logical CSS properties.

## How?
- Adds `style.module.scss` with the margin and padding declarations.
- Replaces Emotion class generation with `clsx` and scoped CSS custom properties.
- Uses logical properties (`margin-inline-*`, `padding-inline-*`, etc.) to preserve RTL behavior without the Emotion `rtl` helper.
- Preserves user `style` precedence over generated spacing variables.
- Updates tests to assert the custom-property contract instead of Emotion style snapshots.
