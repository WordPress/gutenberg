@sarayourfriend Ah! Nice catch. I think this was a result of a (so-so) refactor to achieve the ["abstracted example" from Reakit](https://reakit.io/docs/tooltip/#abstracting).

After poking at it via Storybook, I think the setup should be something like:

```jsx
	return (
		<TooltipContext.Provider value={ contextProps }>
			{ content && (
				<TooltipContent unstable_portal={ modal } ref={forwardedRef}>
					{ content }
					{ shortcut && <TooltipShortcut shortcut={ shortcut } /> }
				</TooltipContent>
			) }
			{ children && (
				<TooltipReference
					{ ...tooltip }
					{ ...children.props }
					ref={ children.ref }
				>
					{ ( referenceProps ) => {
						if ( ! focusable ) {
							referenceProps.tabIndex = undefined;
						}
						return cloneElement( children, referenceProps );
					} }
				</TooltipReference>
			) }
		</TooltipContext.Provider>
	);
```

The `forwardedRef` goes to the `TooltipContent`, and the trigger's ref stays in place.
That way, you can have access to the `TooltipContent` node, if needed.

```jsx

export const _default = () => {
	const ref = useRef()
	const tooltipContentRef = useRef()

	return (
		<Tooltip
			ref={tooltipContentRef}
		>
			<Text ref={ref}>Hello</Text>
		</Tooltip>
	);
};
```
