# Issue #72931: Theme: Condense object shape of color ramps

## Body

## What problem does this address?

See discussion:

The current generated color ramp object is quite expansive. Now that we're precomputing default ramps as of #72847, this has a non-trivial impact on bundle size.

## What is your proposed solution?

We should optimize the shape of the ramp object.

For example, the [above discussion](https://github.com/WordPress/gutenberg/pull/72847#discussion_r2485701020) includes some ideas around either eliminating or changing the shape to simplify how colors are assigned, removing `warning` value from the ramp objects.
