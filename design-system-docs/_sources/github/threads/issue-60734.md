# Issue #60734: The Button component has incorrect padding with text and icon position right

- URL: https://github.com/WordPress/gutenberg/issues/60734
- Author: johnhooks
- Created: 2024-04-14T15:45:24Z
- Updated: 2025-09-23T18:58:26Z
- Comments: 2 of 2

## Body

### Description

The `Button` component of `@wordpress/components` has incorrect padding with text, icon and `iconPosition="right"`.

It applies the same reduced padding to the left and normal padding on the right, which is intended to improve the look of the button with an icon on the left.


<img width="205" alt="button-padding" src="https://github.com/WordPress/gutenberg/assets/20690965/a37b1c6b-9d13-4875-9baa-ecc9943c5101">


This results in a button looking uneven when it has an icon on the right. With the text too close to the left side and the button too far from the right.


<img width="114" alt="button-right-icon-2" src="https://github.com/WordPress/gutenberg/assets/20690965/c995d5c8-70a5-4896-af19-332cc13bc187">


### Step-by-step reproduction instructions

```jsx
import { Button } from `@wordpress/components`;
import { wordpress } from `@wordpress/icons`;

function HelloWordPress() {
  return (
    <Button text="Hello" icon={wordpress} iconPosition="right" />
  );
}
```
