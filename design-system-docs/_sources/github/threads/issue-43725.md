# Issue #43725: Icon: Deprecate dashicon strings

- URL: https://github.com/WordPress/gutenberg/issues/43725
- Author: mirka
- Created: 2022-08-30T19:17:49Z
- Updated: 2023-09-01T00:25:13Z
- Comments: 2 of 2

## Body

It was suggested in https://github.com/WordPress/gutenberg/pull/27461#issuecomment-760806802 that dashicons strings be deprecated from the Icon component, in favor of SVGs.

Note that this will also affect components that rely on Icon and accept arbitrary `icon` values, such as Button and DropdownMenu.

URL: https://github.com/WordPress/gutenberg/issues/43725#issuecomment-1233271167

It has come to my attention that the `Icon` component is responsible for rendering [block icons](https://developer.wordpress.org/block-editor/reference-guides/block-api/block-registration/#icon-optional), where I would imagine dashicons to be widely used.

So this itself could be considered a blocker to deprecating.
