## Body

## Description
With the block breadcrumbs introduced in the footer of the block editor, the snackbar notices are being cut off. This PR fixes the bottom margin for Snackbar notices.

## How has this been tested?
Steps to test:
- Run this line of code in your browser console:
```
wp.data.dispatch( 'core/notices' ).createSuccessNotice( 'hello', { type: 'snackbar' } )
```
