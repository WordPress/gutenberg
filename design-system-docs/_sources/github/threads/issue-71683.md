# Issue #71683: Button: Suppress  `__next40pxDefaultSize` warning if the variant is link

- URL: https://github.com/WordPress/gutenberg/issues/71683

- Updated: 2026-01-15T22:24:54Z

## Body

## What problem does this address?

Related to #65840

The Gutenberg project has an ESLint rule that displays a warning message if a component is the default size and does not have a `__next40pxDefaultSize` prop:

https://github.com/WordPress/gutenberg/blob/aa3b96150333d9102fe3bbb07cff3041fda69a3b/.eslintrc.js#L342-L346

This rule applies to `Button` components whose variant is `link`:

<img width="960" height="229" alt="Image" src="https://github.com/user-attachments/assets/1c7c9341-3bba-4eb1-be37-75fda24d3f0f" />

However, this prop is not actually necessary for `Button` components with the `link` variant, as their height is auto:

<img width="493" height="335" alt="Image" src="https://github.com/user-attachments/assets/936e902b-54ec-4992-a002-d61428f98833" />

Personally, I find this warning a bit annoying.

## What is your proposed solution?

My suggestions are:

- Make an exception to the ESLint rule, and in the case of the variant link button, do not output a warning even though `__next40pxDefaultSize` is missing.
- Don't apply the `is-next-40px-default-size` css class for `Button` components with the `link` variant. For example:

  ```diff
  diff --git a/packages/components/src/button/index.tsx b/packages/components/src/button/index.tsx
  index 0ab6b24b4d..38af680468 100644
  --- a/packages/components/src/button/index.tsx
  +++ b/packages/components/src/button/index.tsx
  @@ -146,7 +146,8 @@ export function UnforwardedButton(
          ];
   
          const classes = clsx( 'components-button', className, {
  -               'is-next-40px-default-size': __next40pxDefaultSize,
  +               'is-next-40px-default-size':
  +                       __next40pxDefaultSize && variant !== 'link',
                  'is-secondary': variant === 'secondary',
                  'is-primary': variant === 'primary',
                  'is-small': size === 'small',
  ```
