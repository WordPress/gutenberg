### hbhalodia on 2025-11-05T07:04:37Z

URL: https://github.com/WordPress/gutenberg/issues/72856#issuecomment-3489667477

Hi @picocodes, Thank you for sharing the reproduction steps.

Here’s a detailed explanation:

When using a touchpad, the gesture you’re performing is recognized as a scroll action, not a drag. To test the drag behavior, you’ll need to click and hold, then move (drag) the cursor. This will allow you to observe the intended drag functionality. Using the touchpad alone triggers a scroll action instead.

I have tested the behavior and can confirm that the drag functionality on the touchpad is working as expected. To verify this on your end, try clicking and holding on the touchpad before performing the drag action, instead of directly scrolling over it.
