## Body

## What?
Updates the **header hint text** (shown next to the _Size_ label) and **select hint text** (shown alongside each option in the select dropdown) in `FontSizePicker` to match what's in the design.

## Why?
Part of a focus into making the Typography panel look like it does in the design. See  https://github.com/WordPress/gutenberg/issues/34345#issuecomment-1217390408.

## How?
Here's the logic that I deduced from [the design](
![](https://user-images.githubusercontent.com/612155/185020659-3c07e7aa-e33d-4779-89da-dad28a7ded83.png)
):

Header hint text:

1. If entering a custom value, display _Custom_; otherwise
2. If a T-shirt selector is shown, display the selected T-shirt size; otherwise
3. If all size options are the same unit (e.g. _px_), display the unit in parentheses; otherwise
4. Display nothing.

Select hint text:

1. If all size options are the same unit (e.g. _px_), display just the number; otherwise
2. If the individual size option is a simple CSS value (e.g. not a `clamp()`), display it; otherwise
3. Display nothing.

`CustomSelectControl` has been updated to allow showing the selected hint text in the button per the designs.

## Testing Instructions
1. Navigate to Global Styles → Typography → Text.
2. Play with the _Size_ control.
3. Check different themes and/or modify the amount of sizes in `settings.typography.fontSizes` in your theme.json.
