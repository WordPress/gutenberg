Why the change to use ReactNode?

That seems to work in my testing, but this should really conform to [`JSXElementConstrcutor`](https://github.com/DefinitelyTyped/DefinitelyTyped/blob/deed5dd41a3f743d286cdc434f68cc14878936e0/types/react/index.d.ts#L84-L86). 

```ts
    type JSXElementConstructor<P> =
        | ((props: P) => ReactElement | null)
        | (new (props: P) => Component<P, any>);
```

The [`FunctionComponent`](https://github.com/DefinitelyTyped/DefinitelyTyped/blob/deed5dd41a3f743d286cdc434f68cc14878936e0/types/react/index.d.ts#L546-L547) type also returns `ReactElement | null`. ([`JSX.Element` just extends ReactElement](https://github.com/DefinitelyTyped/DefinitelyTyped/blob/deed5dd41a3f743d286cdc434f68cc14878936e0/types/react/index.d.ts#L2973), so `JSX.Element | null` is also good)
