### tellthemachines on 2020-04-30T05:39:40Z

URL: https://github.com/WordPress/gutenberg/issues/18427#issuecomment-621623856

@WPCurt when the alpha value is set to less than 1, the input for the hexadecimal value disappears because the hexadecimal format doesn't support transparency. So, if you need to use custom alpha values, you're restricted to the `rgba` or `hsla` input options. I hope that answers your question!

Closing as this is the correct behaviour for this component; feel free to reopen if I've missed anything.
