## Body

## What?
Update DataViews styles so that sticky elements inherit their background color from the parent container.

## Why?
Currently these elements have a hard-coded background color. That means if you want to use DataViews with a non-white background color you need to apply style overrides or endure these awkward mismatches:

<img width="978" height="593" alt="Screenshot 2025-11-13 at 14 36 47" src="https://github.com/user-attachments/assets/5b379d73-6893-4ccd-b0b3-35398f078137" />

## How?
Apply `background-color: inherit` to relevant elements. Result:

<img width="990" height="611" alt="Screenshot 2025-11-13 at 14 38 20" src="https://github.com/user-attachments/assets/ee41fa01-f5e5-4789-8220-2482aa566e57" />


## Testing Instructions
### Storybook
1. `npm run storybook`.
2. Observe the [DataViews story](http://localhost:50240/?path=/docs/dataviews-dataviews--docs) and change the background color of the DataViews container via the inspector.
3. Notice that the sticky elements in the table (column headers, actions column, footer) inherit the correct background color.

### Site editor
Check table layouts for any regressions.

> [!NOTE]  
> There is a trade-off with this approach; if a DataViews instance is placed in a container with no background color (or a transparent one) the inheritance will fail. Perhaps we should add a note to the documentation about this?
