# Issue #34816: Components: support `step="any"` in `NumberControl` and `RangeControl`

- URL: https://github.com/WordPress/gutenberg/issues/34816
- Author: ciampo
- Created: 2021-09-14T16:14:24Z
- Updated: 2021-10-11T05:29:13Z
- Comments: 0 of 0

## Body

## What

Accept `any` as a valid value for the `step` prop of the `NumberControl` and `RangeControl` components

## Why

The `input[type=number]` and `input[type=range]` HTML elements support `any` as a value for the `step` attribute ([#](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/range#attr-step), [#](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/number#attr-step)).

`NumberControl` and `RangeControl` aim at being a superset of these components, and should therefore support the `step="any"` case. Currently, this is not supported and causes the value of the inputs to become `NaN`

Also, partially related: #33156

## A/C

- [x] Introduce support for `step="any"` to `NumberControl` and `RangeControl`, following the expected behaviour from the HTML spec
- [ ] Add Storybook examples for both components
- [x] Update the `step` prop docs in both components README:
	- [x] The property can now be of type `number | "any"`
	- [x] Add a paragraph explaining the how the component should behave when passing "any"
- [ ] Add a CHANGELOG entry in the `@wordpress/components` package
