# Issue #16652: ResizableBox example does not resize

## Body

**Describe the bug**
The ResizableBox example in README.md does not resize and cursor never changes to resize syle.

Here is the code I used:

```
import * as React from 'react';
import { ResizableBox } from '@wordpress/components';

const Edit = (props: any) => {
  const {
    attributes: { height, width },
    setAttributes,
    toggleSelection,
  } = props;

  return (
    <ResizableBox
      size={{
        height,
        width,
      }}
      style={{
        backgroundColor: 'orange',
      }}
      minHeight="50"
      minWidth="50"
      enable={{
        top: false,
        right: true,
        bottom: true,
        left: false,
        topRight: false,
        bottomRight: true,
        bottomLeft: false,
        topLeft: false,
      }}
      onResizeStop={(event, direction, elt, delta) => {
        setAttributes({
          height: parseInt(height + delta.height, 10),
          width: parseInt(width + delta.width, 10),
        });
        toggleSelection(true);
      }}
      onResizeStart={() => {
        toggleSelection(false);
      }}
    >Some text</ResizableBox>
  );
};

export default Edit;
```

But when I use original module instead of exported one, it works as expected:

```
import { Resizable as ResizableBox } from 're-resizable';
```

### derweili on 2019-07-26T09:16:02Z

URL: https://github.com/WordPress/gutenberg/issues/16652#issuecomment-515375212

I testet the component again an found out that the `ResizableBlox` is indeed working.

The reason why it seems not not to work is because the handles (used for resizing) are hidden by default. 

https://github.com/WordPress/gutenberg/blob/bd76217166e0d75793ca20b63ad5d4c89119b321/packages/components/src/resizable-box/style.scss#L3-L7

This makes sense because the handles should only be visible when the Block is selected.
Unfortunately there is not documentation about this behavior.

To show the handles you need to add following css to your block:
```
.components-resizable-box__handle {
	display: block;
}
```

Thats the way how the core-blocks solve it:
Media-Text block
https://github.com/WordPress/gutenberg/blob/672599a74c5a373cfba7c83a0616e7d9e3af8023/packages/block-library/src/media-text/editor.scss#L53-L69
Image block
https://github.com/WordPress/gutenberg/blob/7964f381e07e06b2ac13698fd1465a4d0c16da1b/packages/block-library/src/image/editor.scss#L33-L36

There should be definitely be a documentation about this.

To improve the usage of the Component, I would recommend to add an "official" way to show/hide the handles, instead of a bunch of individual solutions.

This could be done by adding an new attribute "showHandles" to the `ResizableBox` which shows/hides those handles.
This attributes accepts a boolean value and should be false by default to ensure backwards compatibility
