## What?

Closes: #50521

This PR improves the usability of the gradient editor by adding multiple intuitive ways to remove control points:

1. Delete/Backspace key support when a control point is selected
2. Auto-removal of control points when dragged outside the gradient bounds (0% or 100%)

## Why?
Currently, removing gradient control points is not intuitive. Users can only remove points by selecting them and finding the "Remove Control Point" link at the bottom of the color picker.

## How?
- Added keyboard event handling for Delete/Backspace keys to remove the currently selected control point
- Implemented logic to automatically remove control points when dragged beyond the gradient boundaries (0% or 100%)

## Testing Instructions
1. Open the block editor and add a block that supports gradients (like a Cover block)
2. Edit the gradient by adding multiple control points (at least 3)
3. Test the following removal methods:
   - Select a control point and press Delete or Backspace
   - Drag a control point to the far left (0%) or far right (100%)
