# Issue #43951: Small language adjustment for "there are x events".

## Body

The following strings have a similar issue and don't really flow grammatically in all languages when translated. I wanted to create a PR for it, but I'm bad at reading giant text files and easily finding the origin. So, ticket time.

https://translate.wordpress.org/projects/wp-plugins/gutenberg/stable/nl-be/default/?filters%5Bstatus%5D=either&filters%5Boriginal_id%5D=11733917&filters%5Btranslation_id%5D=97011841

"%1$s. There is %2$d event" 

If this is displayed next to each other I'd change the "." to a ":"... Or change it to: 

"There is %2$s event on %1$s" and "There are %2$s events on %1$s". That flows a bit better and makes it easier for translation. Now, it's a bit restrictive.

https://translate.wordpress.org/projects/wp-plugins/gutenberg/stable/nl-be/default/?filters%5Bstatus%5D=either&filters%5Boriginal_id%5D=14392752&filters%5Btranslation_id%5D=97011792

"%1$s. Selected. There is %2$d event"

First of all, why the "." between the date and the word "selected"? The user selected those dates. I'd change the "." to "is". Also, what is the advantage / need of "Selected"? Since in the previous string you also select a date...? Maybe add the difference in the translation note as well as I assume that it's a difference between actually clicking on a date and hovering over it. 

I'd change this string to:

"%1$s is selected, there are %2$d event(s)" 

This flows a bit better.

It's especially those "." that bug me. Translated into e.g. Dutch, it feels wrong if you translate it exactly.
