# Issue #34306: [ENHANCEMENT] Putting more focus on the "Published" dialogue box which is easy to miss

- URL: https://github.com/WordPress/gutenberg/issues/34306
- Author: saiftheboss7
- Created: 2021-08-25T18:26:03Z
- Updated: 2025-07-23T04:44:58Z

## Body

## What problem does this address?
One of the changed Gutenberg introduced is how the "Post is published" appeared before Gutenberg. The new dialogue box is minimal and nice but when you have larger screen and focusing on the content, it's pretty easy to miss. Also, previously where the "Post is published" were, there was also a button to copy post link. Which is now in a separate place.
![CleanShot 2021-08-26 at 00 17 29](https://user-images.githubusercontent.com/19363738/130844409-76a54084-985c-43c8-af57-dd2b57680ff8.png)


## What is your proposed solution?
Just make the notification tooltip a bit bigger so it's more easily recognizable. Also, add a copy button to copy the post link. Added a green accent line to notify user the post is published successfully (Green = Success, general perception)

![CleanShot 2021-08-26 at 00 24 57](https://user-images.githubusercontent.com/19363738/130845013-96172727-04c5-4f2c-8a9a-d4a7864f0251.png)
