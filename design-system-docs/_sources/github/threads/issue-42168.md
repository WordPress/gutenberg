# Issue #42168: Allow ability to set a custom order for units in blocks

- URL: https://github.com/WordPress/gutenberg/issues/42168
- Author: kathrynwp
- Created: 2022-07-05T20:10:29Z
- Updated: 2022-07-08T17:19:41Z
- Comments: 1 of 1

## Body

## What problem does this address?

Currently, there does not seem to be a way to set a custom order for units in blocks. This means that the person using the site editor may inadvertently use the default unit by accident, causing display issues under some circumstances.

## What is your proposed solution?

Allow developers to set a custom order for units that is respected by the editor.

## Context

Brought up in [this forum thread](https://wordpress.org/support/topic/how-to-set-a-default-preferred-spacing-unit/), where the poster explained the following use case:

> In my themes I have:

```
"spacing": {
  "blockGap": true,
  "margin": true,
  "padding": true,
  "units": [ "em", "%", "px" ]
}
```

> However, in the unit dropdowns px always comes first, no matter which order they have in theme.json. Now my clients always forget to choose em for margins and paddings, and therefore mess up their mobile versions.
