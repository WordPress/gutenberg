## Body

Consider [this trac issue](https://core.trac.wordpress.org/ticket/64318#comment:18): ↗ should not be replaced by Twemoji

There's an ongoing discussion around whether the Twemoji set that is bundled by default with WordPress should replace the ↗ glyph with an emoji or not. At present, and as of 6.9, it does, which results in these cases, though note: **only in the site-editor for some reason**:

<img width="293" height="235" alt="Image" src="https://github.com/user-attachments/assets/a05da98d-7a8f-41b6-817e-c2c99fb59551" />

<img width="279" height="460" alt="Image" src="https://github.com/user-attachments/assets/d6ba4cd6-c051-47c0-82ce-46b6937b147f" />

Outside of reverting the change that led to this, it arguably means the ExternalLink component needs a new CSS class added: `wp-exclude-emoji`, for it to look as [intended](https://wordpress.github.io/gutenberg/?path=/docs/components-externallink--docs):
