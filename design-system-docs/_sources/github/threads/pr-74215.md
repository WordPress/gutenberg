## Body

## What?

Fixes #74214

Fixes DatePicker event indicators (blue dots) not appearing for scheduled and published posts when Gutenberg plugin is active.

## Why?

When PR #73887 refactored DatePicker to use configured timezone handling, the event date comparison logic was not updated to normalize event dates the same way as calendar days. This caused event indicators to disappear or display incorrectly when the browser timezone differed from the WordPress site's configured timezone.

## How?

Updated the event filtering logic in `packages/components/src/date-time/date/index.tsx` to:

1. Convert event dates using `inputToDate()` to handle various input formats (strings, Date objects, timestamps)
2. Normalize to start of day in configured timezone using `startOfDayInConfiguredTimezone()`
3. Compare with calendar days that are already normalized the same way

This ensures event indicators display correctly regardless of timezone differences.
