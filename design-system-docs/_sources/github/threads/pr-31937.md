>We'll still need to remove the !important for the active control. Without it, it's essentially minimal specificity competing against minimal specificity:

I refactored not to use `important` here: https://github.com/WordPress/gutenberg/pull/31937/commits/b730335c92363d110396a8dab06eb2885bb213ac.

While this works, the approach I took was to use `emotion css` with classNames. What this does is combining all the styles from the classes passed, in the order they are passed.
