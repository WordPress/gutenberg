# Issue #73385: DataViews: Improve spacing for primary action buttons

- URL: https://github.com/WordPress/gutenberg/issues/73385

- Created: 2025-11-18T09:55:57Z
- Updated: 2025-11-18T15:21:22Z

## Body

## What problem does this address?

Currently, the action button has a padding which makes it vertically misaligned with the field label "Actions". IMO this works for an icon, since it's also aligned with the Appearance gear icon. 

<img width="965" height="533" alt="Image" src="https://github.com/user-attachments/assets/3d220df3-e7f1-45cb-b060-58d3f7e8f4b8" />

With primary actions now presented as text links rather than buttons, scenarios with a single primary action further accentuate the vertical misalignment resulting from the button padding.

<img width="948" height="378" alt="Image" src="https://github.com/user-attachments/assets/547589ef-104c-445a-b3c0-13d58a9dd045" />

## What is your proposed solution?

As per @jameskoster's suggestion, one possible solution to introduce an unstyled button variant. In this approach, the spacing of buttons would be controlled by the container rather than the buttons themselves.
