## Body

![Screen Capture on 2021-01-29 at 09-51-16](https://user-images.githubusercontent.com/2322354/106292258-9990af80-621a-11eb-8de6-1050a8ba12f0.gif)

This update adds a new [Elevation component](https://github.com/ItsJonQ/g2/tree/main/packages/components/src/Elevation) for the [new Component System](https://github.com/WordPress/gutenberg/issues/28399).

This is a brand new primitive component. `@wordpress/components` previously didn't have a `Elevation` component, so we didn't need to "adapt" it.

This component renders shadows using the elevation/shadow values from the new Style System.

## How has this been tested?

Tested locally in Storybook and in Jest.

@diegohaz Thank you for the review! We'll update the `isInteractive` prop in the story. The idea is that if it's enabled, the `Elevation` shadow should automatically provide `hover`/`active` effects (without you having to manually specify values).

To clarify with `focus`:

Let's pretend we want to add `Elevation` to a clickable (link) Card UI.
Let's say we want the shadow to be pretty big when the `Card` is focused:

We could do something like this:

```jsx
<LinkCard>
  ...
  <Elevation focus={10} />
</LinkCard>
```

The styles are written in a way where once the `LinkCard` is `:focused`, the `Elevation` `box-shadow` will change.
(Same goes for `active` and `hover`)

They apply when the direct parent element is engaged with, rather than the `Elevation` component itself.

Hope this helps 🙏
