# Issue #18885: DropZone: Pass originating event in onHTMLDrop and onFileDrop callbacks

- URL: https://github.com/WordPress/gutenberg/issues/18885
- Author: mwidmann
- Created: 2019-12-03T11:10:32Z
- Updated: 2024-12-25T18:30:57Z
- Comments: 3 of 3

## Body

**Is your feature request related to a problem? Please describe.**

Trying to implement a Drag'n'Drop enabled block from an external resource (in our case our editorial archive) is rendered difficult as `DropZoneProvider` hides away data that is would be valuable as it makes some arbitrary choices. 

Dragging the required content from our archive system has three types in the `e.dataTransfer.types`
array: ["text/plain", "text/uri-list", "text/html"]. in DropZone this results in `onHTMLDrop` to be used to give the data back, but only the data provided by `e.dataTransfer.getData('text/html')` 

**Describe the solution you'd like**

Besides passing an array of files and the position in `onFilesDrop` or the html and the position in `onHTMLDrop` also pass the originating event as a third argument.

Alternatively always also trigger `onDrop` which receives the originating event.

**Describe alternatives you've considered**
For the time being I'll try to implement my own DropZoneProvider which passes the data I need.
