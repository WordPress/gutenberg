## What?
<!-- Link this PR to its associated issue with an appropriate keyword: Closes, See, Follow up to, etc. -->

Migrate the "Color" / "Gradient" tabs on the edit palette screen to the new `Tabs` from `@wordpress/ui` ~and fix alignment~

ℹ️ **After the reviews, we're only going with the migration to the new component and ignore the spacing. I'm updating the PR title and description to better reflect that.**

<!-- In a few words, what is the PR actually doing? -->

## Why?
<!-- Why is this PR necessary? What problem is it solving? Reference any existing previous issue(s) or PR(s), but please add a short summary here, too -->

~The tabs looked misaligned with the rest of the UI~. Following the recommendation is to use the `Tabs` from the design system.

## How?
<!-- How is your PR addressing the issue at hand? What are the implementation details? -->

Update the component ~and set the `padding-inline` to use the same as the other elements in the context~. Kept the `tabIndex={-1}` as the panels were set to focusable=false.

A quick audit shows that basically all usages in the app have the `focusable={ false }` option. This made me wonder whether this should be the default.
