## What?

Adds a new `VisuallyHidden` component to `@wordpress/ui`.

This is a replacement for the `VisuallyHidden` component in `@wordpress/components`. It doesn't have an Emotion dependency, and relies on [Base UI](https://base-ui.com/)  to support a `render` prop that will be standard for the `@wordpress/ui` components.
