# Issue #43724: Icon: Support `size` prop for dashicons

- URL: https://github.com/WordPress/gutenberg/issues/43724
- Author: mirka
- Created: 2022-08-30T19:11:47Z
- Updated: 2022-11-11T18:43:34Z
- Comments: 7 of 7

## Body

## What problem does this address?

The `size` prop does not work when the `icon` is a dashicon string.

## What is your proposed solution?

Add some handling (either to the Dashicon or the Icon component) so it adds a `font-size` style equivalent to the `size`.
