# Issue #27283: Using the scrollbar of the parent page selector closes the selector.

- URL: https://github.com/WordPress/gutenberg/issues/27283
- Author: jennydupuy
- Created: 2020-11-25T22:15:49Z
- Updated: 2023-07-24T13:10:07Z
- Comments: 1 of 1

## Body

### Description
When i'm using the scrollbar in the parent page selector, the selector closes itself.
The bug is occuring under Chrome and Firefox.

### To reproduce
Steps to reproduce the behavior:
1.Go to the page editor
2.Activate the parent page selector
3.Click on scrollbar to scroll down or up : the selector closes itself

### Expected behavior
Scroll up or down with the scrollbar without the selector closes itself.
