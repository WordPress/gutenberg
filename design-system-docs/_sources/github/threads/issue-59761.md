# Issue #59761: TextControl: input element has 1px margin on the left and right

- URL: https://github.com/WordPress/gutenberg/issues/59761
- Author: t-hamano
- Created: 2024-03-11T15:46:22Z
- Updated: 2024-03-29T13:41:42Z
- Comments: 0 of 0

## Body

## What problem does this address?

`TextControl` component has an `input` element inside. WordPress core styles form elements with 1px margins on the left and right sides of `input` and `select` elements, which causes them to appear 2px wider than expected.

The `SelectControl` component is not affected by this style because [it applies `margin:0` to the internal `select` element](https://github.com/WordPress/gutenberg/blob/2142b52f3f9585d5f8bf254c085f183160cd89e4/packages/components/src/select-control/styles/select-control-styles.ts#L132). This results in differences in component width.

![text-control-margin](https://github.com/WordPress/gutenberg/assets/54422211/c302dd53-562b-43cf-a476-8c210a622c61)

## What is your proposed solution?

I think we need to apply `margin:0` to the `input` element inside the `TextControl`.
