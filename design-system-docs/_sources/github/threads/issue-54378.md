# Issue #54378: TimePicker onChange event only fires on month change

- Created: 2023-09-12T10:11:05Z

## Body

### Description

Importing the time picker [component](https://wordpress.github.io/gutenberg/?path=/story/components-timepicker--default&args=currentTime:1694210400000;is12Hour:!false)

When updating values other then the month in this component no onChange event is fired. 
The changes in time, day and year do persist after input but don't seem to fire the onChange function. 

I think this is a bug in the component or am I missing something? Hope someone can provide some perspective on this.

### Step-by-step reproduction instructions

Paste this code in an create-block edit.js file.


```
import {TimePicker} from '@wordpress/components';
import { useBlockProps } from '@wordpress/block-editor';

export default function Edit(props) {
	const blockProps = useBlockProps();
	return (
		<div {...blockProps}>
			<TimePicker
				currentDate={ new Date() }
				onChange={ ( date ) => console.log("logging here: ", date) }
			/>
		</div>
	);
}
```
Change values and check the logs. It only fires when changing the month.
