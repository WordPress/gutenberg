## Body

## What?
Update the border radius applied to the `Card` component.

## Why?
https://github.com/WordPress/gutenberg/pull/64368 sought to update all components, but Card was missed. This PR rectifies that.

`radiusLarge` is applied as this aligns with the guidelines in the radius scale:

> `$radius-large: 8px;     // Applied to containers with larger padding.`

I think we can consider `Card` similar to `Modal` in this respect.
