# Issue #47504: The hue jumps to red when leaving the colour picker area

## Body

### Description

The hue of the color picker jumps to red, when leaving the area of the color picker with the mouse. This makes selecting grey tones with a color tint very difficult, when accidentally moving the mouse too left.

### Step-by-step reproduction instructions

1. select a color with the color picker
2. select a color by holding the mouse down
3. move the mouse outside of the color picker area
