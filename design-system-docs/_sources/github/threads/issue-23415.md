# Issue #23415: Modals containing iframe incorrectly closes due to `shouldCloseOnClickOutside`

- URL: https://github.com/WordPress/gutenberg/issues/23415
- Author: emilio-martinez
- Created: 2020-06-24T08:01:54Z
- Updated: 2022-08-05T05:27:52Z
- Comments: 3 of 3

## Body

**Describe the bug**
Modals containing an iframe, e.g., from an embed, will incorrectly/unexpectedly close when `shouldCloseOnClickOutside` is enabled.

**To reproduce**
Steps to reproduce the behavior:

1. Use `Modal` within a component in a situation similar to what's portrayed in the code snippet below. `YouTubeEmbed` in this case is an example of a component that would render an `iframe` element.
2. When the `Modal` instance is displayed, click on the `iframe` as if to play the video embed or whatever action the `iframe` provides.
3. Observe the modal closes immediately.
4. Set `shouldCloseOnClickOutside` to `false` in the shown code and repeat steps.
5. Observe Modal won't close as before.

```jsx
<Modal
	// ...other properties, as applicable
	isDismissible
	shouldCloseOnClickOutside
	onRequestClose={ () => setModalOpen( false ) }
>
	<YouTubeEmbed id={ ... } />
</Modal>
```

**Expected behavior**
Logic executed when `shouldCloseOnClickOutside` is enabled should not close `Modal` instances when user clicks in `iframe`s contained within the modal.

**Editor version (please complete the following information):**
- WordPress version: [e.g: 5.4.2]
- Does the website has Gutenberg plugin installed, or is it using the block editor that comes by default? Yes, default.
- If the Gutenberg plugin is installed, which version is it? Version that comes with Wordpress using WP VIP config.

 - OS: macOS

 - Version 83.0.4103.106
