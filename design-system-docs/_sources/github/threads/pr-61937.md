## What?
Fixes: #61931 

## Why?
The slider dots in the `RangeControl` are brought to the front when opening the Appearance dropdown. 

## How?
Removing the z-index property from the InputControl's Root component in `focus-within` rule resolves the z layering issue.

## Testing Instructions
<!-- Please include step by step instructions on how to test this PR. -->
1. Open site editor.
2. Go to Patterns > Template Parts > Header
3. Select the navigation block. And go to it's InspectorControl and test the Appearance dropdown from Typography Panel.
