## Body

## Summary
This PR converts the `ResizableBox` component to TypeScript and cleans some stuff up along the way.

Part of #18838.

## List of changes
- Converted `ResizableBox` and its sub-components to TypeScript.
- Removed some dead code around the tooltip component that passed some props around that weren't actually being used. (I think they were a leftover from early iterations of the PR that added the tooltip.)
- Moved some constant CSS class/style objects out of `ResizableBox` component function so they aren't duplicated for every instance.
- Fixed several cases where `null` properties were included in `React.CSSProperties` objects, which expect `undefined` for empty values.
- Corrected several types that weren't explicit about allowing nullish values.
- Fixed a stylelint complaint in `resize-tooltip/styles/resize-tooltip.styles.js `.
- Enabled `strictNullChecks` for `@wordpress/components`. (Helped a lot in finding some of the above issues.)

## How has this been tested?
I inserted a Spacer block and used checked to make sure the drag handles work and display tooltips as before.
