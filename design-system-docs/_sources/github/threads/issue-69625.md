# Issue #69625: CustomSelectControl: Selected option’s `Check` icon doesn’t adapt with dark theme

## Body

### Description

The `Check` icon, which indicates a selected option within `CustomSelectControl` and `CustomSelectControlV2`, becomes nearly invisible in dark mode due to its dark color. Unlike other elements in the component, it does not adapt properly to the dark theme.

### Step-by-step reproduction instructions

1. Open the Storybook documentation for `CustomSelectControl` from [here](https://wordpress.github.io/gutenberg/?path=/docs/components-customselectcontrol--docs&globals=componentsTheme:darkBg).
2. Select an option.
3. Confirm, the `check` icon corresponding to the selected option is nearly visible.
