# Issue #23030: Cover: Reset should remove all user changes

- URL: https://github.com/WordPress/gutenberg/issues/23030

- Updated: 2020-06-10T07:51:24Z

## Body

**Describe the bug**

The new Padding controls should remove user changes when "Reset" is clicked. At the moment, it only removes session based changes.

This issue was originally discussed here:
https://github.com/WordPress/gutenberg/pull/21492#issuecomment-641236713


**To reproduce**

* sets a value for padding to 20
* saves the post
* reloads the editor
* click reset
* at this point, the padding value is 20 but reset doesn't work (I expected I'd be able to reset them)

**Expected behavior**

* sets a value for padding to 20
* saves the post
* reloads the editor
* click reset
* Padding should be 0. No padding inline styles
