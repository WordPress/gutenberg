# Issue #56192: Dropdown Menu component multi-select affordance not clear

- URL: https://github.com/WordPress/gutenberg/issues/56192
- Author: getdave
- Created: 2023-11-16T09:47:07Z
- Updated: 2023-11-16T09:47:07Z
- Comments: 0 of 0

## Body

When working in the Site Editor there are certian controls that utilise the DropDown component which have a poor UX around single vs multi-selection.

For example, in the Inspector Controls when enabling / disabling controls on a given block it is not clear to the user that the control allows for multi-selection.

How? There is no visual affordance that this is a multi-select control. It looks exactly like a single select toolbar such as you might find in any typical operating system. 

Why is this important? Because it's confusing to users. The visual affordance suggests a single click mechanic, so when they click and the dropdown remains open it is a confusing interaction. It _feels_ like a bug or a problem.

This behaviour was recorded by me when I was observing a user interacting with the software to build a website.

### Solution

We need to provide a visual design treatment that clearly indicates that you can select multiple items. I would suggest making the checkbox that is displayed once you click an option visible at all times. Then when you select an item it is given a "selected" visual treatment.
