## Body

## What?

Fixes Sass variable handling for the red color in validated form controls.

## Why?

They were not properly referencing the Sass color variable for red, rendering the `$alert-red` string itself in the resulting stylesheet.

## How?

Updates the Sass import/usage to properly reference the `$alert-red` variable.

## Testing Instructions

1. `npm run storybook:dev` and go to the story for `ValidatedInputControl`.
2. Trigger a validation error state.
3. The focus ring on the input should be red.
