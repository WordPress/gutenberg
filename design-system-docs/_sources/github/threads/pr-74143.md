## Body

This came out as a part of #74135, inspired by #74309, but I thought to do it separately as an extra benefit for the future.

## What?

Upgrades Storybook from v8 to v9 <s>and converts the `storybook` directory into an npm workspace package to isolate its dependencies</s>. Updating to v10 is going to be a major task which may need some configuration changes to the whole monorepo, as [Storybook v10](https://storybook.js.org/docs/releases/migration-guide) is ESM only and doesn't work with `"moduleResolution": "node"`, changing that is going to be chaotic and thus it needs more thought.

https://github.com/WordPress/gutenberg/blob/0c4de409d7d5fabfb5e11004170eafea7e241599/tsconfig.base.json#L27

## Why?

- Storybook v9 brings performance improvements and updated APIs

## How?

- Upgraded Storybook and the related dependencies to v9
- Removed obsolete `@ts-expect-error` directives from story files
- Replaced the incompatible source-link and badge addons with compatible ones given on the storybook docs
- Fix a race condition in `npm run storybook:dev`. See https://github.com/WordPress/gutenberg/pull/74143#discussion_r2652925970

## Testing Instructions

1. Run `npm install`
2. Run `npm run clean:package-types && npm run build` — should complete without errors
3. Run `npm run storybook:build` — should build successfully
4. Run `npx http-server storybook/build` to server the built storybook files.
5. Go to the URL the server is available on.
6. Confirm that the stories load fine.
7. Run `npm run storybook:dev` — storybook should start at http://localhost:50240
8. Confirm that the badges and source links work fine
