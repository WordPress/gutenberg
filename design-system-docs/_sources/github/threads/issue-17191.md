## Body

**Describe the bug**
I am building a custom dropdown that I have added to the top toolbar. This dropdown has a label. However, whenever I hover over the icon for the dropdown, the tooltip is covered by the admin bar. 

**To reproduce**
Steps to reproduce the behavior:
1. Register custom dropdown in toolbar
1. Hover over icon. 
1. See tooltip not displaying

**Expected behavior**
Tool tip displays

You can add the `tooltipPosition="bottom"` prop on a `Button` component to make it show below. [Here's an example](https://github.com/WordPress/gutenberg/blob/master/packages/block-editor/src/components/inserter/index.js#L44).
