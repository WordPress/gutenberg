# Issue #76153: Move "View Page" modal after SAVE to top right

- URL: https://github.com/WordPress/gutenberg/issues/76153
- Author: jhmonroe
- Created: 2026-03-04T17:39:05Z
- Updated: 2026-03-04T18:47:47Z
- Comments: 3 of 3

## Body

In UX/UI, forcing a user to move all over the page to do actions is a no-no.

When clicking SAVE (found in upper-right corner of screen) on a page/post in WP...

A "View page" modal briefly appears in the lower left corner of screen for approx 1-2 secs.

It's so easy to miss, and actually causes anxiety for people who will actually use it and are trying to get there fast enough to click.

Why can't this modal simply appear OVER the upper-right menu area briefly?

That way someone can click in the same area they just clicked to save.

This is no longer true with the latest Gutenberg version. Snackbars now appear in the middle, making them much easier to notice. See #75294.

Similar UI elements are usually positioned at the bottom of the page or app, away from action buttons. Moving them near top toolbar is probably a "won't fix".

You can find more general discussion regarding Snackbars in https://github.com/WordPress/gutenberg/issues/16549#issuecomment-3577598783.
