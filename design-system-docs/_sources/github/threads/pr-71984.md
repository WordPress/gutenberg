# PR #71984: Move search icons in search fields to prefix position

- URL: https://github.com/WordPress/gutenberg/pull/71984

## Body

Part of #56388
Part of #65323

## What?

Moves the search icon in all search fields to the prefix position.

### Affected components

- `SearchControl`
- `DataViews` search widget
- Command menu search

## Why?
 
We've agreed in #56388 that it's more coherent to have the search icon in the prefix position, since the icon is not interactive. In our component system, we generally put decorative items in the prefix, and interactive items in the suffix.

This is the first step of our search field style adjustments. The second step is to try removing the gray background color.

## Testing Instructions

See the Storybook story for the `SearchControl` component. It should look correct in a dark theme as well.

See inline comments for in-app instances.
