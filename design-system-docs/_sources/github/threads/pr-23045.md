## Description
This PR adds the ability to set a custom `class` attribute on the individual _**options**_ in the `<CustomSelectControl>` component.

Previously adding a `style` attribute was already possible, [but in certain circumstances](https://github.com/WordPress/gutenberg/pull/18869), this was insufficient when needing to add complex styling rules to individual options.

![Screen Shot 2020-06-10 at 06 29 21](https://user-images.githubusercontent.com/444434/84230622-509db680-aae4-11ea-9b94-f68439d14570.png)


## How has this been tested?

Manual testing and adding to Storybook example.

Tricky to test as the dropdown is added/remove from the DOM when you toggle the control. Therefore we need to use the browser debugger to "pause" the DOM with the dropdown in the open state!

To test:

* Checkout this PR.
* Boot Storybook `npm run storybook:dev`.
* Goto http://localhost:50240/?path=/story/components-customselectcontrol--default
* _Be ready_ to interact with the control.
* In your browser devtools console type: `setTimeout(() => { debugger; }, 5000)` and hit `ENTER`.
* Quickly toggle the dropdown in the example to "open" state so the dropdown is visible. 
* Wait for timeout to finish and debugger to be active.
* Switch to `Elements` panel in devtools.
* Inspect the dropdown `li` element. Look for the new `class` attribute `can-apply-custom-class-to-option` (see screenshot above).
* For testing only, try adding some additional classnames to other options and repeat the testing proceedure.
