# Issue #74736: Color picker: Custom color option (checkerboard swatch) is not discoverable

- URL: https://github.com/WordPress/gutenberg/issues/74736
- Author: davemart-in
- Created: 2026-01-19T12:29:00Z
- Updated: 2026-06-10T16:45:46Z
- Comments: 4 of 4

## Body

## Description

In the editor’s color picker/palette UI, the checkerboard/grid swatch that opens the custom color selector isn’t clearly interactive, so users may not realize they can choose a custom color.

<img width="554" height="682" alt="Image" src="https://github.com/user-attachments/assets/d4cd0337-d683-48b9-a37f-2d7d2592fc5c" />

In a recent usability test with 5 testers, one of the tasks was to change the color of text to be red. 3 of the 5 users struggle to figure out how to select a custom color.

**Expected:**
The UI should clearly indicate that custom colors are available—e.g., with a label (“Custom color”), an icon, tooltip, button styling, or other visual affordance that makes the checkerboard swatch obviously clickable.

Here's a mockup of an edit icon being added:

<img width="562" height="688" alt="Image" src="https://github.com/user-attachments/assets/011485c7-ab5a-4087-9cf2-e73b34099351" />

**Actual:**
The custom color entry point appears as a checkerboard/grid swatch with little/no indicator that it can be clicked, reducing discoverability.
