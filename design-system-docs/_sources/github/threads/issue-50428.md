# Issue #50428: `RadioControl` doesn't follow theme colors

- URL: https://github.com/WordPress/gutenberg/issues/50428
- Author: ciampo
- Created: 2023-05-08T12:34:53Z
- Updated: 2023-12-25T11:17:02Z
- Comments: 5 of 5

## Body

Currently, the `RadioControl` component doesn't inherit the theme colors. Here's an [example from Storybook](https://wordpress.github.io/gutenberg/?path=/story/components-radiocontrol--default&globals=componentsTheme:darkBg), when picking the "Dark (background)" theme preset from the top toolbar:

![Screenshot 2023-05-08 at 14 26 15](https://user-images.githubusercontent.com/1083581/236823757-9a54e283-2bdd-41e2-bbc7-dc702df3de74.jpg)

Both the text color and the UI "accent" color should be updated.

Furthermore, from playing around in dev tools, it seems like the existing styles (especially the `background` and `border-color` rules) don't affect the appearance of the `input`.  If we want to continue to add [custom styles](https://github.com/WordPress/gutenberg/blob/ecbde0e846ce3958f125302cfeda1cd34b5b89e3/packages/base-styles/_mixins.scss#L296-L337) to our radios, we should probably add `appearance: none`. Alternatively, we could look into using [`accent-color`](https://developer.mozilla.org/en-US/docs/Web/CSS/accent-color) instead, now that it's supported by all evergreen browsers
