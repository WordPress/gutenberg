# Issue #49225: DuotonePicker: Tooltip renders underneath UI

## Body

## What problem does this address?

In the [Storybook story](https://wordpress.github.io/gutenberg/?path=/story/components-duotonepicker--default) for DuotonePicker, the swatch tooltips are rendered underneath the duotone bar:

<img width="238" alt="Screenshot of tooltip layered underneath" src="https://user-images.githubusercontent.com/555336/226590417-50d8e548-2aa8-429d-8b19-f8e45656b88a.png">


## What is your proposed solution?

Usually this is fixed by wrapping the component in a `SlotFillProvider`:

```jsx
<SlotFillProvider>
  <MyComponent />
  <Popover.Slot />
</SlotFillProvider>
```

This does not seem to be sufficient in this case.
