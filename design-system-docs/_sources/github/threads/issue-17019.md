## Body

**Describe the bug**
A clear and concise description of what the bug is.

**To reproduce**
Steps to reproduce the behavior:

```js
import { SelectControl } from '@wordpress/components';
import { withState } from '@wordpress/compose';

const MySelectControl = withState( {
    size: '1',
} )( ( { size, setState } ) => (
    <SelectControl
        label="Size"
        value={ size }
        options={ [
            {value: null, label: '请选择...', disabled: true},
            {value: '1', label: 'select1 (decoration1)'},
            {value: '2', label: 'select2 (decoration2)'},
        ] }
        onChange={ ( size ) => { setState( { size } ) } }
    />
) );
```

although I disabled the first selection, but it always can be selected

**Expected behavior**
The first selection should be disabled
