# PR #27462: Extract the SlotFill feature out of components into a separate package

- URL: https://github.com/WordPress/gutenberg/pull/27462
- Author: jsnajdr
- Created: 2020-12-03T09:45:17Z
- Updated: 2026-01-28T10:52:06Z

## Body

Fixes #27191. I moved the `slot-fill` sources to a separate `@wordpress/slot-fill` package. The `@wordpress/components` now merely reexports the `@wordpress/slot-fill` exports, keeping full backward compat.

I didn't even mark the `@wordpress/components` reexports as deprecated, and didn't make any decisions about the two `SlotFill` implementations. The `@wordpress/slot-fill` package still contains both, and they are discriminated by the `<Slot bubblesVirtually>` prop. Please comment if you think that any of these things should be done in this PR.

Then I updated all imports in the Gutenberg monorepo to import directly from `@wordpress/slot-fill` and never use the `@wordpress/components` reexports.
