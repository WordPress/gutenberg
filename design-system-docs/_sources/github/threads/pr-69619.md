Closes https://github.com/WordPress/gutenberg/issues/69615


## Why?
This PR solves the issue of the subcomponents of the Popover component not exposing their TypeScript type

## How?
Just like the [Menu](https://github.com/WordPress/gutenberg/blob/179c868469cb20141f5071a5b8985b88e921be02/packages/components/src/menu/index.tsx#L101), types for the subcomponents of the Popover are also exposed and no longer require `@ts-expect-error`
