# Issue #41845: Spacing controls: Can't edit units on unlinked controls

- URL: https://github.com/WordPress/gutenberg/issues/41845
- Author: ryelle
- Created: 2022-06-21T17:06:11Z
- Updated: 2022-07-23T09:56:20Z
- Comments: 5 of 5

## Body

### Description

When editing the values in an unlinked spacing control (padding, margin, etc), the unit can't be changed. If you switch back to the linked control, it's possible to update it, but then it sets the same unit for all sides.

Could be related to #37856

### Step-by-step reproduction instructions

1. Add a Cover or Group (or any other block with spacing controls)
2. Go to the Dimensions settings, enable padding if it's not, and click the "unlink" button
3. Try to change the dimension for the top padding
4. You can't 😞 

If you link the controls again, you can change the dimension for all.
