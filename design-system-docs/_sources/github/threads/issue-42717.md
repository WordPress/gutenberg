# Issue #42717: Storybook: Write add-on to simulate effects of `forms.css` file

- URL: https://github.com/WordPress/gutenberg/issues/42717
- Author: mirka
- Created: 2022-07-27T00:23:35Z
- Updated: 2023-05-17T15:46:15Z

## Body

## What problem does this address?

When components are used in a WordPress context, they will be affected by a lot of broadly scoped styles in the [`forms.css`](https://wordpress.org/gutenberg/wp-admin/css/forms.min.css) file, which is loaded in wp-admin pages. But as a component library, the presence of the forms.css file in any given use case is not guaranteed.

## What is your proposed solution?

Similar to how we implemented a LTR/RTL switcher to the Storybook, we should implement a switcher to load/unload the forms.css file so component styles can be tested in both environments.
