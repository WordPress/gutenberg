## Description
This PR adds a component to pick angles and a hook to make dragging things easier to implement.
Some components will be refactored to use the new hook e.g: the custom gradient picker.
The angle picker will be used in the custom gradient picker PR that adds angle gradient type picking https://github.com/WordPress/gutenberg/pull/19582. The PR is ready to receive this component we just need to replace the AnglePicker component with this one.
