# Issue #62728: Styles: the edit Palette UI is not operable with a keyboard

## Body

### Description

Splitting this out from https://github.com/WordPress/gutenberg/pull/62698

I couldn't find a way to _add_ or _remove_ a custom color in the edit palette UI when using only the keyboard. 
This is a serious violation as _any_ user interface must be operable with the keyboard.

I guess this issue is not limited to the Edit palette UI and can be reproduced wherever the color picker is used with no explicit buttons to Cancel and Save.



### Step-by-step reproduction instructions

- Go to the Site Editor > Styles > Colors > Palette.
- Use the keyboard.

First not accessible flow:
- Move focus to the plus icon button 'Add color' and press Enter or Spacebar.
- The color picker opens.
- Observe that although the focus style is not always visible, all controls within the color picker aroperable with a keyboard.
- But...
- Once a color is set, there is no way to save or cancel and close the color picker with the keyboard.
- Observe there's no Button to Save.
- Press Escape: observe that nothing happens. Expected: the color value to be reset and the color picker to close.
- Use the mouse to click 'Done'.

Second not accessible flow:
- Move focus to the circular button of the new color and press Enter or Spacebar.
- The color picker opens.
- Change the values of the color usign the keyboard.
- Press Escape.
- Observe that now the color picker does close and the changes are saved.
- However, this is not the expected interaction: the Escape key should never, ever 'save'. Instead, it should always be used to cancel the current operation and reset any value.

Thir not accessible flow:
- Once a custom color is set, mofe focus to the ellipsis button 'Color options', press Enter, choose 'Show details' and press Enter.
- Move focus to the custom color item and press Enter or Spacebar.
- The color picker opens.
- Obserrve that whatever you do you can't exit the color picker with the keyboard.
- Observe there is no way to move focus to the `lineSolid` icon button to remove the color.
- Observe the remoce color button is only rendered in this 'editing' state of the UI, when keyboard users can't exit the color picker.
