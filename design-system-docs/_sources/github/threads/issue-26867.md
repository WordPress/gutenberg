## Current behavior

Currently, no matter what you pass into `PanelBody` as the `title` prop, it is wrapped in the `h2` element shown above. While this is fine for many of the core use cases, it raises issues when the component is used for custom features in plugins. I have run into the scenario multiple times where I want to use a `PanelBody` in an area where the document structure would suggest a different heading size -- e.g.

```
h1 My Document Title

h2 A section about cats
h3 A PanelBody with cat stuff
h3 A PanelBody with cat stuff

h2 A section about dogs
h3 A PanelBody with dog stuff
h3 A PanelBody with dog stuff
...etc.
```

Assuming reflecting document structure with my heading levels is important to me, PanelBody can't be used this way, so I'm forced to make my own component or use a hacked copy of PanelBody in my plugin.

## Suggested Change

I would like to be able to pass a prop into the PanelBody component to set the title size. It could be `titleHeadingLevel`, and it could default to the current `h2` for backward-compatibility. 


I'm going to self-assign this and will plan to work on a PR in the near future if no one raises any objections to this idea.
