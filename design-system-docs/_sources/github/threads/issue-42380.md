# Issue #42380: FlexItem doesn't render children when used "as" another component

- URL: https://github.com/WordPress/gutenberg/issues/42380
- Author: tellthemachines
- Created: 2022-07-13T04:05:34Z
- Updated: 2023-05-17T15:47:04Z
- Comments: 0 of 0

## Body

### Description

When using a FlexItem "as" a component that is expected to have children, the children of that component may not get rendered. This happens because in the [`useContextSystem` hook](https://github.com/WordPress/gutenberg/blob/trunk/packages/components/src/ui/context/use-context-system.js#L75), `finalComponentProps.children` is set even if there is no value for it, so the component FlexItem is rendering "as" receives an empty `children` prop, which may override its own children. 

I came across this issue while trying to use FlexItem "as" an [Icon](https://github.com/WordPress/gutenberg/blob/trunk/packages/icons/src/icon/index.js) in #42309.

### Step-by-step reproduction instructions

1. Try creating a FlexItem to render "as" an Icon, e.g. `<FlexItem as={ Icon } icon={ positionCenter } />`
2. Verify that the Icon content (in this case, the `path` inside the `svg` element) isn't rendered.
