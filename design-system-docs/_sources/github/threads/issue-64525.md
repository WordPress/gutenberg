# Issue #64525: Button groups in Typography tools should use ToggleGroupControl

- URL: https://github.com/WordPress/gutenberg/issues/64525
- Author: mirka
- Created: 2024-08-15T00:00:13Z
- Updated: 2024-08-16T19:09:56Z
- Comments: 2 of 2

## Body

The Decoration, Orientation, and Letter Case controls in Typography tools current use an ad hoc button group, but these should be using the [`isDeselectable` variant](https://wordpress.github.io/gutenberg/?path=/docs/components-experimental-togglegroupcontrol--docs#deselectable) of ToggleGroupControl. It's already nicely componentized and has an animation on toggle.

There aren't any blockers that I know of, but let me know if there are.
