# Issue #13579: The DateTime component incorrectly restricts years

- URL: https://github.com/WordPress/gutenberg/issues/13579
- Author: pento
- Created: 2019-01-29T23:01:46Z
- Updated: 2019-02-04T13:04:01Z
- Comments: 0 of 0

## Body

**Describe the bug**

The `DateTime` component restricts years to between 1970 and 9999. It shouldn't do that.

**To Reproduce**

1. Create a new post
2. Change the publication year to 1950.

**Expected behavior**

The year is changed to 1950.

**Additional context**

Core Ticket: https://core.trac.wordpress.org/ticket/46139
