## Why?
<!-- Why is this PR necessary? What problem is it solving? Reference any existing previous issue(s) or PR(s), but please add a short summary here, too -->

## How?

## Testing Instructions

- Confirm Storybook examples and editor examples work as expected.

## Notes
- PR also includes some updates to `Snackbar` to re-use the new `Notice` types, as recommended in #45472
- Added some new stories to demonstrate actions, JSX children
- Included some in-line comments to add context where needed

## Followups
`OnRemove` and `OnDismiss` are confusing props. In `Notice` there's really no difference between them. In `Snackbar` however there _is_ a subtle difference in behavior, so it would be good to update the docs of that component to make the distinction more clear.
