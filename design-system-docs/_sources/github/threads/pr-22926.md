# PR #22926: Fix CustomSelectControl items to use default cursor style

## Body

Currently, the items in the `<CustomSelectControl>`'s dropdown shows x2 cursor styles during an interaction. 

1. `cursor: text` - when interacting **directly over the item _text_**.
2. `cursor: default` - when interacting directly over the item anywhere _other_ than the text.

If we observe the interactions with a standard `<select>` control the cursor remains consistent as `cursor: default`. 

This PR updates the `<CustomSelectControl>` to match the behaviour of the native control by using the `cursor: default` style consistently when interacting with dropdown items. This also improves consistency when interacting with the component.

This issue was originally identified in https://github.com/WordPress/gutenberg/pull/18869#discussion_r435126582.
