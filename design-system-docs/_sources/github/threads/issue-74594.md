# Issue #74594: @wordpress/dataviews: Externalize design tokens stylesheet dependency

- URL: https://github.com/WordPress/gutenberg/issues/74594
- Author: aduth
- Created: 2026-01-13T19:02:22Z
- Updated: 2026-02-03T19:12:05Z
- Comments: 1 of 1

## Body

## What problem does this address?

Related discussion: https://github.com/WordPress/gutenberg/pull/74174#discussion_r2644046439

The `@wordpress/dataviews` package currently embeds the `@wordpress/theme/design-tokens.css` stylesheet contents. This can lead to duplication of the stylesheet the design tokens are already provided elsewhere in their application.

## What is your proposed solution?

Remove the design tokens stylesheet from `@wordpress/dataviews` own stylesheet and make it the consumer's responsibility to ensure the stylesheet is included in their application.

Specifically:

- Remove the [embedded stylesheets from DataViews](https://github.com/WordPress/gutenberg/blob/a8182e984b5a241041725a42ce34a3e1dd84d8d3/packages/dataviews/src/style.scss#L1)
- Document the requirement in the package README.md
- Communicate as a breaking change in CHANGELOG.md
- Ensure that existing usage includes the stylesheet to avoid regressions on existing usage within WordPress
