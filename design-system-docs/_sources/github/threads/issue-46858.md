# Issue #46858: `Dropdown`: the `position` prop is made redundant by `popoverProps`

- URL: https://github.com/WordPress/gutenberg/issues/46858
- Author: ciampo
- Created: 2023-01-03T18:08:39Z
- Updated: 2023-05-17T15:44:31Z
- Comments: 0 of 0

## Body

## What

While taking a look at the recent work done in #45787, I realized that the `position` of the popover for the `Dropdown`  can be set in two different ways:

- via the `position` prop (which should be soon deprecated in favour of `placement`, see https://github.com/WordPress/gutenberg/issues/44401)
- via the `popoverProps.position` prop

This situation is not ideal, since the component offers two separate ways to set the popover's position which can create confusion in the user:
- setting it via `popoverProps` overrides the value set via the `position` prop
- even more confusing, passing `popoverProps.placement` (which is the suggested prop instead of `position`) doesn't have any effects, since `position` is always set from the `position` prop and [it will override the `placement`](https://github.com/WordPress/gutenberg/blob/b1202138f4e44fa6312e93f2e7d5132cf73586cd/packages/components/src/popover/index.tsx#L258-L260)


## Proposed solution

I suggest we deprecate the `position` prop altogether, and we discourage its usage. We should use `popoverProps.placement` instead to set the popover's position.
