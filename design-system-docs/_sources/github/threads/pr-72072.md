## Body

Closes https://github.com/WordPress/gutenberg/issues/56388
Closes https://github.com/WordPress/gutenberg/issues/65323

## What?

This attempts to unify the `SearchControl` styles to the same standard styling of an `InputControl`.

## Why?

There've been concerns about the `SearchControl`'s gray background color, as it is the color of a disabled input. This will cause coherency issues within the design system.

## Testing Instructions

See the Storybook for `SearchControl`.

For all the affected instances, see the screenshots.
