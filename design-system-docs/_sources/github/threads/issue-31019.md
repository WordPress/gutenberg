## Description
If the link dialog is open, changing the format of the highlighted word can cause the link dialog to move on the screen. I'm able to reproduce this in both Safari and Firefox.


This was [originally reported on WordPress trac](https://core.trac.wordpress.org/ticket/50327) by Wordpress.org user [bjornsennbrink](https://profiles.wordpress.org/bjornsennbrink/).

## Step-by-step reproduction instructions
<!--
Please list the steps needed to reproduce the bug. For example:
1. Go to '...'
2. Click on '...'
3. Scroll down to '...'
-->
1. Set your desktop browser with to around 1327px wide
2. Go to the edit post screen
3. Enter some text
4. Highlight a word you wish to link
5. Click the link button in the toolbar
6. Press CMD+B on your keyboard
7. The link dialog jumps on the screen.

On the original report, it was jumping each time the user pressed cmd+b but I've only been able to reproduce it jumping once. This is possibly worth testing at additional browser widths.

## Expected behaviour
<!-- Please describe what you expected to happen. -->
Highlighted text to bold, the dialogs position is unaffected.

## Actual behaviour
<!-- Please describe what actually happened. -->
Highlighted text does bold, the dialog jumps.
