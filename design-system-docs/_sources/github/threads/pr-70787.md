### t-hamano on 2025-07-19T07:27:41Z

URL: https://github.com/WordPress/gutenberg/pull/70787#issuecomment-3091992333

It would be nice if we could take into account that the default font may vary from OS to OS and that font weight `500` may not be supported. If the weight is not found, the [fallback weight](https://developer.mozilla.org/en-US/docs/Web/CSS/font-weight#fallback_weights) is applied.

In Gutenberg, the following font families apply:

```
-apple-system,BlinkMacSystemFont,"Segoe UI",Roboto,Oxygen-Sans,Ubuntu,Cantarell,"Helvetica Neue",sans-serif
```

On Windows, [Segoe UI](https://learn.microsoft.com/en-us/typography/font-list/segoe-ui) is applied, but this font does not support weight `500`, so it is rendered as weight `600` (SemiBold):

<img width="381" height="134" alt="image" src="https://github.com/user-attachments/assets/52b41e60-1897-4e6b-bc11-3f5abf90bd1e" />

Therefore, there is a larger visual change compared to Mac.
