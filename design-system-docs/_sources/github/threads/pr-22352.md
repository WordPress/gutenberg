## Description

This PR upgrades the `reakit` dependency on `@wordpress/components` to the stable `v1.0.0`.

Two things were fixed that are relevant to us:

1. `onMouseDown` on `ToolbarItem`s no longer prevents drag events from happening.
2. `CompositeItem` is now focused on VoiceOver clicks (<kbd>Control</kbd>+<kbd>Option</kbd>+<kbd>Space</kbd>), so we don't need this piece of code on `AlignmentMatrixControl` anymore.

## How has this been tested?

1. Check toolbars are working properly.
2. Check `AlignmentMatrixControl` introduced on #21091.
