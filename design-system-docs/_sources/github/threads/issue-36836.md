# Issue #36836: Placeholder component does not correctly add margin-right for dashicons

- URL: https://github.com/WordPress/gutenberg/issues/36836
- Author: markjaquith
- Created: 2021-11-24T20:08:16Z
- Updated: 2023-01-05T19:23:50Z
- Comments: 1 of 1

## Body

### Description

The `Placeholder` component adds `margin-right` to its icon:

https://github.com/WordPress/gutenberg/blob/8533ca10dac2c2aa1831fb65bc2cf5768b9615e5/packages/components/src/placeholder/style.scss#L43-L65

The `margin-right` is specified as `1ch`.

But when you supply a dashicon, like `<Placeholder icon="admin-links" label="Label" />`, this doesn't work, because `1ch` is defined as the width of the `0` (zero) character in that font. And the width of `0` for the Dashicons font is apparently... wait for it... zero, so the icon is smashed up against the text.





### Step-by-step reproduction instructions

1. Make a component that feeds `Placeholder` a dashicons icon string and a label.
2. View how it renders.

### Screenshots, screen recording, code snippet

```jsx
import { Placeholder } from '@wordpress/components'

export default function MyComponent() {
  return (
    <Placeholder icon="editor-code" label="Some Label">
      <p>Inner Contents</p>		
    </Placeholder>
  )
}
```
