@Mamaduka unit tests are failing because `jsdom` doesn't implement scroll-related methods (see https://github.com/jsdom/jsdom/issues/1422 and https://github.com/jsdom/jsdom/issues/2751) — I suspect this was the original cause that pushed Dani to use `scrollLeft` instead of `scroll()`.

We could either look into adding global mocks for the whole Gutengerg project, or potentially add extra checks (or optional chaining) in the source code and add a comment explaining the reason for it.
