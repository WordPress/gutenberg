### ravishakya on 2018-12-21T05:48:48Z

URL: https://github.com/WordPress/gutenberg/issues/13045#issuecomment-449262790

Found alternative solution for this  `<ColorPicker>` and save your color as `rgba` it will disable the default `hex`

```
<ColorPicker								
        color={ this.props.attributes.bgOverlay }
	onChangeComplete={ 
	( bgOverlay ) => 
		this.onPageChanges( 
			'bgOverlay', 
			'rgba(' + bgOverlay.rgb.r + ',' + bgOverlay.rgb.g + ',' + bgOverlay.rgb.b + ',' + bgOverlay.rgb.a + ')' 
		) 
	}					
/>```

attributes: {
	selectedPageID:{
		type: 'string',
		default: 'rgba(255,0,0,0.3)'
	},
}
