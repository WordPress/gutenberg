## Body

### Description

In the site editor, if the topmost block is longer than the viewport height, the block toolbar is disappearing under the block. 

### Step-by-step reproduction instructions

1. In a new template, add a Query loop;
2. Make sure the Query has enough content that the block is longer than viewport height;
3. Select Query and see toolbar appearing behind it.
