# Issue #55137: DatePicker: Add support for dropdown and inputs in date selection

## Body

## What problem does this address?

The current [DatePicker component](https://wordpress.github.io/gutenberg/?path=/docs/components-datepicker--docs) does not provide a drop-down list feature, as well as inputs, similar to the [DateTimePicker component](https://wordpress.github.io/gutenberg/?path=/docs/components-datetimepicker--docs). 

This absence often requires additional steps or manual input from the user to select dates, which could be streamlined with a dropdown menu.

## What is your proposed solution?

Introducing a drop-down list and date inputs in the DatePicker component, akin to what is available in the DateTimePicker component. This addition will allow users to quickly navigate through months and years.

Currently, it looks like drop-down list for selecting date in calendar is only available in [TimePicker](https://wordpress.github.io/gutenberg/?path=/docs/components-timepicker--docs) component.

It would be great to have same date input in DatePicker component via prop.
