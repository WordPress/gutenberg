## Body

Our popover-like components animate in inconsistent ways, and are jarring when used together. We should unify the animations so they feel harmonious. We can use the [animations specs](https://github.com/WordPress/gutenberg/issues/73424#issuecomment-3554359831) proposed by @nebojsajurcic-a8c.

- [x] Popover (Dropdown, DropdownMenu, etc) #74082
- [x] Menu #74111
