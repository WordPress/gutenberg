# Issue #19610: Color Picker saturation overlay is offset until saturation picker moves

- URL: https://github.com/WordPress/gutenberg/issues/19610
- Author: jeryj
- Created: 2020-01-13T22:29:04Z
- Updated: 2020-06-22T06:28:47Z
- Comments: 3 of 3

## Body

**Describe the bug**
When the color picker is first rendered (before moving the saturation picker), the saturation background is offset to the left.

**To reproduce**
Steps to reproduce the behavior:
1. Go to the editor
2. Add a navigation block
3. Edit the text color of the navigation
4. Click the "custom color" link/button
5. See the offset saturation (the right 8px or so will be a solid, bright color)
6. Move the saturation picker and the saturation will snap into the correct spot

**Expected behavior**
The light/dark saturation background should span the entire background instead of being offset.
