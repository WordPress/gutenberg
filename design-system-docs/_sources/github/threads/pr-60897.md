## What?
<!-- In a few words, what is the PR actually doing? -->

There was a need to add a delay after every Tooltip test. After an Ariakit update, it's not necessary anymore for every test. See discussion: https://github.com/WordPress/gutenberg/pull/57345#discussion_r1435167187

## Why?
<!-- Why is this PR necessary? What problem is it solving? Reference any existing previous issue(s) or PR(s), but please add a short summary here, too -->

Faster tests.

## How?
<!-- How is your PR addressing the issue at hand? What are the implementation details? -->

Removed delay after every test and only added where necessary (after one specific test).
