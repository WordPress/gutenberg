# Issue #74007: Theme: Ensure theme styles are exposed via WordPress style handle

- URL: https://github.com/WordPress/gutenberg/issues/74007
- Author: aduth
- Created: 2025-12-15T18:18:44Z
- Updated: 2026-01-26T16:14:04Z

## Body

**Task**:

- A developer should be able to `wp_enqueue_style( 'wp-theme' );` to enqueue [`design-tokens.css`](https://github.com/WordPress/gutenberg/blob/trunk/packages/theme/src/prebuilt/css/design-tokens.css)

**Background:**

Related comment: https://github.com/WordPress/gutenberg/pull/73938#issuecomment-3656662012

We already treat `@wordpress/theme` as a "typical" script package in that we already have a script handle, and so it seems reasonable to have a style handle to bring in the required styles.

**Implementation notes:**

The build system [looks for `style.css` for "auto-registration"](https://github.com/WordPress/gutenberg/blob/d6e97990368dc9c7f2ee4d2ee6c0e8587399b05d/packages/wp-build/src/build.mjs#L465), so we may either need to ensure that a `style.css` is available for it to find, or update the build system to generalize styles exposed for auto-registration.
