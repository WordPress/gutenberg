## What problem does this address?

It is currently difficult to quickly locate specific icons in the Figma library, particularly as the collection grows. Users must manually browse through the library, which can be time-consuming and inefficient. This lack of a search function creates a barrier to usability and slows down workflows for those relying on the library for their designs.


## What is your proposed solution?

Introduce keyword search functionality in the Figma Icon Library to allow users to quickly find icons by typing relevant keywords. This enhancement would streamline workflows, improve accessibility, and encourage consistent use of system assets. The search functionality could mirror the [recent implementation in the Icon Library in Storybook](https://github.com/WordPress/gutenberg/pull/67442), ensuring alignment and a cohesive experience across platforms.

## Limitations

- Figma’s search functionality is limited to what’s included in component names, descriptions, and tags, so strategic naming and keywording are crucial.
- If more advanced search functionality is needed, like filtering or dynamic keyword management, external plugins or tools may need to be explored.
