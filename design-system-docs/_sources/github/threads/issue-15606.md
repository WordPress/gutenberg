# Issue #15606: Components: Avoid unguarded getRangeAt (Autocomplete)

- URL: https://github.com/WordPress/gutenberg/issues/15606
- Author: aduth
- Created: 2019-05-13T18:15:55Z
- Updated: 2019-07-29T18:23:12Z
- Comments: 0 of 0

## Body

Previously: #11457, #15576, #11209

Safari will throw errors when attempting to call [`Selection#getRangeAt`](https://developer.mozilla.org/en-US/docs/Web/API/Selection/getRangeAt) when there are no ranges in the selection. This has resulted in block errors on multiple occasions in the past (#11209, #15576).

**Tasks:**

- [ ] Update all outstanding unguarded references to `Selection#getRangeAt` to be guarded.
   1. https://github.com/WordPress/gutenberg/pull/15576#issuecomment-491924504
- [ ] Consider an ESLint rule or other programmatic enforcement which might help avoid regressions in the future.
   - Proposed implementation at:
      - https://github.com/WordPress/gutenberg/pull/15576#issuecomment-491928130
      - https://astexplorer.net/#/gist/26984b64750ba301178a38680fbce17f/66c7af6eb40fa09446d81d33f4adf3697eb13b47
