## Description

I'm sorry for the size of this PR. I tried to split it up but it seems impossible, there are either various build failures or tests that won't pass without all of these changes. I wish I could summarize the changes somehow but honestly it followed the process of starting with the smallest change and then following every rabbit hole that opened up until no more rabbit holes existed. I've essentially played whack-a-mole and whacked all the moles 😭 

I'd be happy to walk anyone though this PR and the progression of it. Hopefully the commits help a little bit with that, but some of them aren't split up nicely at all.

Even with all these changes, there's still a lot to do. This leaves certain components like `surface` completely broken, but it's also unused so I think this is safe to do.
