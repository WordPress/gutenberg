### Review thread 7 (resolved)

#### tyxla on 2024-11-07T02:53:50Z

URL: https://github.com/WordPress/gutenberg/pull/66635#discussion_r1831981136
Path: packages/components/src/input-control/stories/index.story.tsx

```diff
@@ -16,7 +16,8 @@ import { InputControlSuffixWrapper } from '../input-suffix-wrapper';

 const meta: Meta< typeof InputControl > = {
-	title: 'Components (Experimental)/InputControl',
+	title: 'Components (Experimental)/Selection & Input/Common/InputControl',
+	id: 'components-inputcontrol',
```

As this component is still formally experimental, if we change its ID, it will cause the previous URL not to work:

http://localhost:50240/?path=/docs/components-experimental-inputcontrol--docs

To fix that, we have 2 options:
- Use `id: 'components-experimental-inputcontrol'`
- Add the component to `PREVIOUSLY_EXPERIMENTAL_COMPONENTS`. 

Since the component is still experimental, I'd prefer the former option. Once we stabilize the component, we can always add it to `PREVIOUSLY_EXPERIMENTAL_COMPONENTS`
