## What problem does this address?
Contrary to `TextControl` fields, the `TextareaControl` doesn’t allow setting a `ref`, since the component doesn’t make use of `forwardRef` to its actual input.

## What is your proposed solution?
Add `forwardRef` to `TextareaControl`.
