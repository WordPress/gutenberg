## Body

We're running into some serious issues with plugins that bundle `react/jsx-runtime` and produce incompatible elements: `$$typeof: Symbol.for('react.element')` (legacy) versus `$$typeof: Symbol.for('react.transitional.element')` (new).

Then there is a runtime check that throws when legacy element is encountered: https://react.dev/errors/525

React 19 used to have a feature flag called `renameElementSymbol` to enable/disable this behavior, with some patching we might be able to recover it for WordPress/Gutenberg.
