## What?

This PR adds the `ValidateControls` components as private APIs. These components wrap the WordPress components adding the validation controls too.

This PR imports https://github.com/Automattic/wp-calypso/pull/100771 changes with small changes:

- fixed ESLint rules
- updated the CSS selectors replacing `a8c` with `components`
- restructure folders following the Gutenberg patterns.


The first commit contains the raw copy from Calypso repo (https://github.com/WordPress/gutenberg/pull/70620/commits/6ac9b6f4c2c53fa8355489c24882c2a5f02f480a)

## Why?
