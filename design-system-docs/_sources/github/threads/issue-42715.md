# Issue #42715: ColorPalette: Allow checkered pattern to show through for semi-transparent colors

- URL: https://github.com/WordPress/gutenberg/issues/42715
- Author: mirka
- Created: 2022-07-26T21:22:43Z
- Updated: 2023-01-27T09:22:32Z
- Comments: 2 of 2

## Body

## What problem does this address?

When a color with a `alpha` channel is selected, the user cannot tell that it is semi-transparent because it basically renders as a solid color.

<img width="581" alt="The checkered transparent background cannot be seen through a translucent red color" src="https://user-images.githubusercontent.com/555336/181067561-2d645f42-808f-4904-9366-32cd19a889bc.png">

(Encountered in #42232)

## What is your proposed solution?

We should look into tweaking the `background` implementation so the checkered background can be seen through a semi-transparent color. This is already the case with the circular swatch.

The current implementation simply _replaces_ the checkered background when a color is selected.
