# Issue #34838: [Components]: MenuItem renders a wrapper with the same class with a child node conditionally

- URL: https://github.com/WordPress/gutenberg/issues/34838
- Author: ntsekouras
- Created: 2021-09-15T08:14:58Z
- Updated: 2025-10-22T05:08:46Z
- Comments: 1 of 1

## Body

While working on some PRs ([like this one](https://github.com/WordPress/gutenberg/pull/34710)) which included working with `MenuItem`, I noticed that if `info` prop is provided we render the components content in a structure that contains the same css class (`components-menu-item__item`) in the main wrapper and in a child node as well.

The code [is here](https://github.com/WordPress/gutenberg/blob/trunk/packages/components/src/menu-item/index.js#L77) and this fragile and problematic (styling, tests, etc..).

This was introduced here: https://github.com/WordPress/gutenberg/pull/25218/files. I'm not sure how impactful this change could be since there could be third party usages which now rely on this..


```
if ( info ) {
	children = (
		<span className="components-menu-item__info-wrapper">
			<span className="components-menu-item__item">{ children }</span>
			<span className="components-menu-item__info">{ info }</span>
		</span>
	);
}
....
return ....
<span className="components-menu-item__item">{ children }</span>
```
