# Issue #54246: RichText Component used inside InspectorControls makes Popover component to have wrong position.

- URL: https://github.com/WordPress/gutenberg/issues/54246
- Author: nkyimas-epignosis
- Created: 2023-09-07T12:06:10Z
- Updated: 2025-05-27T12:33:31Z

## Body

### Description

When `<RichText>` is used inside `<InspectorControls>` then the <Popover> of highlight or link settings are getting the wrong position and are partially hidden below `<InspectorControls>` sidebar.
It seems that it is getting the position from the RichText instead of the block toolbar.



### Step-by-step reproduction instructions

1. Create a custom block with `<RichText />` inside `<InspectorControls />`
2. Try to add a link or highlight part of the text using the block toolbar.

### t-hamano on 2025-05-27T12:33:14Z

URL: https://github.com/WordPress/gutenberg/issues/54246#issuecomment-2912343167

Here's an example of using a `RichText` component in a block's sidebar to adjust the position of the popover:

```jsx
/**
 * WordPress dependencies
 */
import {
	RichText,
	BlockControls,
	useBlockProps,
	InspectorControls,
} from '@wordpress/block-editor';
import { useState } from '@wordpress/element';
import { PanelBody, Fill, Slot, SlotFillProvider } from '@wordpress/components';

export default function Edit() {
	const [ content, setContent ] = useState( '' );
	const blockProps = useBlockProps();
	return (
		<>
			<InspectorControls>
				<SlotFillProvider>
					<PanelBody title="Sidebar rich text">
						<RichText
							style={ { border: '1px solid' } }
							inlineToolbar
							value={ content }
							onChange={ setContent }
							placeholder="Write something…"
						/>
						<Slot name="RichText.Toolbar" />
						<Fill name="RichText.Toolbar">
							<BlockControls />
						</Fill>
					</PanelBody>
				</SlotFillProvider>
			</InspectorControls>
			<div { ...blockProps }>This is a test block</div>
		</>
	);
}
```
