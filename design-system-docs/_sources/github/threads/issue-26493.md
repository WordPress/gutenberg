@talldan I got it. I think the standard size for WP button is either of these:

```
<button type="button" class="button button-primary">Button text</button>
<button type="button" class="button button-secondary">Button text</button>
```

`button`, `input` or `a` with class `button` have the same size - 30px. Maybe they're changed in some special locations, but in general, I think it's 30px.

The Button sizes in the Gutenberg have been considered in great detail (the latest which is #46734). You're right that component sizing has been all over the place (not just buttons), but we're now on the path to more consistency within the ecosystem. If anything, the Gutenberg design system is in the process of "trickling up" into WordPress core, for example with the [Data Views project](https://github.com/WordPress/gutenberg/issues?q=is%3Aissue+is%3Aopen+data+views+label%3A%22%5BFeature%5D+Data+Views%22).

There will continue to be some inconsistencies in the meantime, but we'll get there eventually 🙂
