# Issue #41571: Browser Warning Error when focusing on input field

- URL: https://github.com/WordPress/gutenberg/issues/41571
- Author: t-hamano
- Created: 2022-06-07T05:53:19Z
- Updated: 2023-09-05T04:34:42Z

## Body

### Description

In the block's sidebar control, a warning error appears in the browser console when the input field is focused.
This only occurs in development mode (`npm run dev`).
Furthermore, if the target element is given `touch-action: none,` this error will no longer appear.

I cannot determine if this is a bug that should be fixed, but I am reporting it just in case.

## Message

```
[@use-gesture]: The drag target has its `touch-action` style property set to `auto`. It is recommended to add `touch-action: 'none'` so that the drag gesture behaves correctly on touch-enabled devices. For more information read this: https://use-gesture.netlify.app/docs/extras/#touch-action.

This message will only show in development mode. It won't appear in production. If this is intended, you can ignore it. 
```

### Step-by-step reproduction instructions

- run `npm run dev`.
- Insert one block.
- Open the Developer Tools in your browser.
- Select the inserted block and focus on the input field from the sidebar controls.
- Confirm that a warning error is displayed in the browser console.
