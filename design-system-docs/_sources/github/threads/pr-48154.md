Hmm, this is what I'm seeing, where only the width has been updated. For icon buttons, we need to maintain a square ratio.

Also, we want to change the button sizes in all `__unstable-large` cases — not just icon buttons, but text label buttons as well.

The outer height of the entire component (40px) needs to be maintained, so this probably means we also need to increase the padding between the outer border and the button.

<img width="325" alt="image" src="https://user-images.githubusercontent.com/555336/219577426-914ab0e0-c453-4b08-aff2-c8af4d395dcc.png">
