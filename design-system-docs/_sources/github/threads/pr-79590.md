## Body

## What?

Follow up to #65751

Remove the deprecated `__next40pxDefaultSize` prop from `RangeControl`, making the 40px default size the permanent default.

## Why?

The soft deprecation was introduced in WP 6.7 and scheduled to be removed in WP 7.1. `RangeControl` is a mid-layer control that embeds `NumberControl` and must hard-deprecate before `NumberControl`.

## How?

- Remove `__next40pxDefaultSize` from the `RangeControl` runtime API and remove `maybeWarnDeprecated36pxSize`.
- Keep an optional `@deprecated` + `@ignore` type stub on public types (per #46741).
- Hardcode 40px styling on the root and embedded number input; keep passing `__next40pxDefaultSize` internally to embedded `NumberControl` until that primitive is hard-deprecated.
- Strip monorepo usages on `RangeControl` / `FlexedRangeControl`.
- Remove `RangeControl` from the `components-no-missing-40px-size-prop` ESLint rule and add a restricted-syntax rule for passing the prop to `RangeControl`.

## Testing Instructions

1. Open Storybook to **Components / RangeControl** and smoke test the default story.
2. In the block editor, open a control that uses `RangeControl` (for example **BoxControl** spacing, **Height** control, or **Font size picker** custom size slider) and confirm the slider and number input render at 40px height.
3. Confirm no console warnings are logged for `RangeControl` when interacting with these controls.
