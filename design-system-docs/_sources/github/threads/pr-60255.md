## Body

## What?
Use a unicode arrow symbol rather than the `external` icon in `Externalink`.

## Why?
* The minimised icon looks a little clunky.
* Unicode arrow will always match font appearance
* Aligns with treatment on wp.org

I think the main point of `ExternalLink` is to present `target="_blank"` links in an [accessible](https://www.w3.org/TR/WCAG20-TECHS/H83.html) way, which is to hint that it opens in a new tab to both non-sighted _and_ sighted users. So I'm not sure it makes sense to add an option to remove the visual hint in the ExternalLink component itself. We wouldn't want people to abuse that, when they might not understand the full implications. I don't feel super strongly about it so I could be persuaded otherwise, but that is my initial impression.

If you're sure about the accessibility implications of not showing an arrow in a specific use case context (like if you're sure there are enough context clues that it would open in a new tab), it might be better to just roll your own `<a>` tag or use `Button` as a link?
