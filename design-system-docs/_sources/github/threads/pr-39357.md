## Body

Part of #35665
In preparation for #38720

## What?

Reworks the Storybook stories for `RangeControl` to use Controls instead of Knobs.

### Notable changes

- Added descriptions to stories that weren't obvious what the point was
- Some simplification of story-specific props (e.g. labels, initial values) that were unrelated to the point being demonstrated
- Removed the `Multiple` story (I don't think it currently has a clear purpose)
- Removed the padded wrapper element (Unneeded)

## Why?

Better docs, and easier composition of stories.

## Testing Instructions

`npm run storybook:dev` and see the Docs tab for the `RangeControl` component. The reworked stories should be understandable, and capture the intent of the [original stories](https://wordpress.github.io/gutenberg/?path=/docs/components-rangecontrol--default).
