# Issue #27405: ComboboxControl: Prevent zoom on Mobile Safari

- URL: https://github.com/WordPress/gutenberg/issues/27405
- Author: mirka
- Created: 2020-12-01T17:06:31Z
- Updated: 2020-12-04T14:42:52Z
- Comments: 0 of 0

## Body

**Describe the bug**

`ComboboxControl` has a font-size smaller than 16px, so Safari on iPhone will zoom in when the input field is focused.

**To reproduce**
Steps to reproduce the behavior:

1. Open Safari on an iPhone or in iOS Simulator.
1. Go to the [Storybook page](https://wordpress.github.io/gutenberg/?path=/story/components-comboboxcontrol--default) for the ComboboxControl component.
2. Click on the input field.
3. The browser will zoom in.

**Expected behavior**

The browser doesn't zoom in.

**Editor version (please complete the following information):**

Doesn't happen in the editor, just the standalone component.

**Smartphone (please complete the following information):**
 - Device: iPhone 11 Pro
 - OS: 14.2

**Additional context**

The component itself should have a responsive font-size to prevent this, like the `InputControl` component:

https://github.com/WordPress/gutenberg/blob/50566948c815ba5381a28cc0c86d63eb2f8d3f94/packages/components/src/input-control/styles/input-control-styles.js#L107-L112
