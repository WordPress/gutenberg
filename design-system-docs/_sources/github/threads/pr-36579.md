## Description
<!-- Please describe what you have changed or added -->

Following up some feedback from #36302, This PR brings a bunch of improvements to the `Divider` components:

- Added styles for the `vertical` orientation
- Replaced `marginTop` and `marginBottom` props with `marginStart` and `marginEnd` (which are a better abstraction regardless of the orientation). Added RTL support in the process
- Rewrote Storybook examples to feature both Horizontal and Vertical case scenarios
- Removed the `border-color` override to black from Storybook, and changed the default `Divider`'s `border-color` to be `currentColor`
- Fixed/updated documentation
- Added a CHANGELOG entry
