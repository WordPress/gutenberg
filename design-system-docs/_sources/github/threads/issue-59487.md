# Issue #59487: Unnatural focus outline style in Firefox browser

- URL: https://github.com/WordPress/gutenberg/issues/59487

- Created: 2024-03-01T01:46:15Z
- Updated: 2026-04-25T09:06:50Z

## Body

### Description

Many form components have a focus outline applied to them using the `box-shadow` style, as shown below.

```
box-shadow: 0 0 0 calc(1.5px - 1px) var(--wp-components-color-accent, var(--wp-admin-theme-color, #3858e9));
```

It seems that this focus outline may look unnatural in the Firefox browser. Specifically, the outline on the right side and bottom side looks slightly thicker.

My guess is that this problem occurs when the fourth value of `box-shadow`, i.e. `<spread-radius>`, is a decimal value.

This problem may depend on the OS and display settings, so I would appreciate it if you could test to see if you can reproduce this problem.

### Step-by-step reproduction instructions

- Access [Storybook](https://wordpress.github.io/gutenberg/?path=/docs/docs-introduction--page) using the Firefox browser
- Access the story of a focusable component such as a TextControl.
- Move focus to the component.
