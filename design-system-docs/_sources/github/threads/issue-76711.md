# Issue #76711: Button: focus outline style is not displayed in Windows High Contrast mode

- URL: https://github.com/WordPress/gutenberg/issues/76711
- Author: t-hamano
- Created: 2026-03-20T03:27:18Z
- Updated: 2026-03-23T14:10:14Z
- Comments: 2 of 2

## Body

In Windows High Contrast mode, button focus styles are achieved using outlines. However, due to the reduced CSS specificity of focus styles (#75346), focus outlines no longer visually change in Windows High Contrast mode.

### ✅ Before

```css
// Specificity: 0-3-0
.components-button:focus:not(:active){
	// Windows High Contrast mode will show this outline, but not the box-shadow.
	outline: 3px solid transparent;
}

// Specificity: 0-2-0
.components-button.is-primary,
.components-button.is-secondary,
.components-button.is-tertiary {
	outline: 1px solid transparent;
}
```

## ❌ After

```css
// Specificity: 0-2-0
.components-button.is-primary,
.components-button.is-secondary,
.components-button.is-tertiary {
	outline: 1px solid transparent;
}

// Specificity: 0-2-0
.components-button:focus {
	// Windows High Contrast mode will show this outline, but not the box-shadow.
	outline: 3px solid transparent;
}

```
