# Issue #60836: BaseControl: Support accessible, flexible layouts

- URL: https://github.com/WordPress/gutenberg/issues/60836
- Author: mirka
- Created: 2024-04-17T18:47:09Z
- Updated: 2026-04-16T14:51:28Z
- Comments: 4 of 4

## Body

## What problem does this address?

We are running into [issues](https://github.com/WordPress/gutenberg/pull/60787) where we want to tweak the layout of the `help` text, or reuse just the styles of the help text. Currently, it requires CSS overrides of BaseControl internals, or copy-pasting styles.

## What is your proposed solution?

For example, export a `BaseControl.VisualHelp` like we do with `BaseControl.VisualLabel`. This must be accompanied by clear accessibility guidance in the docs. This is just a potential solution, there may be better solutions.

### ciampo on 2024-07-23T17:14:24Z

URL: https://github.com/WordPress/gutenberg/issues/60836#issuecomment-2245801019

Couple more feedback items:

- `StyledHelp` comes with a top margin, which makes it less easy to drop in other components. We should ideally move spacing between components to dedicated grid/flex parents, instead of using margin
- `BaseControl` should be more flexible about allowing consumers to read/write IDs used to label/describe inputs ([comment](https://github.com/WordPress/gutenberg/pull/63751#discussion_r1688429377))
