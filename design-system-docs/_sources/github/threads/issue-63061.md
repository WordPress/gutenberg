# Issue #63061: RangeControl: Reset button isn't disabled when expected

- URL: https://github.com/WordPress/gutenberg/issues/63061
- Author: mirka
- Created: 2024-07-02T14:51:56Z
- Updated: 2024-08-19T07:39:33Z
- Comments: 0 of 0

## Body

The reset button when `allowReset={ true }` is not disabled when the value cannot be reset anymore.

For example in [this story](http://localhost:50240/?path=/story/components-rangecontrol--default), with `initialPosition={ 50 }`:

https://github.com/WordPress/gutenberg/assets/555336/dab657f9-a757-4ca4-8e25-b04bc6ff292b

The disable logic looks wrong, because `value` is `number | null` and will never be `undefined`:

https://github.com/WordPress/gutenberg/blob/c56aa97858f9c5fe5caead3e20f5bf3f55000475/packages/components/src/range-control/index.tsx#L329

There should probably be some consolidation with the `handleOnReset` logic, so that the reset button will be disabled when the `resetValue` is `null`:

https://github.com/WordPress/gutenberg/blob/c56aa97858f9c5fe5caead3e20f5bf3f55000475/packages/components/src/range-control/index.tsx#L168-L173
