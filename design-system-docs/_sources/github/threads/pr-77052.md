## What

Updates the paragraph block slash inserter behavior in constrained block contexts.

The paragraph placeholder remains **“Type / to choose a block”**, but when no replacement blocks are available in the current context, typing `/` now opens the slash inserter with an inline empty-state message:

> No other blocks are available here

https://github.com/user-attachments/assets/156ccb2d-887b-4d08-9ad4-fd32493f1da1


The empty state uses the default block icon so it visually matches the slash inserter list.

## Why

The previous approach tried to make the paragraph placeholder context-aware, but that required additional block editor store subscriptions and caused typing performance regressions.

This approach avoids adding subscriptions to the paragraph block or block list rendering path. It keeps the placeholder stable and makes the slash inserter outcome accurate when the user actually invokes it.

## How

- Extends autocomplete `useItems` results to optionally include a no-results message.
- Allows autocomplete to render that message when a completer has zero items.
- Keeps regular no-results behavior unchanged for filtered searches.
- Updates the block slash completer to return **“No other blocks are available here”** only when the current block has no replacement block types available.
- Allows `Escape` to close the autocomplete popover even when there are zero selectable options.






## Testing Instructions

### Basic regression: default editor

1. Create a new post.
2. Add or select an empty Paragraph block.
3. Confirm the placeholder reads **“Type / to choose a block”**.
4. Type `/`.
5. Confirm the slash inserter opens with normal block options.
6. Confirm selecting a block replaces the paragraph as expected.

### Content-only Group: no other blocks available

1. Create a new post.
2. Insert this HTML into the editor:

```html
<!-- wp:group {"templateLock":"contentOnly"} -->
<div class="wp-block-group">
<!-- wp:paragraph -->
<p></p>
<!-- /wp:paragraph -->
</div>
<!-- /wp:group -->
```

3. Click into the empty Paragraph inside the Group.
4. Confirm the placeholder still reads **“Type / to choose a block”**.
5. Type `/`.
6. Confirm the slash inserter opens and shows **“No other blocks are available here”** with the default block icon.
7. Press `Escape`.
8. Confirm the slash inserter closes.

### Allowed blocks restricted to Paragraph only

1. Insert a Group block.
2. In the block inspector, open **Advanced → Manage allowed blocks**.
3. Deselect everything except **Paragraph**.
4. Insert or select an empty Paragraph inside the Group.
5. Confirm the placeholder reads **“Type / to choose a block”**.
6. Type `/`.
7. Confirm the slash inserter opens and shows **“No other blocks are available here”**.

### Allowed blocks restricted to another block

1. Insert a Group block.
2. In **Advanced → Manage allowed blocks**, allow a non-paragraph block such as **Quote** and disallow Paragraph.
3. Insert or select an empty Paragraph inside the Group.
4. Type `/`.
5. Confirm the slash inserter shows the allowed replacement block.
6. Confirm selecting it replaces the Paragraph.

### Content block containers still offer replacements

1. Insert a Quote block.
2. Click into an inner Paragraph or citation and create/select an empty Paragraph.
3. Confirm the placeholder reads **“Type / to choose a block”**.
4. Type `/`.
5. Confirm the slash inserter opens with relevant block options.
6. Repeat with a Cover block containing inner content.
