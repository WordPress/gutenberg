# Issue #21459: CustomSelectControl: currently selected value is not presented to screen readers

- URL: https://github.com/WordPress/gutenberg/issues/21459
- Author: Aljullu
- Created: 2020-04-07T13:50:18Z
- Updated: 2022-03-09T09:18:45Z
- Comments: 1 of 1

## Body

**Describe the bug**
The `CustomSelectControl` component doesn't read the currently selected value when it's focused.

**To reproduce**
1. Edit a post and select a paragraph block.
2. With a screen reader navigate the block _Typography_ panel in the sidebar.
3. Focus the _Preset Size_ select.
4. Notice the currently selected option is not presented to the user.

**Expected behavior**
When focusing the select, I would expect the currently selected value to be read by the screen reader. Like it's done for other form elements.

**Desktop (please complete the following information):**
Tested in two devices:

**Device 1**
 - OS: Fedora Linux
 - Browser: Firefox
 - Screen reader: Orca

**Device 2**
 - OS: Windows
 - Browser: Chrome
 - Screen reader: Narrator
