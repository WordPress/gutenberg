## Body

Related to #76950

## What?

This PR adds `Autocomplete.Group` and `Autocomplete.GroupLabel` subcomponents.

## Why?

The command palette depends on the external library `cmdk`, but there are several a11y bugs that have not been resolved upstream. To address these issues, we need to refactor it entirely with the `Autocomplete` component. However, first, we need to support the grouping of list items. Grouping should also be beneficial for the `Autocomplete` component itself.


## How?

- Simply export the equivalent components from BaseUI.
- The minimum style is applied. The group label text is uppercase, and there is a slight margin between each group. This style could be improved.
