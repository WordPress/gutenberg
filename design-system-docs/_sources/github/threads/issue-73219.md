## Body

### Description

In the **Guide** component, the close button becomes invisible when hovered. It changes to white, blending into the white background.

### Step-by-step reproduction instructions

1. Visit https://wordpress.github.io/gutenberg/?path=/docs/components-guide--docs
2. Click `Open Guide` Button
3. Hover over the Close (×) button in the top-right corner
4. Observe: The button disappears because it becomes white

> It appears that the current hover color is tailored for the welcome modals used in the core. Proposed fix from [#73220](https://github.com/WordPress/gutenberg/pull/73220) will introduce a bug for them.
> 
> Maybe the Guide component shouldn't have this hover effect by default and make it sepecific for welcome modals.

You are right. I found that the Guide component is used inside four different welcome-guide components : edit-site, edit-post, editor, and edit-widgets.

These welcome guides have a blue background with images, and the close button hover color was white to look good there.

But since Guide is shared, that white hover color made it look inconsistent in other places where the background isn’t blue.

To fix this, I updated the #73220 and I removed the hover effect from the Guide component and added it directly to the welcome-guide components instead.

Now, Guide stays clean and generic, and each component that uses it can set its own hover style when needed.
