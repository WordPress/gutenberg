# Issue #63420: ComboboxControl: Increase the size of the Reset button

## Body

### Description

A farily new design pattern in the editor places buttons in a way that they _visually_ appear within a related input field. Examples of this pattern can be seen, for example, in the LinkControl and in the Post URL setting popover. Screenshot:

![linkcontrol](https://github.com/WordPress/gutenberg/assets/1682452/38ff9d72-9549-427e-9266-ef89fab65013)

![post url popover](https://github.com/WordPress/gutenberg/assets/1682452/494a70ff-5f0d-422d-a2c9-eb83fce8a69e)

As an accessibility specialist, I'm not sure I'd support this pattern because the visual appearance of a button _inside an input field_ is somehow unexpected and disorienting.

Regardless, this pattern should at least be consistent.

Turns out the ComboboxControl does have an optional `Reset` button. Its size is way smaller and it's pretty inconsistent.

Also, a control target size should be as large as possible. This one is too small. Screenshot:

![reset](https://github.com/WordPress/gutenberg/assets/1682452/011b0b63-2830-4bca-9e87-810184d45c2b)


### Step-by-step reproduction instructions

- Edit a page and click the Parent setting in the Inspector post panel.
- Alternatively, test on the storybook. Make sure the `allowReset` prop is set to `true`: https://wordpress.github.io/gutenberg/?path=/story/components-comboboxcontrol--default&args=allowReset:!true
- Choose a suggestion to make the Reset button enabled.
- Move focus to the button to visually see its size.
- Observe the button size is smaller than the one of other similar buttons.

### afercia on 2025-02-10T08:58:07Z

URL: https://github.com/WordPress/gutenberg/issues/63420#issuecomment-2647331174

@SainathPoojary thanks for pointing that out. Yes I do see that in WordPress 6.7 many inputs with buttons inside have changed and now the buttons have a smaller size. So this appears to be a broader issue now and not limited to the combobox. I guess this new smaller size came from some design input.

However, I'm not sure I understand how intentionally _reducing_ the target size of interactive controls makes the user experience more usable and accessible.

Rather, I would say that whenever possible the target size should be _increased_.

While the new size of 24 by 24 pixels is compliant with [the minimum requirement](https://www.w3.org/TR/WCAG22/#target-size-minimum), WordPress should aim to provide _something better than the minimum_.

I would appreciate feedback from @WordPress/gutenberg-design . Can anyone explain why these buttons size was reduced to 24 by 24 and if there's any specific discussion about this change? Thanks,.
