# Issue #71259: Generate branch-specific Storybook preview sites

## Body

## What problem does this address?

Reviewing pull request changes that affect components usually requires someone to have a local development environment for Gutenberg, which is a barrier to entry, particularly for non-technical contributors. [WordPress Playground Gutenberg PR Reviewer](https://playground.wordpress.net/gutenberg.html) (and [gutenberg.run](https://github.com/WordPress/gutenberg.run) before it) help mitigate this for Gutenberg integration in WordPress, but there's no equivalent for [the Gutenberg Storybook site](https://wordpress.github.io/gutenberg/?path=/docs/docs-introduction--page). Storybook can be especially useful for easily previewing various states of UI components, and a preview environment can reduce the feedback loop between developers, designers, and other contributors.

## What is your proposed solution?

- For each pull request, publish a preview environment for Storybook including those changes, publicly accessible at a URL
- Ideally this is integrated with the pull request itself (e.g. triggered automatically when a pull request is opened, and automatic comments on the pull request with a link to the preview environment)

## Background

Related issues:

- #22155
- #26184
- #28477

A service like [Chromatic](https://www.chromatic.com/) has been discussed in the past at #22155. The service is operated by the maintainers of Storybook, includes [pull request workflows](https://www.chromatic.com/docs/in-pull-request/), offers [open source sponsorships](https://www.chromatic.com/docs/open-source/#open-source-sponsorships), and could be used in the future for other component testing solutions.

Alternatively, we may be able to extend the existing GitHub Pages workflow that we use for the [current Storybook site built from `trunk`](https://wordpress.github.io/gutenberg/?path=/story/components-flex--default) to build for each pull request branch. An approach like this was used in the WordPress/openverse-frontend project: https://github.com/WordPress/openverse-frontend/pull/1334#top
