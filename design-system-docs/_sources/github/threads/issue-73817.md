# Issue #73817: The color palette in the color settings panel is not scrollable in WordPress 6.9

- URL: https://github.com/WordPress/gutenberg/issues/73817
- Author: inc2734
- Created: 2025-12-08T12:32:16Z
- Updated: 2025-12-11T11:13:12Z
- Comments: 0 of 0

## Body

### Description

If your color palette contains so many colors that you need to scroll, you will not be able to select all of the colors in WordPress 6.9 because you cannot scroll.

The color palette in "Block Toolbar → Highlight" scrolls correctly.

### Step-by-step reproduction instructions

1. Register many colors in the Global Styles.
2. Select a paragraph block and open the color palette in the Color Settings panel.
3. Scroll through the color palette.
