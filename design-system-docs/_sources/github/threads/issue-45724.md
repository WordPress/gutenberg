# Issue #45724: Button component with set variant doesn't wrap text

- URL: https://github.com/WordPress/gutenberg/issues/45724
- Author: monsieur-z
- Created: 2022-11-11T17:01:34Z
- Updated: 2023-07-26T15:13:29Z

## Body

### Description

When set as primary, secondary, or tertiary (via the `variant` prop), the [Button](https://github.com/WordPress/gutenberg/tree/trunk/packages/components/src/button) component doesn't wrap text on a new line when there's not enough space to display the full label.

This looks like a conscious decision, given [the component styles](https://github.com/WordPress/gutenberg/blob/trunk/packages/components/src/button/style.scss#L45). However that seems like an odd default behaviour to me, since cutting text causes accessibility issues. I also don't think that's an edge case: I'd assume that on a 320px wide screen and in German (which has longer words than English), labels would be cut fairly often.

### Step-by-step reproduction instructions

1. Visit the [component's page in Storybook](https://wordpress.github.io/gutenberg/?path=/story/components-button--default)
2. With the _Canvas_ tab selected, change the size of the preview to _Small mobile_
3. With the help of the _Controls_ panel below, set the component `variant` prop to `primary`
4. In the same panel, update the content of the `children` prop until you see the text being cut in the preview
