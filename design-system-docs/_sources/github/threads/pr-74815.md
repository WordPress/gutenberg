## What?

Adds basic usage guidance for components in `@wordpress/components`, which can be referenced by humans in Storybook, and by coding agents through the AGENTS.md file.

## Why?

We are in a transitionary phase where it isn't always clear which component should be used instead of a newer or different version. This PR adds a way to add up-to-date usage guidance for each component, which can be referred to by both humans and coding agents.

Once `@wordpress/ui` is more fleshed out, we will facilitate the transition process with lint rules as well.

## How?

Adds metadata to the Storybook file for each component, which is the source of truth. This metadata is referenced by a status indicator on the Storybook docs pages, as well as by coding agents through a AGENTS.md file.

## Testing Instructions

See `@wordpress/components` pages on Storybook.
