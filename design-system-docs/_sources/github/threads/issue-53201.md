# Issue #53201: Prevent snackbars from stacking up by adding a max count

- URL: https://github.com/WordPress/gutenberg/issues/53201

## Body

Snackbars should have a max count, where you can't end up with a stack of them hanging around. https://github.com/WordPress/gutenberg/issues/53200 will reduce the number, but there should be a max. Even as small as three notice max may work just fine.
