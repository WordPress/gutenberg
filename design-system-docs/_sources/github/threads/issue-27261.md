# Issue #27261: RangeControl's tooltip overlaps label

- URL: https://github.com/WordPress/gutenberg/issues/27261
- Author: talldan
- Created: 2020-11-25T08:55:13Z
- Updated: 2021-10-16T00:02:32Z
- Comments: 5 of 5

## Body

**Describe the bug**
When `RangeControl` has a visible label, the tooltip from the slider overlaps the label.

**To reproduce**
Steps to reproduce the behavior:
1. Add an image to an image block
2. Select the crop option
3. Select the zoom option
4. Observe the tooltip overlaps the label.

**Expected behavior**
The tooltip is below the slider
