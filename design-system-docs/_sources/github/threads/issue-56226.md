# Issue #56226: Expose onBlur in ComboboxControl

- URL: https://github.com/WordPress/gutenberg/issues/56226
- Author: drazenbebic
- Created: 2023-11-16T19:32:25Z
- Updated: 2023-12-15T12:29:53Z
- Comments: 0 of 0

## Body

## What problem does this address?

While trying to write a combobox component which dynamically loads data via an AJAX request, I found the need to reset pagination variables when the combobox popover is closed, so that I know when the user started a new search. I found no way of doing this with the `ComboboxControl` in its current state. 

## What is your proposed solution?

Expose the `onBlur` prop. I saw that `ComboboxControl` uses a `TokenInput` component, which already has an `onBlur` event. This means that the `ComboboxControl` needs an additional `onBlur` property which is called within the `onBlur` handler of the `TokenInput` component.
