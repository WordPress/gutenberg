## Body

### Description

The `Button` component uses `uniqueId()` for the `aria-describedby` attribute to point to a `VisuallyHidden` element with that ID.

`uniqueId()` produces numeric IDs, however, IDs in HTML must not start with a number.

`uniqueId()` should be used with a prefix (or perhaps replaced by `uuid`) and ideally be memoized so it doesn't change on every render.

https://github.com/WordPress/gutenberg/blob/5cca2e1a8021679aaf2fc713c1a2c1cce168c374/packages/components/src/button/index.js#L142-L145

https://github.com/WordPress/gutenberg/blob/69e348ec80dc2cb9d537a8ba3cf6774b48636461/packages/block-editor/src/components/block-switcher/index.js#L167

### Step-by-step reproduction instructions

Render the `Button` component yourself or observe the wrong ID in the block switcher.
