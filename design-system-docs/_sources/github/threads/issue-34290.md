# Issue #34290: Components: delete the `createComponent` function

- Author: ciampo

- Updated: 2021-09-22T07:55:34Z

## Body

## Why

The [`createComponent()` function](https://github.com/WordPress/gutenberg/blob/trunk/packages/components/src/ui/utils/create-component.tsx#L38) represents an unnecessary abstraction, which makes the code harder to read.

## What

We should delete the `createComponent` function and replace its usages with explicit calls to:

- using the component's hook
- rendering the component as a `<View />`
- setting the `displayName` static prop
- calling the `contextConnect` function
