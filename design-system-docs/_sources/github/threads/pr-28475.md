@saramarcondes Thank you for working on this one 🙏 !!

I gave it some thought. I think we should just replace the current (web) `Text` component with the one from G2 Components, rather than using the `next` adapter.

Fortunately, the (current) `Text` is under `experiment` and it isn't used in a lot of places.

I poked around, and these seem to be the only places it's being used so far:

* packages/components/src/input-control/styles/input-control-styles.js
* packages/components/src/navigation/styles/navigation-styles.js
* packages/components/src/resizable-box/resize-tooltip/styles/resize-tooltip.styles.js
* packages/edit-site/src/components/template-details/index.js

I vote that we use it directly 👍
That'll allow us to remove a lot of code. I'm not even sure if we need to preserve the previous `variant` API.
The G2 `Text` has that built in as part of it's `size` style.

Let me know what you think!
