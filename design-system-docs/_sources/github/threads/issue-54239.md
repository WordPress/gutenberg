# Issue #54239: Allow `CircularOptionPicker` to work as a non-listbox

## Body

### Description

Work was recently done (#35292) to improve the keyboard navigation of [the `ColorPalette` component](https://wordpress.github.io/gutenberg/?path=/story/components-colorpalette--default) (and related) by changing [the underlying `CircularOptionPicker`](https://wordpress.github.io/gutenberg/?path=/docs/components-circularoptionpicker--docs) to a single-tabstop listbox (#52255).

While this works well for the `ColorPalette` usage identified in #35292, there are areas of the admin interface where this is undesired behaviour, and `CircularOptionPicker` should remain as multiple buttons, each as their own tab stop.

### Step-by-step reproduction instructions

This can be seen, for example, by:
 1. open Site Editor
 2. open Global styles sidebar
 3. Navigate to the "Colors" panel
 4. Navigate to the "Palette" subpanel

The swatches under both the "Solid" and "Gradient" tabs will present as a single tab stop, semantically as "listbox options". They should still be regular buttons.
