## Body

Migrates the `AlignmentMatrixControl` styles from Emotion to a `style.module.css` file. If we managed to do this for all 35 Emotion components, we could remove Emotion completely, including our build process which now must run Babel just for the `@emotion/babel-plugin` and nothing else.

There are still some open questions on this PR, see the review comments. If we sort them out, we can write a more precise prompt that could do the entire migration very quickly.
