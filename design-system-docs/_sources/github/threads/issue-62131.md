# Issue #62131: Typography: Font size dropdown control interferes with dimension controls

- URL: https://github.com/WordPress/gutenberg/issues/62131
- Author: webmandesign
- Created: 2024-05-30T08:46:36Z
- Updated: 2024-05-30T14:08:11Z
- Comments: 2 of 2

## Body

### Description

When a theme declares a number of font sizes so the font size control is displayed as a dropdown,
and dimension controls (padding, margin) are visible in block editor sidebar,
the font size dropdown list interferes with dimension controls (CSS `z-index`, positioning issue).

### Step-by-step reproduction instructions

1. Add a new font size to Twenty Twenty-Four theme's `theme.json`. This will cause font size control in block editor to display as a dropdown.
2. In block editor enable dimension controls for a block.
3. When dimension controls are displayed, try to select a font size from the dropdown. You can see the dropdown list covered by the dimension controls.
