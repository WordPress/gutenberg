## Body

This PR addresses https://github.com/WordPress/gutenberg/pull/32926#discussion_r657969720.

Instead of manually setting `popoverProps={ { isAlternate: true } }` every time we use `ToolbarDropdownMenu`, the component should do that automatically.

There's also a minor refactor on the component so the toggle props are properly merged with the internal `ToolbarItem` props (by passing the toggle props to the `ToolbarItem` component, and not directly to the `DropdownMenu` component). This may avoid future issues.
