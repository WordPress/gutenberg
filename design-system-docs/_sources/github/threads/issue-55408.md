# Issue #55408: Tooltip: Unstable display in the iframed editor

- URL: https://github.com/WordPress/gutenberg/issues/55408

- Created: 2023-10-17T11:52:08Z
- Updated: 2025-04-30T14:15:00Z

## Body

### Description

This problem cannot be reproduced reliably, but when the `Tooltip` component is used in an iframed editor, there seem to be cases where a quick mouse action does not display the Tooltip.

> **Note**
> In WordPress 6.4 RC1 without the latest Gutenberg enabled, the issue is a little different. This issue is reported in #55448.

### Step-by-step reproduction instructions

- To render the editor as an iframe, if custom field settings are enabled, disable them from the preferences menu.
- Insert a group block or column block. These blocks have variation buttons with the tooltip.
- Hover the mouse over any variation. Mouse out slightly from that variation and then quickly mouse in again.
- There may be times when the tooltip is not displayed.
- Similarly, quickly hover your mouse from one variation to another.
