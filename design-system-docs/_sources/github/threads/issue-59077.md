# Issue #59077: DropdownMenu V2: Chevron icon position and orientation are incorrect when submenu is flipped

- URL: https://github.com/WordPress/gutenberg/issues/59077
- Author: t-hamano
- Created: 2024-02-15T14:00:10Z
- Updated: 2024-02-16T01:13:17Z
- Comments: 3 of 3

## Body

### Description

My understanding is that when a DropdownMenu V2 component has a submenu, a chevron icon is displayed to the right of the text. This icon should expect the submenu to expand to the right, as the chevron icon indicates.

![image](https://github.com/WordPress/gutenberg/assets/54422211/04468692-f3ea-4add-889e-efa2f248cb8a)

However, if this component is located at the right edge of the screen, the chevron icon will still point to the right, even though the submenu will appear on the left.

![image](https://github.com/WordPress/gutenberg/assets/54422211/dabbf3f9-a846-4977-bb81-07d89a41f8d9)

I may not call this a bug, but I would expect that when the submenu expands to the left, the chevron icon points to the left and appears to the left of the text.

### Step-by-step reproduction instructions

- Access the all template list page in the site editor.
- Click the "View options" icon at the top right of the data view to expand the submenu.

### mirka on 2024-02-15T16:12:07Z

URL: https://github.com/WordPress/gutenberg/issues/59077#issuecomment-1946439467

Do you know any reference designs that do this? For example, nested submenus on macOS do not do chevron flipping according to popover placement (I'm sure they do it for RTL languages though).

From a UX standpoint, I'm afraid it might be more confusing because popover placement can be quite dynamic. If you imagine a somewhat narrow viewport, it would only take two nested levels for the popover placement to flip back. Then you'd have two different chevron placements in a single menu tree for something that is functionally the same. Or you could run into cases where a chevron for the next level submenu is pointing right back at the parent's chevron.
