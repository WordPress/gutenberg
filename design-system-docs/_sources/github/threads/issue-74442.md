# Issue #74442: Faster motion effect in submenus inside popover-like components

- URL: https://github.com/WordPress/gutenberg/issues/74442
- Author: fcoveram
- Created: 2026-01-08T09:25:01Z
- Updated: 2026-01-13T15:31:58Z
- Comments: 3 of 3

## Body

Based on #74079 

## What problem does this address?

The new motion effect implemented in #74079 looks great, but when showing popovers that exist inside the main one, the interaction could feel slightly slower.

https://github.com/user-attachments/assets/0d4050eb-bf7f-4f06-ab04-07de8d33715c

This is not a problem per se, but a personal observation in comparison with other similar situations. Here are three examples where subpopovers feel quicker compared to the main one.

**MacOS**

https://github.com/user-attachments/assets/88336ffa-7299-4806-8cef-cfdbdf6bc601

**Slack**

https://github.com/user-attachments/assets/1cdcf379-e9c4-4766-bd99-93f64e51eac6

**Figma**

https://github.com/user-attachments/assets/3763ee12-49d5-4c87-89e6-1c8ecdfb99e8

## What is your proposed solution?

As per the examples added above, I propose reducing the animation duration to `0` and removing the motion effect and travel distance. Basically, to look similar to Figma.

In a chat with @mirka, she told me how [tooltips](https://wordpress.github.io/gutenberg/?path=/story/components-togglegroupcontrol--with-tooltip) behave similarly, so the interaction would feel consistent.

What do you think of this? Tagging @WordPress/gutenberg-design for direct pings.
