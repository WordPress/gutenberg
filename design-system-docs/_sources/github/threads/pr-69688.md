You could pass props to the story by doing this in the decorator:

```
( Story, context ) => {
	// ...
	const newContext = {
		...context,
		args: {
			...context.args,
			anchor: buttonRef.current,
			onClose: () => {
				context.args.onClose?.();
				handleClose();
			},
			onFocusOutside: ( e: SyntheticEvent ) => {
				context.args.onFocusOutside?.( e );
				handleFocusOutside();
			},
		},
	};
	// ...
	{ isVisible && <Story { ...newContext } /> }
```

But to be honest, we may as well just write this directly in the `render` function, instead that under `decorators`

(cc @mirka as I actually learned it today what `context` can be used to pass props in decorators)
