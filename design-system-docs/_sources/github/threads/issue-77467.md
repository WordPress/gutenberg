## Body

### Description

The CollapsibleCard has an interactive header, and when it receives focus, a focus ring appears on the visual button.

<img width="608" height="212" alt="Image" src="https://github.com/user-attachments/assets/685c6b6c-dbf4-4bdc-af35-c687c3d03f8c" />

However, the WordPress core applies `outline: none` to the `div` element, so the focus ring is not displayed:

<img width="922" height="338" alt="Image" src="https://github.com/user-attachments/assets/303e278a-c08c-4842-8722-49ca93e8a0ef" />

### Step-by-step reproduction instructions

- Access the following URL: http://localhost:50240/?path=/docs/design-system-components-collapsiblecard--docs&globals=css:wordpress
- In this story, WordPress-derived CSS is enabled.
- Press the Tab key on your keyboard to focus on the header. There are no visual changes.
