## Body

After implementing a dedicated `Listbox` component (https://github.com/WordPress/gutenberg/issues/65801) it would be good to update `ComboboxControl` to make use of it. 

There are some other tweaks we might also consider:

1. Render the listbox in a floating popover rather than pushing subsequent content down.
2. Create a version the renders the input and listbox together in a popover/dropdown. This will be useful in data views filters.
