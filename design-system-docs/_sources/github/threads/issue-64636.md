# Issue #64636: Update the `Notice` component to match the new design

- Created: 2024-08-20T09:28:37Z
- Updated: 2024-08-20T09:28:38Z

## Body

We have a new design for the [Notice component](https://wordpress.github.io/gutenberg/?path=/docs/components-notice--docs) that comes with an updated appearance and new styles and customization options.

<img width="630" alt="image" src="https://github.com/user-attachments/assets/e784cdb7-21d9-43e5-90c3-dd140aa8129b">

The new component has several styles and props.

## Styles

**Neutral**
Used for displaying information that is supplemental or separate from a task, like sharing feedback.

![Neutral](https://github.com/user-attachments/assets/18d6130b-231f-41db-b938-1a946dcce4cb)

**Informational**
Used for displaying information that can be helpful, but isn't necessary to complete a task, like visiting documentation. Currently: `info`

![Info](https://github.com/user-attachments/assets/f5adef50-cfcc-4417-9571-378cb15d5419)

**Alert**
Used for displaying information that may be important to the user's current task, like restoring an auto-saved version of the currently edited item. Currently: `warning`

![Alert](https://github.com/user-attachments/assets/f2dba935-ac08-417a-9ddb-11a70af85ae8)

**Error**
Used for displaying error messages and information that may result in breakage, interruption, or data loss. Error messages should be actionable if possible. Currently: `error`

![Error](https://github.com/user-attachments/assets/370e7959-30e4-4b1a-b899-2004641ab8b2)

**Success**
Used for displaying successful status messages, like completing a database update or a background process. Currently: `success`

![Success](https://github.com/user-attachments/assets/8b53329d-e6a5-4fbd-a916-6749f6b26c5f)

## Props

The new notice component comes with several props.

- **Actions**: Enables or disables action buttons.
- **Icon**: Enables or disables an icon (uses the [icon component](https://wordpress.github.io/gutenberg/?path=/docs/components-icon--docs)).
- **Title**: Enables or disables a title displayed above the notice content.
