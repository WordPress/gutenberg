## Body

Part of #39397

## What?

Adds an internal `__next36pxDefaultSize` feature flag prop to introduce the larger default size for `CustomSelectControl`.

## Why?

In preparation for standardizing the default sizes to 36px height.

## How?

Following the procedure outlined in #39397, conditional styles have been added to enlarge the height and paddings. The font size is also enlarged to be consistent with `SelectControl`.

The inconsistent chevron (#39400) will be addressed separately.

@jasmussen How do the paddings feel?

## Testing Instructions

1. `npm run storybook:dev` and see the stories for `CustomSelectControl`.
2. From the Controls tab, toggle the `__next36pxDefaultSize` prop.
