## What?
Updates the label of the center cell of an `AlignmentMatrixControl` from `Center Center` to just `Center`

## Why?
Internally, we refer to the center cell as `center center`. [When `center` is passed, it gets converted to `center center`](https://github.com/WordPress/gutenberg/blob/02562313b414ba202b0604b9e394ee4cf0dee1bd/packages/components/src/alignment-matrix-control/utils.tsx#L40), but that level of specificity isn't as relevant from an end-user's point of view.

For the label, `Center` is more concise, and better matches how a user would likely describe that cell.

## How?
Updating the strings for both `center` and `center center` alignments in the `AlignmentLabel` record.

## Testing Instructions
<!-- Please include step by step instructions on how to test this PR. -->

### Testing Instructions for Keyboard
In Storybook, focus on the canvas and press `Tab` once to focus on the control. This should display the current label in a tooltip. Use the arrow keys to change the currently selected cell, navigating away from and then back to `Center`.
