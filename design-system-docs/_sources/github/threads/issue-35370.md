# Issue #35370: DateTimePicker component - inconsistent activeElement with month navigation

- URL: https://github.com/WordPress/gutenberg/issues/35370

- Created: 2021-10-05T19:46:49Z
- Updated: 2023-07-24T13:16:57Z

## Body

### Description

If I open the [DateTimePicker](https://github.com/WordPress/gutenberg/tree/trunk/packages/components/src/date-time) that is associated with a Post's Publish Time/Date, and either go forward or backward in months, and then try to click on the Gutenberg Sidebar area then I would expect that the date picker would lose focus and close. However, it does not and stays open.

If I do the same, but then click in to the Gutenberg editor (not the sidebar) then the date picker closes fine, as expected.

### Step-by-step reproduction instructions

1. Create a new post, and click the "Immediately" to modify the post's publish time/date and open the DateTimePicker.
2. Once the DateTimePicker is open. Use the Forward/Backward month navigation to progress forward or backward.
3. Click off of the DateTimePicker component and in to the Gutenberg Sidebar area.
4. Note: the DateTimePicker is still opened.
