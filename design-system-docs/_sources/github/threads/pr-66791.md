To minimize the amount of changes in this file, I'm going to suggest something like this. The main points of the changes being:

- "Controlled"/"Uncontrolled" in these testing contexts refers to the [React concept](https://react.dev/reference/react-dom/components/input#controlling-an-input-with-a-state-variable), so naming this `ControlledUnitControl` would be confusing. But since we want the prop on all instances anyway, let's just import the original as `_UnitControl` and define an overridden `UnitControl` at the top.
- It's generally more accurate to use `React.ComponentProps<>` to extract types directly from the component, rather than import the `FooComponentProps`. In the component package, the actual component often allows more props than is defined in the `FooComponentProps` type.
