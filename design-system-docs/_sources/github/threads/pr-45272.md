## Why?

## ✍️ Dev Note 

The `Disabled` component internally relies on the [`inert` property](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/inert). In order to manage expectations when interacting with the component in [browsers where the `inert` attribute is not supported](https://caniuse.com/?search=inert), the component's docs were updated to clarify that the polyfill for the `inert` property needs to be added by the consumer of the `@wordpress/components` package.
