Do we already have a need for this in Gutenberg, by the way?

If we were to build this, I think we'd need to make it a new component (e.g. `PasswordControl`) since it's a bit presumptuous to automatically enhance it this way based on just `type="password"`.

On the other hand, this is very simple to implement using InputControl (not TextControl) — trivial enough that it might even be sufficient to just add a new example story in the Storybook docs for InputControl. So we can go that route if we don't have plans to reuse it multiple times in Gutenberg.
