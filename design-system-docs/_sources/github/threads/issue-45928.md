# Issue #45928: ColorPalette: Clear button doesn't show when default colors array is empty

## Body

### Description

I am developing a custom Gutenberg block, and using the [ColorPalette](https://developer.wordpress.org/block-editor/reference-guides/components/color-palette/) component for some color attributes. The ColorPallete doesn't show the clear button if the `colors` props is empty or not set. The `clearable` property is not honored in this case. Whereas if the `colors` is set to at least one default color object, the clearable also works as expected.

### Step-by-step reproduction instructions

In order to reproduce the issue, you need to add the following ColorPalette code in any test Gutenberg Block's edit.js file:

```jsx
<ColorPalette
    value={ color }
    onChange={ ( color ) => setColor( color ) }
    clearable = {true} // Regardless of true or false, this prop is not honored
/>
```

The following code will work when the colors prop is set to at least one default color object:

```jsx
<ColorPalette
    colors={ [
        { name: 'Red', color: '#f00' }
    ]}
    value={ color }
    onChange={ ( color ) => setColor( color ) }
/>
```
