## Description
<!-- Please describe what you have changed or added -->

Follow-up for #28624.

This PR removes the feature flag `process.env.COMPONENT_SYSTEM_PHASE` that was added to avoid leaking G2 components into WordPress 5.7 release. Now that beta 1 should happen this week, we can get rid of this temporary solution and plan to roll out G2 components in Gutenberg at a larger scale. There are still two versions of the font size picker, but we should plan to remove the old implementation separately.

This PR also includes some clean-up tasks marked in #28624:
- removes unused TS types
- improves where TS checks are enabled
- exposes `FontSizeControl` from `@wordpress/components/ui` that is useful for experiments
