```diff
+# Field Optionality Guidelines
+
+When designing forms with DataForm, it's important to clearly communicate which fields are required and which are optional. This guide explains best practices for marking field optionality to create clear, scannable forms.
```

I guess this PR is complementary to [this one](https://github.com/WordPress/gutenberg/pull/74430), right?

I think we've decided on the `auto` approach where we mark either the `required` or `optional` fields based on the minority of each type. This means, there will be no API to mark any field as `optional` (default), unless the field is `required`, which they should always do for validation too.

So, this paragraph should be reworded a bit I think.
