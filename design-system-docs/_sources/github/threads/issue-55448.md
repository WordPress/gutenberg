## Body

### Description

> **Note**
> With the latest Gutenberg, the problem is slightly different. The issue is reported in #55408.

For example, the playholder for Group block and Columns block display the tooltip when you hover over each variation. If you move the mouse cursor a little after hovering over it, the tooltip will blink.

### Step-by-step reproduction instructions

- Make sure that custom fields are turned off in the settings menu so that the editor becomes an iframe.
- Insert a Group block and a Column block.
- Hover over any variation.
- A tooltip should appear.
- Move the cursor until it does not go outside the variation.
- The tooltip should flash.
