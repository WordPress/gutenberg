## Body

## What?

Follow up to #65751

Remove the deprecated `__next40pxDefaultSize` prop from `BorderControl`, making the 40px default size the permanent default.

Follows #79420 (`BorderBoxControl`).

## Why?

The soft deprecation was introduced in WP 6.7 and scheduled to be removed in WP 7.1.

## How?

- Remove `__next40pxDefaultSize` from the `BorderControl` runtime API and remove `maybeWarnDeprecated36pxSize`.
- Keep an optional `@deprecated` + `@ignore` type stub on public types (per #46741).
- Always map `size="default"` to `__unstable-large`.
- Keep passing `__next40pxDefaultSize` internally to embedded `UnitControl` and `RangeControl` until those primitives are hard-deprecated.
- Remove `BorderControl` from the `components-no-missing-40px-size-prop` ESLint rule and add a restricted-syntax rule for passing the prop to `BorderControl`.

## Testing Instructions

1. Open Storybook to **Components / BorderControl** and smoke test the default story.
2. Open Storybook to **Components / BorderBoxControl** and confirm linked and split modes still render at 40px height.
3. Insert a Group or Image block and confirm border controls in the sidebar work as before (color/style picker, width input, slider when present).
4. Confirm no console warnings are logged.

### Testing Instructions for Keyboard

1. Tab to a border control in the block inspector.
2. Open the color/style picker with Enter/Space.
3. Navigate color swatches and style options with arrow keys.
4. Confirm focus order and activation work as before.
