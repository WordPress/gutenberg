# Issue #38009: Bottom half of text is cut off with SelectControl

- URL: https://github.com/WordPress/gutenberg/issues/38009
- Author: mipon
- Created: 2022-01-16T04:55:25Z
- Updated: 2026-04-16T15:15:24Z
- Comments: 3 of 3

## Body

### Description

Without any custom CSS rules, the default appearance of the `SelectControl ` label seems to have a problem that the bottom half of the text is cut off. It is less obvious in the inspector panel but occurs in both.

### Step-by-step reproduction instructions

1. Create a custom block with the code below.
```JavaScript
import { registerBlockType } from '@wordpress/blocks';
import { __ } from '@wordpress/i18n';
import {
	SelectControl,
	PanelBody,
} from '@wordpress/components';
import {
	InspectorControls,
	useBlockProps,
} from '@wordpress/block-editor';

registerBlockType( 'gutenberg-tests/select-control', {
	apiVersion: 2,
	title: 'Test: Select Control',
	icon: 'universal-access-alt',
	category: 'design',
	attributes: {
		selectField: {
			type: 'string',
		},
	},

	edit( { attributes, setAttributes } ) {
		const blockProps = useBlockProps();
		const { selectField, } = attributes;

		function onChangeSelectField( newValue ) {
			setAttributes( { selectField: newValue } );
		}

		return (
			<div { ...blockProps }>
				<InspectorControls>
					<PanelBody title={ __( 'Settings' ) }>
						<SelectControl
							label="Select Control"
							value={ selectField }
							options={ [
								{ value: 'a', label: 'Option A' },
								{ value: 'b', label: 'Option B' },
								{ value: 'c', label: 'Option C' },
							] }
							onChange={ onChangeSelectField }
						/>
					</PanelBody>
				</InspectorControls>
        <SelectControl
          label="Select Control"
          value={ selectField }
          options={ [
            { value: '1', label: 'Option 1' },
            { value: '2', label: 'Option 2' },
            { value: '3', label: 'Option 3' },
          ] }
          onChange={ onChangeSelectField }
        />
			</div>
		);
	}
} );
```
2. Display it in the editor.

### t-hamano on 2022-02-06T14:11:36Z

URL: https://github.com/WordPress/gutenberg/issues/38009#issuecomment-1030840478

I was able to disable the text cutoff in Chrome using one of the following methods.

- Change `appearance` value  `none` to `auto`
- Change `font-family` value `system-ui` to another font
- Change `line-height` value `1` to another value (`initial` / `2`, etc.)

I suspect it has something to do with the system font (Yu Gothic UI) adopted in Windows 10.
