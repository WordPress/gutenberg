# Issue #36703: Color Picker: RGB values reset to 0 when you delete text in one of the RGB fields

- URL: https://github.com/WordPress/gutenberg/issues/36703
- Author: noisysocks
- Created: 2021-11-21T23:59:03Z
- Updated: 2022-11-10T00:36:27Z
- Comments: 0 of 0

## Body

### Description

It's really frustrating to manually enter RGB values into the Color Picker because, when you clear one of the RGB fields, the two other fields reset to 0.

### Step-by-step reproduction instructions

1. Open a Color Picker, e.g. select a block and modify its _Text color_.
2. Toggle _Show detailed inputs_.
3. Select _RGB_ in the dropdown that appears. (Bug also exists when using _HSL_.)
4. Type in something like R = 200, G = 200, B = 200.
5. Double click on the R field.
6. Press <kbd>Delete</kbd>, as if you were about to modify it to be 100.
7. The G and B fields reset to 0!
