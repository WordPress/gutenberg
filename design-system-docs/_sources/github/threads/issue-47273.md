# Issue #47273: Links within snackbars have insufficient color contrast ratio on hover

- URL: https://github.com/WordPress/gutenberg/issues/47273
- Author: afercia
- Created: 2023-01-19T09:23:16Z
- Updated: 2023-07-24T12:47:45Z
- Comments: 18 of 18

## Body

### Description

When hovering a link within a Snackbar, the link hover style changes the link color to a blue `#007cba`. This color has insufficient contrast ratio against the background color `#1e1e1e`. The contrast ratio is only 3.65:1. It should be at least 4.5:1.

<img width="302" alt="Screenshot 2023-01-19 at 09 58 01" src="https://user-images.githubusercontent.com/1682452/213402029-03b39db1-e816-4976-bcbb-d8867c5c0916.png">


### Step-by-step reproduction instructions

- Edit a draft post and save it as draft.
- Wait for the Snackbar to appear at the bottom left of the screen.
- Hover the 'View Preview' link.
- Observe the link color changes to blue `#007cba`.
