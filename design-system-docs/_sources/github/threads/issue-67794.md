# Issue #67794: Update `Text` component to utilise tokens

## Body

Tokens were recently added for styling text using scss. This is [documented on Storybook](https://wordpress.github.io/gutenberg/?path=/docs/tokens-typography--page). 

Let's discuss updating the `Text` component to utilise these tokens. By doing so we can hopefully close out issues like this one: https://github.com/WordPress/gutenberg/issues/47735

### jameskoster on 2024-12-20T14:20:06Z

URL: https://github.com/WordPress/gutenberg/issues/67794#issuecomment-2557106342

@rinkalpagdar it's not currently possible to reference tokens from the design system relating to typography in the [`Text`](https://wordpress.github.io/gutenberg/?path=/docs/components-experimental-text--docs) component. 

It should be possible to utilise system tokens in properties like `size`, `weight`, `lineHeight`, and so on.

Additionally it should be possible to reference a specific style (a combination of font styles defined as [scss mixins](https://github.com/WordPress/gutenberg/blob/12f77640cfad82f850a02718e6fe7de41379b8ad/packages/base-styles/_mixins.scss#L48-L70)) rather than handling individual properties.

For example consumer should be able to do something like:

<Text style="body.small">Hello</Text>

I hope that makes sense? 

I seem to recall discussing this a bit with @ciampo but it looks like we didn't make any notes. Maybe he has some recollection 🤞
