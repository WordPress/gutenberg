## Description
<!-- Please describe what you have changed or added -->
Refactor <TimePicker> to function component following the latest best practices. Related to #22890. Notable changes are as follow.

- Refactored tests to use RTL, as per #17249.
- Add `<TimePicker>` story in storybook.
- Avoid syncing state and props as much as possible. Use an `useEffect` to reset the state when necessary.
- Truncate the date at the minutes at all time, related to #24305.
