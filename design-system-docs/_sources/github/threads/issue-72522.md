# Issue #72522: ComboboxControl reset button should be displayed if there's a value

- URL: https://github.com/WordPress/gutenberg/issues/72522
- Author: juanfra
- Created: 2025-10-21T10:27:46Z
- Updated: 2025-10-27T15:35:14Z

## Body

## What problem does this address?

The clear button should only appear when there's an actual value to clear, and be hidden when the combobox is empty.

https://github.com/user-attachments/assets/5eea3b05-9134-4dfa-9951-cd54bb42b4ec


## What is your proposed solution?

To improve the UX, my suggestion is to show the button only when there's a value to clear (when it's actionable). So that we avoid confusion about why a button is disabled when no action is applicable. Also, a button appearing confirms that a value has been selected.
