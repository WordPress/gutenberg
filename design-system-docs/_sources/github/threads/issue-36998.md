# Issue #36998: Color Picker: Refine the look of "unset" color picker

- URL: https://github.com/WordPress/gutenberg/issues/36998
- Author: jasmussen
- Created: 2021-11-30T12:18:48Z
- Updated: 2023-03-17T10:26:29Z
- Comments: 6 of 6

## Body

Extracting from [this comment](https://github.com/WordPress/gutenberg/pull/36994#issuecomment-982558698), the checkerboard background currently in place for the Custom Color card indicates transparency, but it should probably lean towards indicating "unset" instead. Also:

> We need to discriminate from "white" and "not set". Though perhaps that can be written in the place of the hex code.

There are the beginnings of a PR in `try/polish-unset-color-indicator-further`, but it isn't quite visually succesful:

<img src="https://user-images.githubusercontent.com/1204802/144041329-85714322-164e-4a4a-8f07-46720ae7537b.gif">

It also opens the question: should the checkerboard backgroud remain in place for when a color with opacity is created?
