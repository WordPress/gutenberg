# Issue #53886: ResponsiveWrapper does not correctly render images wrapped in Button

- URL: https://github.com/WordPress/gutenberg/issues/53886
- Author: markjaquith
- Created: 2023-08-23T03:21:53Z
- Updated: 2026-05-20T17:52:04Z
- Comments: 1 of 1

## Body

### Description

I expect to be able to pass anything to ResponsiveWrapper... not just an image tag. Something about the new aspect ratio stuff is causing images to render with zero height when wrapped in a `Button`.

This worked before WordPress 6.3.

I know I can just attach an `onClick` to the image, but that's not good for accessibility. Buttons are for tapping things. If I wrap an image in a button, browsers know that this is a thing that can be pressed, and accessibility is handled.

### Step-by-step reproduction instructions

```jsx
			<MediaUpload
				onSelect={onSelectMedia}
				allowedTypes={['image']}
				multiple={false}
				value={media}
				render={({ open }) => (
					<ResponsiveWrapper
						naturalWidth={ media.media_details.width }
						naturalHeight={ media.media_details.height }
					>
						<Button onClick={open}><img src={media.source_url} /></Button>
					</ResponsiveWrapper>
				)}
			/>
```

The cleaner way to do this would be to wrap whole `ResponsiveWrapper` in the `Button`. 

```jsx
<Button onClick={ open }>
    <ResponsiveWrapper naturalWidth={ media.media_details.width } naturalHeight={ media.media_details.height }>
        <img src={ media.source_url } alt="" />
    </ResponsiveWrapper>
</Button>
```
That preserves the wrapper's aspect ratio and keeps the image keyboard- and pointer-actionable. 

Also worth noting: ResponsiveWrapper is marked status: 'not-recommended' with note "Planned for deprecation" in its Storybook config, So I feel we can go ahead and close this issue as "wont-fix".

see: https://github.com/WordPress/gutenberg/blob/trunk/packages/components/src/responsive-wrapper/stories/index.story.tsx#L21-L25
