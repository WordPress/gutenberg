# Issue #79088: Adopt the new `size` design tokens (`--wpds-dimension-size-*`)

- URL: https://github.com/WordPress/gutenberg/issues/79088
- Author: jameskoster
- Created: 2026-06-10T14:02:40Z
- Updated: 2026-06-10T14:02:40Z

## Body

`@wordpress/theme` now ships dedicated **size** tokens:

https://github.com/WordPress/gutenberg/blob/7dd7d62090d281df4109c5578f063fa9617245d4/packages/theme/tokens/dimension.json#L154-L211

They represent the size of UI elements; control heights (buttons, inputs) and the uniform dimension of inherently square elements (icons, markers, indicators, thumbnails).

> [!NOTE]
> These tokens are **not** intended for the width of layout regions/containers (e.g. column widths, content areas). Use them for element heights and square element sizing only. Layout widths are out of scope and should keep their existing approach (or use `surface-width` tokens where appropriate).

While the tokens were unavailable, many places added placeholders with `// TODO: use size token when available` comments. Now that the tokens exist, we should adopt them where appropriate and remove any workarounds.

### Available tokens

| Token | CSS custom property | Value | Intended use |
|---|---|---|---|
| `5xs` | `--wpds-dimension-size-5xs` | 4px | Notification indicators |
| `4xs` | `--wpds-dimension-size-4xs` | 8px | Small interactive elements (e.g. resize handles) |
| `3xs` | `--wpds-dimension-size-3xs` | 12px | Small markers |
| `2xs` | `--wpds-dimension-size-2xs` | 16px | Small controls (checkboxes/radios), small decorative icons |
| `xs` | `--wpds-dimension-size-xs` | 20px | Medium icons |
| `sm` | `--wpds-dimension-size-sm` | 24px | Icons and small buttons |
| `md` | `--wpds-dimension-size-md` | 32px | Medium buttons and inputs |
| `lg` | `--wpds-dimension-size-lg` | 40px | Default buttons and inputs |

Many current placeholders are `calc(var(--wpds-dimension-base) * N)` (base = 4px). As a guide: `*4` → `size-2xs` (16px), `*6` → `size-sm` (24px), `*8` → `size-md` (32px).

## Scope

Replace hardcoded heights / `calc()` placeholders / `base-styles` Sass variables (`$button-size-small`, `$icon-size`) with the appropriate `--wpds-dimension-size-*` token, and remove the related TODO comments.

> This checklist was compiled from existing TODO comments and may not be exhaustive. Please also catch any size-related hardcoded values that map cleanly to a size token while working through these.
