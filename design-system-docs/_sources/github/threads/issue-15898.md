# Issue #15898: Expose focusOnMount <Popover> property in <Dropdown> component

- URL: https://github.com/WordPress/gutenberg/issues/15898
- Author: TimothyBJacobs
- Created: 2019-05-29T18:14:51Z
- Updated: 2019-05-30T00:57:29Z

## Body

**Is your feature request related to a problem? Please describe.**
When using the `<Dropdown />` component, I'd sometimes like to be able to set the `initialFocus` to the `container` instead of the `firstElement`.

**Describe the solution you'd like**
Expose `focusOnMount` in the `<Dropdown />` component so I can do `<Dropdown focusOnMount="container" />`.

**Describe alternatives you've considered**
The `<Dropdown />` component is thin enough that it is possible to reimplement when necessary. But having to do the `closeIfClickOutside` bit is annoying.

Happy to PR.
