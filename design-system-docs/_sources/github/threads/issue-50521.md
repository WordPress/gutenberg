# Issue #50521: Gradient: Improve removing control points

- URL: https://github.com/WordPress/gutenberg/issues/50521
- Author: hanneslsm
- Created: 2023-05-10T15:42:00Z
- Updated: 2025-04-21T07:31:51Z
- Comments: 2 of 2

## Body

## What problem does this address?
Currently it's not intuitive how to remove a point on a gradient.
You have to select the point on the gradient (aka open the color picker) and find the "Remove Control Point" link on the bottom of the color picker. It's neither a intuitive place for the link, nor a visually easily to distinguish.

<img width="570" alt="image" src="https://github.com/WordPress/gutenberg/assets/17861443/7a490c42-94df-4632-be9e-8dc757fa9ffc">


## What is your proposed solution?
- Removing a point should be possible by dragging the point out of the gradient area. 
- Optional by selecting the point and pressing backspace.
