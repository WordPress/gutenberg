### t-hamano on 2025-12-22T08:44:39Z

URL: https://github.com/WordPress/gutenberg/pull/74091#issuecomment-3681053321

@prasadkarmalkar Thanks for the update!

Is there a reason you're [applying a background to the pseudo-element](https://github.com/WordPress/gutenberg/pull/74091/changes#diff-027457a66581220a0f7ca217f66814f5b813d5b8270e1d5e9a1cb8343294728bR72)? As far as I've tested, the following simplification works fine:

```scss
.editor-post-featured-image__preview {
	height: auto !important;
	outline: $border-width solid rgba($black, 0.1);
	@include checkerboard-background( 12px );

	.editor-post-featured-image__preview-image {
		object-fit: cover;
		width: 100%;
		object-position: 50% 50%;
		aspect-ratio: 2/1;
	}
}
```
