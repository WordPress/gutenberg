# Issue #68575: AnglePickerControl: no help property, no margin bottom, outdated doc

- Created: 2025-01-09T15:52:39Z

## Body

I tried using the `AnglePickerControl` component.

What I noticed:
1. the [storybook](https://wordpress.github.io/gutenberg/?path=/docs/components-anglepickercontrol--docs) doesn't mention `className` property, which it [supports](https://github.com/WordPress/gutenberg/blob/3cb93e95e5f1f8875362f9e7c4246884d0fe7ad7/packages/components/src/angle-picker-control/index.tsx#L29-L35).
2. the [dev doc](https://developer.wordpress.org/block-editor/reference-guides/components/angle-picker-control/) doesn't mention the `className` property, which it [supports](https://github.com/WordPress/gutenberg/blob/3cb93e95e5f1f8875362f9e7c4246884d0fe7ad7/packages/components/src/angle-picker-control/index.tsx#L29-L35).
3. component supports `label` but does not support `help` for some reason. 
4. the component does not have margin-bottom like `RangeControl` or others.

The workaround to `3.` and `4.` is to wrap it in `BaseControl`, set `BaseControl[label]` and `BaseControl[help]` properties. And then you must set `AnglePickerControl[label]` property to an empty string to remove duplicated labels. Quite ugly.
