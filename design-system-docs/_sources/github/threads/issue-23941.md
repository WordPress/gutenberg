# Issue #23941: Update Text component

- URL: https://github.com/WordPress/gutenberg/issues/23941
- Author: jameskoster
- Created: 2020-07-14T20:38:04Z
- Updated: 2024-09-24T16:32:07Z

## Body

In order to [improve the wordpress.org Figma libraries](https://make.wordpress.org/design/2020/07/03/improvements-to-the-figma-libraries/) @noahshrader has attentively created a collection of [text styles in Figma](https://www.figma.com/file/e4tLacmlPuZV47l7901FEs/WordPress-Design-Library?node-id=41%3A973) that match what has been implemented throughout Gutenberg.

However, the styles defined in the [Text](https://github.com/WordPress/gutenberg/tree/master/packages/components/src/text) component are not in alignment with that broader implementation, and need updating. For example, the `Button` style in the `Text` component sets the font-size to 14px, but the actual `Button`s in the Gutenberg UI are rendered at 13px.

The `Text` component is also missing some styles like `Helper Text` and `Section Heading`.
