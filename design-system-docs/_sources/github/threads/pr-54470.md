## What?
<!-- In a few words, what is the PR actually doing? -->
- Improve the icons so they are more visible (higher contrast and not blurry on high-resolution screens) and a bit smaller, to fit better in the Inspector. The color is technically darker than the track value, but optimally it does not look so (as it's smaller visually). 
- Condenses a bit as well, so the controls take up less space — but are still approachable. 
- Adjusts the icons iso they are in line with the label. 
- Small refinement to the settings icon.
