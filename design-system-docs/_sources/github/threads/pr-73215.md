## What?

Closes #73360

Updates theme package to implement basic support for density.

## Why?

As described in #71196, density is intended to be one of the key configurable aspects of theming. Several of the use-cases described for Boxes associated with #72784 are related to context-specific spacing adjustments (see https://github.com/WordPress/gutenberg/issues/72336#issuecomment-3499182839).

## How?

- Uses [DTCG-standard Extensions syntax](https://www.designtokens.org/tr/2025.10/format/#extensions) to provide "overrides" for semantic spacing tokens, defined using "modes" that [Terrazzo](https://terrazzo.app/) tool can understand as part of compiled CSS
- The changes here include a fix to the behavior of the plugin introduced in #72890 which handles value inlining, since it previously did not handle this type of mode overrides behavior (where mode values may also reference a primitive value in a way that needs to be appropriately inlined)

4. Use "Theme" button in Storybook toolbar to toggle to different densities like "Compact" and "Comfortable"
8. Observe that the padding varies based on density selection
