## Body

### Description

When using the Position block option, only the default value is displayed by default. 
The user cannot see there are other values unless he knows there is another
e.g. the Sticky option is hidden, sliding the dropdown values is difficult

### Step-by-step reproduction instructions

1. Edit your page or your template part (ex: header)
2. Add a group
3. Use the Position option
4. Observe that the different options are not visible : your need to know there is another value to try to reach the value
5. The dropdown is difficult to click (too narrow height)
