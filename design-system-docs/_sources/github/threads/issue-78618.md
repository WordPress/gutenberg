# Issue #78618: Gutenberg publish panel does not respect lowercase a in g:i a time format.

## Body

### Description

The Gutenberg publish/schedule panel does not fully respect the site's configured.

**Expected Result:**
The time selector should display lowercase am/pm because the selected PHP time format uses lowercase `a`.

Example:
`12:32 pm`

**Actual Result:**
The Gutenberg publish panel displays uppercase `AM/PM` instead.

Example:
`12:32 PM`

**Additional Notes:**
When using `g:i A`, uppercase `AM/PM` is correct.
When using `H:i`, the editor should use 24-hour format without `AM/P`M.

### Step-by-step reproduction instructions


**Steps to Reproduce:**

1. Go to Dashboard → Settings → General
2. Set **Time Format** to: `g:i a`
3. Open the Block Editor (Gutenberg)
4. Check the Publish/Schedule panel time selector.

Thanks for the report and steps to reproduce. I checked this. Found that the published date and time on the frontend will still show exactly as set in your sites time format settings. So there's no impact on what visitors see.

### t-hamano on 2026-05-26T13:20:47Z

URL: https://github.com/WordPress/gutenberg/issues/78618#issuecomment-4544396108

Date and time formats are solely for configuring how they are displayed on the frontend, and I don't think those rules apply to the editor UI where dates and times are set.

If we want to apply formatting to the editor UI, we would need to add an option to toggle case in the `DateTimePicker` component, but I'm not sure if that's worthwhile.

Personally, I suggest closing this issue as "not a bug."
