# Issue #42093: BoxControl: use a more appropriate ARIA role instead of 'region'

- URL: https://github.com/WordPress/gutenberg/issues/42093
- Author: afercia
- Created: 2022-07-01T13:24:32Z
- Updated: 2023-05-17T15:55:45Z
- Comments: 0 of 0

## Body

### Description

The `BoxControl` component is typically used for Padding / Margin / Block spacing (Gap) controls in the inspector sidebar. 

The root element of this component renders a div element with an ARIA `role="region"` and an `aria-labelledby` attribute that points to some visible text.

It's important to know that when the ARIA `role="region"` is used on a labelled element, it determines an ARIA landmark. 

ARIA landmarks should only be used to 'mark' the main sections of a page. Landmarks allow assistive technology users to quickly get a sense of the page structure and jump through landmarks by using dedicated commands.

The Padding / Margin / Block spacing controls are not 'main sections' of the page. They shouldn't be listed as landmarks together with other, more important, landmarks:

<img width="1441" alt="padding margin regions" src="https://user-images.githubusercontent.com/1682452/176901514-96941f02-beb8-4ea4-997d-815579f05448.png">

A more appropriate role would be `group`, so that the form elements within `BoxControl`  are logically grouped in a `role="group"` with a meaningful labelling given by the `aria-labelledby` attribute.


### Step-by-step reproduction instructions

- edit a post
- add a block that uses margin / padding / block spacing, e.g.: a Columns block
- select the Columns block
- in the block inspector toolbar, make sure to enable 'Padding' and 'Margin' in the Dimensions options menu (the vertical ellipsis on the right of 'Dimensions')
- inspect the source and observe the root element of the 'Padding' and 'Margin' control has a `role="region"` attribute.
