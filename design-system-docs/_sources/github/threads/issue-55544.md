## Body

### Description

While playing with ColorPicker component in Storybook I've noticed a strange bug with ColorPicker when enableAlpha is on:

https://wordpress.github.io/gutenberg/?path=/docs/components-colorpicker--docs

While dragging the color picker to left or bottom edge it starts to interact weirdly and if you go beyond the container while it is dragged it resets hue indicator.

Note: If alpha is not 100% then there are no issues!

### Step-by-step reproduction instructions

1. Insert ColorPicker component
2. Set enableAlpha=true
3. Simply put this onChange event: onChange={ color => setColor( color ) }
4. Start dragging to the left or bottom edge of the Color Picker while having hue set in the middle or somewhere else
