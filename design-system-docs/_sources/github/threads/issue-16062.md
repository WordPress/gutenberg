# Issue #16062: Modal component defines a defaultProp for a required property.

- URL: https://github.com/WordPress/gutenberg/issues/16062
- Author: dsifford
- Created: 2019-06-09T21:40:17Z
- Updated: 2019-06-11T04:49:40Z
- Comments: 0 of 0

## Body

**Describe the bug**
This could lead to bugs and could be confusing for newcomers. Modal requires a defined `onRequestClose` function so that the modal itself can be closed, yet it has a `defaultProp` of `lodash.noop`.

https://github.com/WordPress/gutenberg/blob/a57202e635ff0cd190a09128d27951620db9a870/packages/components/src/modal/index.js#L165-L179

**Expected behavior**
This should be a fatal error if the prop is not provided since it is critical for the modal to function properly.
