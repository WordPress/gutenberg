## Body

## What?
This PR updates even more component tests to use real timers. This is a follow-up to #46714, #47056, #47144, and #47218.

## Why?
We discovered that Jest real timers are preferable when their use is possible, see https://github.com/facebook/react/issues/25889 and the description in #46714.

This post is great writing that explains the rationale in more detail:
https://jsnajdr.wordpress.com/2023/01/11/prefer-jest-real-timers-when-testing-with-react-testing-library/

## How?
We're removing the specific `jest.useFakeTimers();` calls. We're also removing the now unnecessary `jest.advanceTimersByTime()` calls and post-test cleanup that we've been doing with `jest.runOnlyPendingTimers()` and `jest.useRealTimers()`. We're also altering some tests to wait for the appropriate actions before continuing/performing the relevant assertions.
