## What?
<!-- In a few words, what is the PR actually doing? -->

This PR converts `UnitControl`'s Storybook examples to TypeScript. While doing so, it also refactors those examples from using knobs to using controls.

## Why?
<!-- Why is this PR necessary? What problem is it solving? Reference any existing previous issue(s) or PR(s), but please add a short summary here, too -->

Part of the `@wordpress/components`'s TypeScript migration (#35744).

Altogether, the migration to TypeScript and the refactor to controls allow Storybook to extract prop types correctly and display them in the "docs" tab.

## How?
<!-- How is your PR addressing the issue at hand? What are the implementation details? -->

- Converted `UnitControl`'s story to TypeScript
- Added a named export for the un-forwarded `UnitControl` component (necessary to extract TS props correctly)
- Added a few missing types (`hideLabelFromVision`, `isShiftStepEnabled`, `shiftStep`) (these types should be later removed once `NumberControl` is migrated to TypeScript, since at that point `UnitControl` will be able to directly extend `NumberControl`'s props)
- Refactored from knobs to controls
