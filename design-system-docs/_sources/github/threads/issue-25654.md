Update: I was able to "fix" it by adding a quick return for the `isWithinElementBounds` method if `element` is `undefined`:

```js
const isWithinElementBounds = ( element, x, y ) => {
	if ( ! element ) return false;

	const rect = element.getBoundingClientRect();
	/// make sure the rect is a valid rect
	if ( rect.bottom === rect.top || rect.left === rect.right ) {
		return false;
	}

	return (
		x >= rect.left && x <= rect.right && y >= rect.top && y <= rect.bottom
	);
};
```

I'm not sure why a `dropZone` item would be undefined though 🤔 .
