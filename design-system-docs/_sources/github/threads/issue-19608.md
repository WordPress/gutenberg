# Issue #19608: Color Picker Format Toggle Icon uses a Dropdown/Accordion Arrow

- URL: https://github.com/WordPress/gutenberg/issues/19608
- Author: jeryj
- Created: 2020-01-13T22:18:59Z
- Updated: 2020-01-17T23:57:15Z
- Comments: 1 of 1

## Body

On the color picker, the button to toggle between formats uses a down chevron arrow. This is the same arrow used by accordions and dropdown options.

The icon suggests that it does something different than it actually does (toggles between color types). Is there a different icon that would better fit? Possibly something that suggests changing the format type, like the block switcher icon?

**To reproduce**
Steps to reproduce the behavior:
1. Go to the editor
2. Adjust the color on something
3. Click the "custom color" button/link to view the color picker
4. See the down chevron in the bottom right
