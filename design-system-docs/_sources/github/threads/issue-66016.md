# Issue #66016: Codify and communicate how people contribute to the design system

- URL: https://github.com/WordPress/gutenberg/issues/66016
- Author: cli-automattic
- Created: 2024-10-10T10:44:29Z
- Updated: 2025-12-04T19:41:43Z
- Comments: 1 of 1

## Body

**Goal:**
Clarify how people can contribute to the design system to evolve our library and make improvements.

**Current Issue:** 
The contribution process is not streamlined, or obvious. With people using various forums to contribute, leading to missed information and difficulty to keep track of requests.

**Proposal:** 
Establish a unified contribution process to streamline the process for everyone and so the design system team can manage the requests. Encourage open communication and make contributions a learned behaviour by our Community.

Such as:
- All contributors should have a GitHub account to participate in discussions and stay updated on changes.
- Before creating a new issue, review if the issue has already been raised
- Create an issue including adding context for the change, a design spec, add correct tags*
- The design system reviews and gives feedback to confirm acceptance of the change
- We implement and open a PR.
- Core team reviews PR, including accessibility review
- Components are merged, Figma library updated and ready for widespread use.
- We update a new release to the design system to the Figma Community

**What we need to do:**

- [ ] Agree the contribution process
- [ ] Make sure we have the process for triage and prioritisation agreed
- [ ] Communicate the process on our channels (slack, Make Design blog)
- [ ] Add the process to our Storybook site so it's visible
