# Issue #76570: UI Text: common.css overrides font size

- URL: https://github.com/WordPress/gutenberg/issues/76570
- Author: simison
- Created: 2026-03-17T09:53:53Z
- Updated: 2026-04-03T16:52:29Z
- Comments: 2 of 2

## Body

When using `Text` component from UI package with semantic rendering tags, `common.css` of WordPress overrides styles set by `variant` prop.

Example:

```jsx
<Text
	// eslint-disable-next-line jsx-a11y/heading-has-content -- content provided via render prop
	render={ <h2 /> }
	variant="heading-lg"
>
	Example
</Text>
```

<img width="460" height="92" alt="Image" src="https://github.com/user-attachments/assets/46d00675-2bf0-4c72-81da-dfe858ce52d5" />
<img width="453" height="65" alt="Image" src="https://github.com/user-attachments/assets/17f2e022-3d10-46a3-8176-dd1a9fffd3ba" />

The solution could be higher specificity styles, even by using a format like `h2.component-class`?
