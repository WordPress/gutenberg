# Issue #65334: SearchControl: Deprecate `onClose` prop

- URL: https://github.com/WordPress/gutenberg/issues/65334
- Author: mirka
- Created: 2024-09-13T17:48:11Z
- Updated: 2024-10-10T11:31:56Z
- Comments: 5 of 5

## Body

## What problem does this address?

The `onClose` prop is not used anymore in the Gutenberg app. It was originally intended to render a close button to "trigger your own logic to close the search field entirely, rather than just clearing the input value."

The prop itself is causing confusion to consumers (#64921), and I think the UI pattern of a single button that doubles as a reset and a close is questionable from a UX standpoint.

## What is your proposed solution?

I think we can [soft deprecate](https://github.com/WordPress/gutenberg/issues/61099) the feature. For consumers that really want to maintain the original behavior, however unrecommended, we can issue guidance to use the `suffix` prop.
