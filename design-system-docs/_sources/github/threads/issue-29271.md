## Description
<!-- Please write a brief description of the bug. -->
When selecting the columns block in Gutenberg (in the Firefox or Safari), the arrow buttons in the block inspector to add or remove additional columns is broken

## Step-by-step reproduction instructions
<!--
Please list the steps needed to reproduce the bug. For example:
1. Go to '...'
2. Click on '...'
3. Scroll down to '...'
-->
1. Navigate to the post editor or site editor
2. Add a columns block
3. Open the block inspector
4. Verify that the arrow buttons does not adjust the number of columns as expected

## Expected behaviour
<!-- Please describe what you expected to happen. -->
- Clicking on the "up" arrow will add an additional column to the columns block
- Clicking down on the "down" arrow will remove a column from the columns block

## Actual behaviour
<!-- Please describe what actually happened. -->
The arrow buttons are unresponsive or don't function at as expected

bf9f9e572138ab28814c1b113a6d9b5fbbfaea8c removed a bit of logic to focus of the input in case it's not. Firefox needs that since it doesn't focus the input if just the spinner arrows are hit and the input (in components based on `InputControl`) must have the focus or else it updates only via props.

I made #29305 which fixes this for Firefox. The issue with Safari seems different and appears to be that the drag-to-adjust feature is not working. Maybe it was something to do with the updated react-use-gesture from #28280. I've not figured that out yet and have to take a break from this for now.
