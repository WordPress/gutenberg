# Issue #25953: ComboboxControl: Searches should be deburred

- URL: https://github.com/WordPress/gutenberg/issues/25953
- Author: mirka
- Created: 2020-10-08T13:07:48Z
- Updated: 2020-12-24T09:34:30Z
- Comments: 0 of 0

## Body

**Is your feature request related to a problem? Please describe.**

`ComboboxControl` does not ignore diacritics, which makes it hard to search.

For example, with the list of countries in the [Storybook](https://wordpress.github.io/gutenberg/?path=/story/components-comboboxcontrol--default), I can't type `aland` to match `Åland Islands`. 

**Describe the solution you'd like**

Queries should be [deburred](https://lodash.com/docs/4.17.15#deburr) by default, or the component should provide a deburr option via prop.
