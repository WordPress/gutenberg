# Issue #46819: ComboboxControl: Empty `ul` tags is rendered when there are no suggestions

- URL: https://github.com/WordPress/gutenberg/issues/46819
- Author: t-hamano
- Created: 2022-12-29T13:27:27Z
- Updated: 2025-01-14T08:24:57Z
- Comments: 2 of 2

## Body

### Description

An empty `ul` tag is rendered when a string is entered that does not match the list specified by the `option` prop.
This results in an unintended border below the input field.

![conbo-box-control](https://user-images.githubusercontent.com/54422211/209959307-e8ffb077-2e02-4f2c-8119-c1cc06e0a4f3.png)


### Step-by-step reproduction instructions

Enter text that does not match any of the options on [the Storybook](https://wordpress.github.io/gutenberg/?path=/story/components-comboboxcontrol--default).
