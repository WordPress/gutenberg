Part of https://github.com/WordPress/gutenberg/issues/65323
Follow-up to https://github.com/WordPress/gutenberg/pull/71984#issuecomment-3365291790

## What?

This flips the search icon in search fields, depending on their placement (dictated by text direction).

### Affected components

- `SearchControl`
- `DataViews` search widget
- Command menu search

## Why?
 
We moved the icons placement from suffix to prefix in #71984, and we want to flip the icon horizontally based on this placement.

## Testing Instructions

See the Storybook story for the `SearchControl` component. Use the RTL switcher 🌐 in the top toolbar.

See inline comments for in-app instances.
