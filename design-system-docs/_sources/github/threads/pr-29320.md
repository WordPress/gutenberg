## Body

This update adds some basic tests for `css` and `styled` from the Style System for the new Components.
At the moment, these functions come from an external library (`@wp-g2/styles`) - so they serve a bit like integration tests to ensure that basic functionality is working correctly.

This is to help improve test coverage for the new Component System as noted by @gziolo 
https://github.com/WordPress/gutenberg/issues/28399#issuecomment-771579755

This update also bumps the `@wp-g2` repos to `v0.0.157`.
This includes the update for improved RTL rendering and `StyleQuery` interpolation:

https://github.com/ItsJonQ/g2/releases/tag/v0.0.157
