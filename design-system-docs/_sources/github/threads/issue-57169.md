# Issue #57169: Font size picker: the Reset button triggers a focus loss

- URL: https://github.com/WordPress/gutenberg/issues/57169
- Author: afercia
- Created: 2023-12-18T15:44:13Z
- Updated: 2023-12-20T07:44:29Z
- Comments: 0 of 0

## Body

### Description

The font size picker component can optionally render a 'Reset' button.
When clicked, the reset button gets disabled dynamically with the addition of a `disabled` HTML attribute. Current code:

https://github.com/WordPress/gutenberg/blob/34dbbe4226d1d2bcc99c0eb33a48e42a5064edcd/packages/components/src/font-size-picker/index.tsx#L278-L293

As such, when using a keyboard, the button becomes not focusable _while_ it is focused thus triggering a focus loss.

There have been several occurrences so far where contributors used the `disabled` attribute on elements that are supposed to be focused while they get disabled. We need to avoid this pattern at all costs. Cc @ciampo 

Long time ago we established to use another, more accessible, pattern instead:
- Used `aria-disabled` instead of `disabled`.
- Noop the control.


### Step-by-step reproduction instructions

- Go to the storybook at https://wordpress.github.io/gutenberg/?path=/docs/components-fontsizepicker--docs
- Set the `withReset` prop to `true`.
- Click the icon button `Set custom size`.
- Set a custom size.
- Using the keyboard, move focus to the 'Reset' button.
- Activate the button with the Spacebar key.
- Note: the button doesn't seem to work with the Enter key, this needs to be investigated.
- Observe the button gets disabled dynamically.
- Observe focus is lost.
