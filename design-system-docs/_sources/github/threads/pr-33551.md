## Description
<!-- Please describe what you have changed or added -->

This PR cherry-picks a few minor improvements to the `<Elevation />` component  that were part of #33098 and didn't get merged:

- reduced-motion transition styles
- better JSDocs for prop types
- updated (and corrected) README

## How has this been tested?
<!-- Please describe in detail how you tested your changes. -->
<!-- Include details of your testing environment, tests ran to see how -->
<!-- your change affects other areas of the code, etc. -->

The only runtime change is about the reduced motion transition styles.

To test those changes:
- run `npm run storybook:dev` locally
- visit the `Elevation` story (in particular the "Focus" sub-story)
- enable/disable [reduced motion settings](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion#user_preferences)
- make sure that, when reduced motion is enabled, the box shadow changes on the `Elevation` component happen instantly (instead of animating)
- check that everything else in the story works and behaves like in [production](https://wordpress.github.io/gutenberg)
