# Issue #57862: ToggleGroupControl: Add disabled state for entire component

- URL: https://github.com/WordPress/gutenberg/issues/57862
- Author: mirka
- Created: 2024-01-15T22:45:08Z
- Updated: 2025-07-24T11:41:03Z
- Comments: 6 of 6

## Body

## What problem does this address?

#57562 surfaced a use case for a `disabled` state for ToggleGroupControl.

## What is your proposed solution?

- The styling could be similar to the `isPressed` Button component when it is disabled.
- As for the [focus behavior when disabled](https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/#focusabilityofdisabledcontrols), we may need an additional `focusableWhenDisabled` prop on ToggleGroupControl so consumers can choose.
