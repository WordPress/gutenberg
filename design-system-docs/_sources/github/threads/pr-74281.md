## Why?
<!-- Why is this PR necessary? What problem is it solving? Reference any existing previous issue(s) or PR(s), but please add a short summary here, too -->

While the tests are currently disabled (see https://github.com/WordPress/gutenberg/issues/73726), they can still serve as an additional check when making changes to the color ramp generation code, like in https://github.com/WordPress/gutenberg/pull/74278.

Therefore, I'm updating the snapshots to be up to date with the latest code on `trunk` .

> [!WARNING]
> It looks like the `node.js` version can impact the result of the snapshots. I chose to use `node@20.19.6` to match the version that is being used in the CI checks.

## How?
<!-- How is your PR addressing the issue at hand? What are the implementation details? -->

- Temporarily un-skipped tests, updated snapshots
