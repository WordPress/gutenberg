# Issue #18494: When the input box for alpha value of ColorPicker is operated, it is forced to 0

- URL: https://github.com/WordPress/gutenberg/issues/18494
- Author: ddryo
- Created: 2019-11-14T04:05:19Z
- Updated: 2019-12-09T16:05:03Z
- Comments: 1 of 1

## Body

ColorPicker cannot be used to manipulate the color alpha value from the input area.
Forced to 0.

**To reproduce**
1. Open ColorPicker.
2. Use alpha-bar to set the opacity of the color.
3. Manipulate the input area for manipulating alpha values
4. Then the alpha value will be forced to 0

**Gif Image**
![output](https://user-images.githubusercontent.com/31400297/68825957-5f9fc000-06df-11ea-9865-3d24ff83165c.gif)


**My source code**
```
<ColorPicker
    clearable={true}
    color={bgColor}
    onChangeComplete={(val) => {
        console.log(val);
        console.log(bgColor);
        const rgb = val.rgb;
        if (1 !== rgb.a) {
            const rgbaColor = `rgba(${rgb.r},${rgb.g},${rgb.b},${rgb.a})`;
            setAttributes({ bgColor: rgbaColor });
        } else {
            setAttributes({ bgColor: val.hex });
        }
    }}
/>
```
