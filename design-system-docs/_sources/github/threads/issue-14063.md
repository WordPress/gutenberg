# Issue #14063: Placeholder Component README Should Describe the Component

- URL: https://github.com/WordPress/gutenberg/issues/14063
- Author: vkoves
- Created: 2019-02-22T20:45:56Z
- Updated: 2023-05-23T13:55:29Z

## Body

**Is your feature request related to a problem? Please describe.**

The [placeholder component's documentation](https://wordpress.org/gutenberg/handbook/designers-developers/developers/components/placeholder/) (the README) shows a usage example, but does not explain what the component is actually for and what it will do. The code has better documentation, saying in the [index JS](https://github.com/WordPress/gutenberg/blob/master/packages/components/src/placeholder/index.js):

> Renders a placeholder. Normally used by blocks to render their empty state.

**Describe the solution you'd like**

Add a description of the component to the README. I'm willing to take this on, but I wanted to open this issue to see if other folks agreed.

I also noticed that the parameters for the component are not documented at all, which makes it necessary to dig into the code to figure out the appropriate usage. Can/should the input parameters also 
be documented? Is there a component that has this well documented as an example?

**Describe alternatives you've considered**

None really. The documentation could be left as is, but if you _need_ to dig into a component's implementation to figure out how to use it, that usually indicates there's some room to add to the documentation.
