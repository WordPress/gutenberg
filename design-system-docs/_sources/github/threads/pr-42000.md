I think my current rule of thumb is:

- If it's less than 4px, use the exact value
- If it's size variant value, use the exact value (for readability, and because there's a 30px variant!)
- If it's related to spacing (margin/padding), prefer to use `space`

Assuming the main point of `space` is to encourage people to use multiples of 4px, it shouldn't _really_ matter whether the `space` util is used 🤞
