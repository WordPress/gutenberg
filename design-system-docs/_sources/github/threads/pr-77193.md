## Summary
  - Adds 4 new primitive ramp steps (`fgSurface3Active`, `fgSurface4Active`, `fgFillActive`, `fgFillInvertedActive`) following the existing
  `bgFill1`→`bgFill2` pattern (1.2:1 contrast)
  - Updates 6 semantic `fg-interactive` active tokens to reference the new primitives
  - Adds regression test ensuring active tokens always differ from idle
