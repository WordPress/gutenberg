Hi @mirka, I would like to propose a solution to deal with long values, Let me know if that approach is worth implementing or not?

A potential approach could be to introduce a new prop to `UnitControl`, such as `maxUnitWidth`, which would accept either a `string` or `number` value (e.g., `48` or `48px`). This value could then be passed to `UnitSelect` to dynamically adjust the width based on consumer preference, updating the `max-width` defined in `baseUnitLabelStyles` accordingly. 

Also, For mobile and smaller screens truncation can as it as around 48px?

I can create a draft PR to add the above approach.
