https://github.com/WordPress/gutenberg/pull/28817

All options expanded by default. _Maybe_ we could add a reasonable [`size` attribute](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/select#attr-size) to the `<select>` so it doesn't get too long. _Technically_ we could even add an `htmlSize` prop or something on the component that forwards to the `<select>` as a standard HTML `size` attribute so a consumer can set their own heights, but I'd rather not. We should keep the `multiple`-related code as simple as possible because as a components library we don't really recommend this usage and it isn't worth the maintenance cost.
