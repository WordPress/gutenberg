# Issue #65338: Deprecate ButtonGroup component

- Updated: 2024-12-20T23:09:44Z

## Body

## What problem does this address?

The component does two things:

- Wrap the buttons in a `role="group"`.
- Add styling to [make it look like a segmented control](https://github.com/WordPress/gutenberg/pull/65336).

As we can see from the usages in the Gutenberg app, `role="group"` is not semantically sufficient to make these buttons behave like a segmented control, and most consumers will not realize this. As such, most of our in-repo usages are inaccessible.

The outdated segmented control style is similar to the already deprecated [RadioGroup](https://wordpress.github.io/gutenberg/?path=/docs/components-radiogroup--docs), and is succeeded by the ToggleGroupControl style.

## What is your proposed solution?

- [x] #65339
- [x] [Soft deprecate](https://github.com/WordPress/gutenberg/issues/61099) the component. https://github.com/WordPress/gutenberg/pull/65429

Consumers who want to wrap their buttons in a `group` can do that with a plain `<div role="group">`.
