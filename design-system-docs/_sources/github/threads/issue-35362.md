### Description

I'm trying to work with the DateTimePicker component and finding some outdated documentation. 

It looks like we added support for the `isDayHighlighted` callback in [PR #22032](https://github.com/WordPress/gutenberg/pull/22032), but then recently removed it in [PR #29716](https://github.com/WordPress/gutenberg/pull/29716). However, the [README](https://github.com/WordPress/gutenberg/tree/trunk/packages/components/src/date-time#isdayhighlighted) for DateTimePicker was not updated to remove references to `isDayHighlighted`

### Step-by-step reproduction instructions

1. Go to [DateTimePicker component README](https://github.com/WordPress/gutenberg/tree/trunk/packages/components/src/date-time#isdayhighlighted) and verify that there is a reference to the `isDayHighlighted` callback.
2. Search Gutenberg codebase for `isDayHighlighted` and verify that [there are no results](https://github.com/WordPress/gutenberg/search?q=isDayHighlighted), except for the outdated reference in the README.
3. Also, review the recently merged [PR #29716](https://github.com/WordPress/gutenberg/pull/29716) to verify that the `isDayHighlighted` callback was removed.
