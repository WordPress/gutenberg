## Why?

- Using the latest version allows us to take advantage of the latest features and bug fixes, and reduces future maintenance overhead
    - I'm specifically interested in the new `experimentalComponentsManifest` option that allows for generating a complete "manifest" of component details ([example](https://github.com/storybookjs/mcp/blob/main/packages/mcp/fixtures/full-manifest.fixture.json)) that could be useful for various applications like MCP servers.
- Motivations for migrating from Webpack to Vite are outlined in #72488, primarily around alignment of tools toward an ESBuild-based toolchain (already implemented in `@wordpress/build`), dropping Webpack altogether

## How?

- Updates Storybook to v10
- Changes Storybook builder from Webpack to Vite
   - It was not originally my goal to make this migration here, though the upgrade broke some behaviors with Webpack like CSS Modules, and it ended up being simpler to do the migration here rather than try to sort out Webpack upgrade path while fully intending to move away from it anyways.
- Changes TypeScript `moduleResolution` option from `node` to `bundler`
   - This was noted in #74148, and was a more significant change than I expected. I think it's a very much _correct_ change for how we use TypeScript given how [the options are described](https://www.typescriptlang.org/tsconfig/#moduleResolution). It might be worth spinning this out as its own pull request to simplify the review of this one.

I'll follow with some specific inline comments to explain changes.
