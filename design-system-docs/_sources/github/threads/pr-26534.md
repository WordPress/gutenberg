## Description
Follow-up for #25628.

This PR proposes that we copy, paste and format the SCSS file from `react-dates` to the component where it is actually used rather than executing a patch on every `npm install` and referencing a file from `node_modules`.

## How has this been tested?
1. Run `npm install`.
2. Run `npm run build` and make sure it still works.
3. Open a new post in the block editor and ensure that the calendar still looks the same.
4. Run `npm run storybook:dev` and make sure that the calendar from `DateTimePicker` component still looks the same.
