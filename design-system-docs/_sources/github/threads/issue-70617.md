# Issue #70617: SelectControl has a larger font size in smaller viewports

- URL: https://github.com/WordPress/gutenberg/issues/70617
- Author: sejas
- Created: 2025-07-04T10:14:56Z
- Updated: 2025-07-08T00:46:36Z

## Body

### Description

We discovered that SelectControl changes its font size from 13px to 16px when the view port is lower than 782px
Partially related to https://github.com/WordPress/gutenberg/issues/59698
I didn't find this font-size change in the SelectControl Figma design: 
https://www.figma.com/design/yit32HxuUIGhBySt3IFPmG/WordPress-Design-System--Community-?node-id=16432-132811&t=5DpNZgnKAhb71Vef-0

Also, it doesn't make sense to change only the font size of the select and not the rest of the UI, so I think the font size increase is unintentional.

### Step-by-step reproduction instructions

1. Go to https://wordpress.github.io/gutenberg/?path=/docs/components-selectcontrol--docs
2. Reduce the width of the window to below 1082px.
3. Observe the font-size of the SelectControl increments
