Elevation (like every other tokens) is not part of the components package, but rather of the design system as a whole. Even technically, the elevation tokens are currently in `@wordpress/base-styles` — the components provided by the `@wordpress/components` package consume those tokens and therefore follow the design system.

In other words, from my perspective, the `@wordpress/components` package is a part of the design system's offering, as much as the token themselves.
