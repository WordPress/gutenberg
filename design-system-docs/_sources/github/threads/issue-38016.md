# Issue #38016: WordPress5.9 When using FontSizePicker with slider, if you select the size preset and then change the input area, an error occurs and the browser freezes.

- URL: https://github.com/WordPress/gutenberg/issues/38016

- Updated: 2022-08-09T15:38:42Z

## Body

### Description

When using the FontSizePicker with slider in WordPress 5.9 environment, if I select the size preset and then change the input area, an error occurs and the browser freezes.

- Size preset can be selected and changed.
- Custom size can be changed with the slider of Custom Size.
- Custom size can be changed in the input area of Custom Size.
- Select the Size preset and use the slider to change the size.
- When I select the Size preset and change the input area, an error occurs and the browser freezes

### Step-by-step reproduction instructions

1. Create a custom block using FontSizePicker with slider
2. If you select Size preset and change the input area, an error will occur and the browser will freeze

##  code snippet
Here is the edit.js code for the custom block used in recording.

```edit.js
import { __ } from '@wordpress/i18n';
import { useBlockProps, InspectorControls } from '@wordpress/block-editor';
import {
	PanelBody,
	FontSizePicker
} from '@wordpress/components';
import './editor.scss';
import { useState } from '@wordpress/element';

export default function Edit() {
	const fontSizes = [
		{
			name: __('Small', 'vk-blocks'),
			slug: 'small',
			size: '12px',
		},
		{
			name: __('Normal', 'vk-blocks'),
			slug: 'normal',
			size: '16px',
		},
		{
			name: __('Big', 'vk-blocks'),
			slug: 'big',
			size: '18px',
		},
		{
			name: __('Extra big', 'vk-blocks'),
			slug: 'extra-big',
			size: '21px',
		},
	];

	const fallbackFontSize = 16;
	const [fontSize, setFontSize] = useState(16);

	return (
		<div { ...useBlockProps() }>
			<InspectorControls>
				<PanelBody title={'FontSizePicker setting'}>
					<FontSizePicker
							fontSizes={fontSizes}
							value={fontSize}
							fallbackFontSize={fallbackFontSize}
							withSlider={true}
							onChange={setFontSize}
						/>
				</PanelBody>
			</InspectorControls>
			<div>
				<p style={{ fontSize: fontSize}}>
					{ __(
						'Example Plugin – hello from the editor!',
						'example-plugin'
					) }
				</p>
			</div>
		</div>
	);
}
```
