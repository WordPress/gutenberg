### cr0ybot on 2020-12-30T01:42:14Z

URL: https://github.com/WordPress/gutenberg/pull/21088#issuecomment-752297993

I think this component is neat and I wanted to use it in a custom block because I found it in the live Block Editor Handbook: https://developer.wordpress.org/block-editor/components/text/

However, this live documentation makes no mention of this being an `__experimental` export. Took me a while to figure out why my block kept failing. I wasn't importing it correctly, though the documentation is pretty explicit in it's usage section:

```
import { Text } from '@wordpress/components';
```

is really meant to be

```
import { __experimentalText as Text } from '@wordpress/components';
```

and thus is probably not ready for prime time, AKA live in the public Block Handbook docs.
