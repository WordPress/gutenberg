# Issue #38222: Color Component: No color contrast warning for link color against background color

## Body

### Description

Currently, in 5.9 there is not a color warning for the link color when compared against the background color. There is one in place for text color against background color and the same needs to exists for link color. 

### Step-by-step reproduction instructions

1. Add a paragraph block/write some text.
2. Make the background black in block settings. 
3. Make link color black. 
4. See no accessibility warning.
5. Make text color black, see accessibility warning.
