## Body

This PR refactors the routing logic in `NavigatorProvider`. It removes all the `useRef`s and `useEffect`s, and moves all state management to a `useReducer` hook. There is now one reducer to rule them all: the list of routes in `screens`, the navigation history in `locationHistory`, and the currently matched route in `matchedPath`. They are all updated on action dispatches. The only job left to do for `NavigationProvider` is to create a very simple binding of the reducer state to a context value.

Makes the `NavigatorProvider` easier to understand and also to replace it in the future with some standardized router.

**How to test:** Everything should work the same way as before: try out various routing scenarios in Site Editor and other places.
