## Description
Adds two new utilities for deriving background and text color from a small set of supported colors. This is used by the Tag and Badge components to determine what colors to use for each variation.

## How has this been tested?
Test this in Storybook is the best way because we want to be able to test that the contrast ratios are enough for each color. I had to make some tweaks for three of the colors from G2 because they did not have sufficient color contrasts. Using the Axe browser extension or the built in accessibility tools in Firefox, check each rendered example in the storybook story here: `/iframe.html?id=components-experimental-background-colors--default&args=` (go to that URL after running `npm run storybook:dev`)

Ensure that each example has the sufficient color contrast to have at least 4.5 (i.e., AA) contrast.
