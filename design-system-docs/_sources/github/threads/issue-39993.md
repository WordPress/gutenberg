# Issue #39993: LetterSpacingControl: Add min/max limit to avoid letters overlapping and extra space

## Body

### Description

While reviewing #39642, I found an issue there is no limit for letter spacing. If negative input is supplied letters overlap and mess the UI. There should be some min and max limit to control this weird behaviour.

As part of the investigation I found we need to make changes here: 
https://github.com/WordPress/gutenberg/blob/trunk/packages/block-editor/src/components/letter-spacing-control/index.js#L37

### Step-by-step reproduction instructions

1. Create a new post or page.
2. Add `site-title` block and write some text.
3. Change letter spacing to some negative value.
4. Save and publish.
5. Open same post and see letters overlapping.
