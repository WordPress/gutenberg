# Issue #69901: Block More Options: 'Reset all' should close the settings popup

- URL: https://github.com/WordPress/gutenberg/issues/69901
- Author: nikunj8866
- Created: 2025-04-15T05:05:18Z
- Updated: 2025-04-17T06:52:24Z
- Comments: 3 of 3

## Body

## What problem does this address?
<!--
Please describe if this feature or enhancement is related to a current problem
or pain point. For example, "I'm always frustrated when ..." or "It is currently
difficult to ...".
-->
Currently, when a user selects Reset all within any block option popup (e.g., Border, Typography, etc.), the settings popup remains open. This behavior is inconsistent with expected UX patterns and could lead to confusion for users who expect the panel to close after a reset action.

![Image](https://github.com/user-attachments/assets/45d22be1-c8ca-4d32-93d1-393ad4128b33)

## Steps
1. Add any block to a post/page.
2. Click on the More options menu (three dots) of a block setting, for example, Border.
3. From the opened settings popup, click on Reset all.

## What is your proposed solution?
<!--
Please outline the feature or enhancement that you want and how it addresses any
problem identified above.
-->
Automatically close the popup panel after clicking on Reset all within block settings for a smoother and more intuitive user experience.
