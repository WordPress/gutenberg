# Issue #17223: disabled components CSS pointer events

- URL: https://github.com/WordPress/gutenberg/issues/17223

- Created: 2019-08-27T21:15:02Z
- Updated: 2019-09-14T15:31:33Z

## Body

**Describe the bug**

I am creating some blocks with Twitter Bootstrap components inside.
A noticed that the [stretched links](https://getbootstrap.com/docs/4.3/utilities/stretched-link/) have a `pointer-events: auto;` on the `::after` pseudo-element.

this makes that the link is still clickable.

**Expected behavior**
Following should fix this.
`.components-disabled *,
    .components-disabled *::before,
    .components-disabled *::after {
      pointer-events: none;
    }`

Kind regards
