## Body

## What problem does this address?

While using the `ColorPalette` component to build new controls a couple of possible improvements to the `ColorPalette` UI were [suggested](https://github.com/WordPress/gutenberg/pull/37769#pullrequestreview-872997703). 

These were:

>  I'm not sure that the current UI (a rectangle displaying the hex of the currently selected color, if there's one) is a clear enough sign to the user that they can click it to enter a custom color

and

> have we considered adding a border around the ColorPicker when picking a custom color? Currently it's edges are very faintly marked by box shadow (I think), and the lack of a clear border around it may be visually confusing to some users.

<img width="367" alt="Screen Shot 2022-02-08 at 2 13 53 pm" src="https://user-images.githubusercontent.com/60436221/152917006-90e1b135-f629-4d55-8090-0f658230d5f1.png">


## What is your proposed solution?

1. Regarding the custom color swatch, could some form of label, help text or tooltip be added without excessively cluttering the UI?

2. Would a border for the `ColorPicker` popover add visual delineation to alleviate the concern raised?
