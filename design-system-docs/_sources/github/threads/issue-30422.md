## Description
<!-- Please write a brief description of the bug. -->
When a `Tooltip` element is used with the disabled `Button`, it adds `,` at the end and also makes a button clickable

Can be related to https://github.com/WordPress/gutenberg/pull/27529
## Step-by-step reproduction instructions
<!--
Please list the steps needed to reproduce the bug. For example:
1. Go to '...'
2. Click on '...'
3. Scroll down to '...'
-->
Wrap disabled `Button` in `Rooltip`
## Expected behaviour
<!-- Please describe what you expected to happen. -->
`Button` is not clickable

## Actual behaviour
<!-- Please describe what actually happened. -->
`Button` is clickable, and comma is added
