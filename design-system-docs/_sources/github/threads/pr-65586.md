## How?
<!-- How is your PR addressing the issue at hand? What are the implementation details? -->

- [x] Export it from components without the `__experimental` prefix.
- [x] Switch subcomponents to dot notation if applicable.
- [x] Keep the old `__experimental` export for backwards compatibility.
- [x] Remove experimental callout from readme.
- [x] Change all imports of the old `__experimental` in GB and components to the one without the prefix (including in Storybook stories).
- [x] Update the docs (readme, JSDocs, Storybook) to refer to the new unprefixed component.
- [x] Add the component storybook `id` (get it from the storybook URL) to the `PREVIOUSLY_EXPERIMENTAL_COMPONENTS` const array in `manager-head.html` so that old experimental story paths are redirected to the new one.
- [x] Add a changelog for both the promotion (enhancement) and the deprecation.

Docs tweaked slightly. No unstable props (other than the 40px sizes one, and `__experimentalIsRenderedInSidebar` which is tracked in https://github.com/WordPress/gutenberg/issues/65581). If no one has any concerns, this one should be a straightforward merge.
