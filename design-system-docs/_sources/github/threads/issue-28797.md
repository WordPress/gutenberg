# Issue #28797: Combined wp-components JS/CSS add unnecessary delays

- URL: https://github.com/WordPress/gutenberg/issues/28797
- Author: iandunn
- Created: 2021-02-05T18:19:12Z
- Updated: 2021-03-11T19:39:44Z
- Comments: 4 of 4

## Body

## What problem does this address?

When a plugin wants to use a component like `<Button>`, they have to enqueue the entire `wp-components` JS and CSS dependencies. 

Those files are huge -- _670k and 108k minified on disk!_ -- and I'm guessing that most of the contents aren't even used in most cases. 

In the plugin I'm currently working on, I'm using `Button, Card, CardHeader, CardBody, Icon, Notice, RangeControl, Spinner, Tooltip`, and Chrome dev tools says that 64% of the JS and 98% of the CSS are unused.


## What is your proposed solution?

The existing combined files would need to continue existing for back-compat, but we could distribute additional files for the  individual modules, like `wp-components-button`, so plugins can enqueue only what they need.

In the case of JS, that would also set the stage for a future enhancement that would allow individual components to be imported as ES modules.


## Alternative solution

There could also be a middle ground, where related components are grouped together, like "input" (for `Textarea`, `FormToggle`, etc), "inspector" (for `Panel*`), "colors", "icons", etc.

That might be more convenient to maintain and use, and wouldn't add too much unnecessary code. If you're using `Card`, then you'll be using `CardBody` most of the time too.


## Downsides

Having both `wp-components` and `wp-components-*` files will sometimes create a situation where plugin `A` is enqueueing `wp-components-button`, but plugin `B` is enqueueing the entire `wp-components`, making the situation even worse than before.

I'm guessing that things would still be faster on the whole, though, since many plugins only load on individual screens.

We could mitigate the impact by calling a `_deprecated_dependency()` function (similar to `_deprecated_function()` when the combined asset is enqueued.
