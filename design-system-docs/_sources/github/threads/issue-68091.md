# Issue #68091: `Badge`: Add property to toggle truncation

- URL: https://github.com/WordPress/gutenberg/issues/68091
- Author: jameskoster
- Created: 2024-12-18T13:21:41Z
- Updated: 2025-01-02T12:45:23Z

## Body

This came up while trying to tackle https://github.com/WordPress/gutenberg/issues/68020. 

The anchor 'badge' in List View is truncated to prevent it from taking over the entire row:

<img width="349" alt="Image" src="https://github.com/user-attachments/assets/c528db10-1aaf-4dec-8d63-f929dd5e288c" />

In order to replace this ad hoc element with the `Badge` component, it would need to be updated to support truncation.

The [`Text`](https://wordpress.github.io/gutenberg/?path=/docs/components-experimental-text--docs) component already supports truncation, so perhaps this is just a case of utilising `Text` inside `Badge`, and providing a way to pass the `truncate` property down to `Text`.

cc @WordPress/gutenberg-components
