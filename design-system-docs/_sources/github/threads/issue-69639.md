# Issue #69639: Text/Textarea Control lacks theming support

- Created: 2025-03-20T07:07:42Z

## Body

### Description

The **Text/Textarea Control** component lacks proper theming support, causing it to appear with a white background and black text in dark mode. To ensure consistency across the UI, it should be appropriately styled for dark mode with the correct background, text colors, and focus, similar to how the `SearchControl` component has been implemented.

Feel free to close this issue if a similar one already exists or if this behavior is intentional.

### Step-by-step reproduction instructions

1. Navigate to the [storybook](https://wordpress.github.io/gutenberg/?path=/docs/components-textcontrol--docs&globals=componentsTheme:darkBg) documentation.
2. Observe that the Text/Textarea Component doesn't adapt well with the dark theme.
