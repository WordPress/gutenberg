## Body

### Description

`ToggleControl` text overflows when it has a long label.
As the label gets longer, the text overshadows the toggle button.

### Step-by-step reproduction instructions

- Access[ the ToggleControl section of the Storybook](https://wordpress.github.io/gutenberg/?path=/story/components-togglecontrol--default).
- Enter long text in the control panel label.
- Ensure that the text covers the toggle button as the label gets longer.

### t-hamano on 2022-10-30T02:24:18Z

URL: https://github.com/WordPress/gutenberg/issues/45381#issuecomment-1296069613

@sharukhkhanajm 

Thank you for your interest in this issue.
`HStack` is a component for arranging child elements horizontally in a Flex layout. For a grid layout, the [Grid](https://github.com/WordPress/gutenberg/tree/trunk/packages/components/src/grid) component would be appropriate.

Alternatively, I believe that the following style could be applied to the label to solve the issue:

```
flex-grow: 1;
flex-basis: 0;
```
