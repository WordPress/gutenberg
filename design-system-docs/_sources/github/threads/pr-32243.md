## Description
<!-- Please describe what you have changed or added -->

- Replace the current implementation of the `<Card />` component with the new g2 implementation (which, prior to this PR, sits in [`packages/components/src/ui/card`](https://github.com/WordPress/gutenberg/tree/4857ad58c1241b3d63d21a6880c989b85746c3dc/packages/components/src/card).
- Keep all components and their existing APIs unchanged. The only exceptions are:
  -  The `isElevated` prop on the `<Card />` component is being soft-deprecated in favour of a new `elevation` prop (which enables fine-grain control on the card's elevation)
  - The `<CardMedia />` component didn't exist in the g2 implementation and was created directly in this PR (pretty much a 1:1 with the current version)
  - The `<CardDivider />` component didn't exist in the g2 implementation and was created directly in this PR. Although its APIs are the same as the old version, internally it now extends the `<Divider />` component
  - The border color has slightly changed to match the same color used by other g2 components
  - There's a new possible value for the `size` property: `none`
  - The CSS `padding` associated to the `size` property has slightly changed to match the spacing system used by other g2 components (used by `<Card />`, `<CardBody />`, `<CardHeader />` and `<CardFooter />`)
