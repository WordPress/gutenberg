# Issue #39433: CustomSelectControl: Make hover styles consistent with SelectControl

- URL: https://github.com/WordPress/gutenberg/issues/39433
- Author: mirka
- Created: 2022-03-14T17:05:02Z
- Updated: 2023-05-23T15:00:46Z
- Comments: 0 of 0

## Body

Related: #39400

## What problem does this address?

`CustomSelectControl` has hover styles (color and cursor) that are not consistent with `SelectControl`.

| CustomSelectControl | SelectControl |
|--------|-------|
|<img src="https://user-images.githubusercontent.com/555336/158222126-546fa457-2cee-4eb5-ad2f-2bcb7b7c8ecc.gif" alt="On hover, CustomSelectControl changes its text color to blue and the cursor to pointer" width="200">|Has no hover styles.|

## What is your proposed solution?

For consistency, we can start by removing the hover styles on `CustomSelectControl`. Though in a future iteration we may be adding back some form of hover styles.
