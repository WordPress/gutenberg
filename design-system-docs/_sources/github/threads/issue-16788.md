# Issue #16788: Tags and `FormTokenField` disappear when user don't add comma or click Enter Key

- URL: https://github.com/WordPress/gutenberg/issues/16788
- Author: phpbits
- Created: 2019-07-29T05:16:57Z
- Updated: 2025-12-15T08:16:21Z
- Comments: 3 of 3

## Body

**Describe the bug**
`FormTokenField` bug on first value. Whenever you add value and do not add comma or press Enter Key the value disappears.

**To reproduce**
Steps to reproduce the behavior:
1. Create a post
2. Add only one tag and do not press Enter Key or add comma
3. Click the Paragraph block
4. Return to the Document inspector and the tag added is missing

**Expected behavior**
Value should be added automatically.

### joedolson on 2024-04-30T15:42:15Z

URL: https://github.com/WordPress/gutenberg/issues/16788#issuecomment-2085719564

As @afercia commented on PR #16849, the solution to this issue is to have a button to save tags. 

Any behavior we choose that happens on a change of focus or loss of visibility is potentially unpredictable. Right now, there are no instructions given to the user about how to save tags, only how to separate them (which also adds them, but isn't stated.)

A simple 'Add Tags' button would both communicate to the user that this is the mechanism to save a tag and provide them with the context that if they have *not* taken this action, the tags will not be saved.

### joedolson on 2024-04-30T15:43:45Z

URL: https://github.com/WordPress/gutenberg/issues/16788#issuecomment-2085722643

But the problem here is, in part, just that the value disappears, rather than retaining the userstate when the change of focus happens. We don't want the value saved to the database when the focus changes, but it should be retained for the user, so that they can save it later.
