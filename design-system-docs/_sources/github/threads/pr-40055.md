## Body

Part of #38934

## What?

Fixes inconsistencies in the main black color used in the Global Styles sidebar. The correct black is `#1e1e1e`.

## Why?

For visual consistency.

## How?

- Add a local icon wrapper component `IconWithCurrentColor` that adds a `fill: currentColor` style to the icon.
- By adding `color: inherit` to the `ItemGroup` Item, ensure that the button color isn't overridden by a UA color.
- Change the `color` of the `Surface` component from `#000000` to `#1e1e1e`. (This wrong color was being inherited throughout the first sidebar view.)
- Fix the color of the "Beta" tag in the sidebar header.

## Testing Instructions

Check the colors in the Global Styles sidebar.
