**Describe the bug**

The `MenuItemsChoice` component appears to depend on external stylesheets in order for the selected and nonselected items to line up correctly.

Here's what it looks like in the `MoreMenu` (implemented in `ModeSwitcher` in `./packages/edit-post/src/components/header/mode-switcher/index.js`)
