# Issue #21370: Popover not closing on click-outside when used in Modal

- URL: https://github.com/WordPress/gutenberg/issues/21370
- Author: HardeepAsrani
- Created: 2020-04-03T01:34:30Z
- Updated: 2022-05-31T01:14:55Z
- Comments: 3 of 3

## Body

**Describe the bug**
If you use the Popover component or anything that uses the Popover component, such as ColorPalette, in Modal component then it doesn't close once you click outside.

**To reproduce**
Steps to reproduce the behavior:
1. Add ColorPalette control to Modal.
2. Click on Custom color which opens color-picker popover.
3. Try clicking outside and it won't close.

**Expected behavior**
Like in the rest of the editor, it should close.

**Screenshots**
Here's a screencast of the issue: https://www.loom.com/share/bcd8bb35dac5445c967b2d6708f6ceb9

**Desktop (please complete the following information):**
 - OS: MacOS
 - Browser Firefox
 - Version 74.0

**Additional context**
- Gutenberg 7.8.1

### HardeepAsrani on 2020-04-03T01:49:38Z

URL: https://github.com/WordPress/gutenberg/issues/21370#issuecomment-608184324

If you want to test it pretty quickly, use this:

```
( function( blocks, element, components ) {
	var el = element.createElement;
	var Modal = components.Modal;
	var ColorPalette = components.ColorPalette;

	blocks.registerBlockType( 'gutenberg-examples/example-01-basic', {
		title: 'Example: Basic',
		icon: 'universal-access-alt',
		category: 'layout',
		example: {},
		edit: function() {
			return el(
				Modal,
				{ title: 'Hello World' },
				el(
					ColorPalette,
					{
						value: '#ffffff',
						onClick: e => console.log( e )
					}
				)
			);
		},
		save: function() {
			return el(
				'p',
				'Hello World, step 1 (from the frontend).'
			);
		}
	});
}(
	window.wp.blocks,
	window.wp.element,
	window.wp.components,
	window.wp.blockEditor
) );
```

Of course, it's a bad example but it shows the issue. :)
