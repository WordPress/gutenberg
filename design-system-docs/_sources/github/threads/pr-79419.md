## Body

## What?

Follow up to #65751

Remove the deprecated `__next40pxDefaultSize` prop from `BoxControl`, making the 40px default size the permanent default.

## Why?

The soft deprecation was introduced in WP 6.7 and scheduled to be removed in WP 7.1.

## How?

- Remove `__next40pxDefaultSize` from the `BoxControl` public API and remove `maybeWarnDeprecated36pxSize`.
- Keep passing `__next40pxDefaultSize` internally to embedded `UnitControl` and `RangeControl` until those primitives are hard-deprecated.
- Remove all monorepo usages of the prop on `BoxControl`.
- Remove `BoxControl` from the `components-no-missing-40px-size-prop` ESLint rule and add a restricted-syntax rule for passing the prop to `BoxControl`.

## Testing Instructions

1. Open Storybook to **Components / BoxControl** and smoke test the default story.
2. Toggle linked/unlinked sides, change values, and use reset.
3. Confirm inputs render at 40px height without the prop, and no console warning should be logged.
