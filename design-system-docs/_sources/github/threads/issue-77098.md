# Issue #77098: UI: Add `LinkButton`, `IconLinkButton` components

- URL: https://github.com/WordPress/gutenberg/issues/77098
- Author: mirka
- Created: 2026-04-07T13:54:05Z
- Updated: 2026-06-04T12:18:58Z
- Comments: 5 of 5

## Body

The current `Button`/`IconButton` components in `@wordpress/ui` don't support rendering as anchor elements (links). This is an [upstream limitation](https://base-ui.com/react/components/button#rendering-links-as-buttons) but a reasonable one, since the elements require different semantics and have different props they can accept.

In Gutenberg, there are about 12 instances of link buttons and 3 instances of icon link buttons. We probably need a separate component to support this pattern.
