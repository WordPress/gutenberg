This is expected. As mentioned in an [earlier comment](https://github.com/WordPress/gutenberg/pull/33729#discussion_r682723977), interpolated functions only work for `styled` components.

Since in this case we're using the `css` function, we have to keep the final `()` for it to work properly. We're mitigating this "limitation" by adding the `rtl.watch()` to the list of `useMemo` dependencies, to ensure that styles are recalculated in case the locale's writing direction changes.

After discussing with @sarayourfriend , we agreed that it is best not to immediately execute the function returned by `rtl()`.

Emotion, in fact, will [recognize the function and interpolate the returned value every time the props update](https://emotion.sh/docs/styled#changing-based-on-props) (the `props` will be also passed as an argument to the interpolated function, although that doesn't matter in this case).

This means that the styles wrapped in the `rtl` function will be able to be re-computed in case the page's language gets updated at runtime.

```suggestion
				${ rtl( {
					marginLeft:
						! isColumn && ! isReverse ? space( gap ) : undefined,
					marginRight:
						! isColumn && isReverse ? space( gap ) : undefined,
				} ) }
```
