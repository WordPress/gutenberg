# Issue #21022: Toolbars don't show selected item in sidebar

- URL: https://github.com/WordPress/gutenberg/issues/21022
- Author: philbuchanan
- Created: 2020-03-19T15:34:28Z
- Updated: 2020-05-01T13:37:01Z
- Comments: 4 of 4

## Body

Toolbars do not show which item is selected. For example, the heading block sidebar:

<img width="271" alt="Screen Shot 2020-03-19 at 11 23 00 AM" src="https://user-images.githubusercontent.com/1783595/77083816-767b5980-69d4-11ea-96ec-b509d18e944f.png">

It appears the `is-pressed` class is not applying any styles to the `button` element in the toolbar.

**To reproduce**
Steps to reproduce the behavior:
1. Add a `heading` block
2. Select various heading levels (e.g. `h2`, `h3`)

**Expected behavior**
The current heading level should be selected.

**System**
- macOS 10.15.3
- Safari version 13.0.5 (also tested in Chrome version 80.0.3987.149)
- WordPress 5.3.2
- Gutenberg plugin version 7.7.1
