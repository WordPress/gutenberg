# Issue #43945: InputControl: See if reducer actions can be typed better

## Body

## What problem does this address?

Reducer functions currently require a bit of typecasting to result in valid TypeScript, since the action's [`event`](https://github.com/WordPress/gutenberg/blob/e6dd3b19d186c61fa8894dc8fdfb4fa716e3b010/packages/components/src/input-control/reducer/actions.ts?rgh-link-date=2022-09-06T16%3A50%3A57Z#L24) is not typed according to the specific triggering action.

### Some examples

- https://github.com/WordPress/gutenberg/pull/43791#discussion_r961028727
- https://github.com/WordPress/gutenberg/pull/43791#discussion_r963095401

## What is your proposed solution?

See if we can use generics to type the actions so consumers can use type narrowing to get the correct event type in their reducer functions.
