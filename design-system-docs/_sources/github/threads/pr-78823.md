## Body

## What?

Simplifies the shared `@wordpress/ui` focus ring utility styles, removing the transition and an unused force-colors mode tweak.

## Why?

The focus ring utility's `transition` shorthand is often overridden by component-level transitions, which makes the focus ring animation inconsistent across call sites.

## How?

Removes the shared focus ring transition and base outline styles. The utility now applies the outline and outline offset only in the active focus states.

## Testing Instructions

1. Open a UI component that uses the shared focus ring utility, such as `Button`, `Link`, or form controls.
1. Focus the component.
1. Confirm the focus ring appears without relying on a transition.
1. Check that there are no regressions in forced-colors mode.
