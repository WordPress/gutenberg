# Issue #70063: BaseControl: Prop docs says it's polymorphic but it's not

- URL: https://github.com/WordPress/gutenberg/issues/70063
- Author: mirka
- Created: 2025-05-06T11:42:58Z
- Updated: 2025-05-14T11:19:56Z
- Comments: 9 of 9

## Body

## What problem does this address?

The prop docs for the `BaseControl` component says that it takes an `as` prop, due to the prop type definition here:

https://github.com/WordPress/gutenberg/blob/8b7b04ab0c95abd52fb0ef6c7cbb7ec6b440ea23/packages/components/src/base-control/index.tsx#L31

But in reality the `as` prop is not passed down to the internal wrapper component.

## What is your proposed solution?

We could fix it by passing down the `as` prop, but since we'll eventually want to move away from Emotion anyway (which means no more `as` props), maybe we should just fix the docs for now (`WordPressComponentProps< BaseControlProps, null, false >`).
