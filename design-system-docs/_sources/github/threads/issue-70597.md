# Issue #70597: CustomSelectControl dropdown is not fully visible when near the bottom of the viewport

- URL: https://github.com/WordPress/gutenberg/issues/70597
- Author: ddryo
- Created: 2025-07-03T07:21:57Z
- Updated: 2025-07-03T16:27:42Z
- Comments: 5 of 5

## Body

### Description

When using the ‎`CustomSelectControl` component near the bottom of the editor viewport, the dropdown menu is partially or almost completely hidden below the visible area of the screen. This prevents users from seeing or selecting most of the options.

### Step-by-step reproduction instructions

 1. Insert a Group block.
 2. Select the Group block and open the “Position” setting.
 3. Click on the Position select box to open the dropdown menu.
 4. Observe that the dropdown list is cut off at the bottom of the screen, and not all options are visible.
