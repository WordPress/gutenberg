# Issue #66805: Storybook: Remove "experimental" category in favor of a badge

- URL: https://github.com/WordPress/gutenberg/issues/66805
- Author: tyxla
- Created: 2024-11-07T07:17:58Z
- Updated: 2025-08-11T23:41:07Z

## Body

In #66275 we're currently in the process of reorganizing the components by categories. 

However, we separate components by stable and experimental already, and as a result, we get multiple directories with the same category:

Stable:
![Image](https://github.com/user-attachments/assets/0e248b78-b548-4c6b-8d40-9c0c3d4fb115)

Experimental:
![Image](https://github.com/user-attachments/assets/9af25ec6-9e47-4b4b-bd72-9466a33ebadf)

Ideally, we shouldn't have that multi-level distinction by category, and the categories would be at the top level. 

To achieve that, I think we can mark the experimental components with a badge, just like we currently mark WIP or private components.

cc @WordPress/gutenberg-components
