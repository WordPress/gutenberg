## Body

Hai 👋 !

I recently noticed a neat UI pattern (demo in the gif below). When adjusting the columns via dragging, there's a popover that clearly shows the values. These values update as you drag. I think it's a wonderful interaction and very user-friendly!

![Screen Capture on 2020-02-13 at 15-10-16](https://user-images.githubusercontent.com/2322354/74474433-818e1780-4e73-11ea-85a7-90ed1374784d.gif)

I can see this being useful in many places they may require finer movements/adjustments. If this were added as a general component in `@wordpress/components`, it could be added to the Columns block to enhance the experience. It can also be used elsewhere, in core blocks or custom blocks as needed.

I sat with a bit to come up with a good name for this component... the best one I could think of was `InfoPop`.
