# Issue #61163: DateTimePicker: AM/PM switcher is not screen reader accessible

- URL: https://github.com/WordPress/gutenberg/issues/61163
- Author: mirka
- Created: 2024-04-26T16:31:00Z
- Updated: 2024-08-26T18:45:34Z
- Comments: 10 of 10

## Body

## What problem does this address?

The AM/PM toggle that appears when `is12Hour={ true }` only expresses state through visual styling, and cannot be distinguished by screen readers.

<img width="202" alt="AM/PM switcher" src="https://github.com/WordPress/gutenberg/assets/555336/1902dc29-62fe-43b5-a927-7ce817944b39">

## What is your proposed solution?

A similarly styled component, [`RadioGroup`](https://wordpress.github.io/gutenberg/?path=/docs/components-radiogroup--docs), is already deprecated in favor of [`ToggleGroupControl`](https://wordpress.github.io/gutenberg/?path=/docs/components-experimental-togglegroupcontrol--docs). Since we don't really use this UI pattern anymore, can we just replace it with a ToggleGroupControl? @WordPress/gutenberg-design
