# Issue #29913: PanelBody arrow may overlap its title

- URL: https://github.com/WordPress/gutenberg/issues/29913
- Author: MatzeKitt
- Created: 2021-03-16T20:19:45Z
- Updated: 2021-03-18T00:42:22Z

## Body

## Description
The German translation for “[Ordered list settings](https://github.com/WordPress/gutenberg/blob/master/packages/block-library/src/list/ordered-list-settings.js#L10)” is longer than the available space in the PanelBody title area but not long enough to wrap into a new line.

## Step-by-step reproduction instructions
1. Set your WordPress to German.
2. Create a list block.
3. Switch list to ordered list.
4. Look into the block sidebar.

## Expected behaviour
Arrow does not overlap its title.

## Actual behaviour
Title may get overlapped by the PanelBody arrow.

## Proposed solution

Add a `padding-right: 48px;` to the `.components-panel__body-toggle.components-button` [here](https://github.com/WordPress/gutenberg/blob/master/packages/components/src/panel/style.scss#L79) to add a restricted zone for the title.
