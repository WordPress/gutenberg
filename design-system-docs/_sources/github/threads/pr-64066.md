# History by version (unit tests)

## v0.3.x (from v0.3.13)

At v0.3.13, tests fail:

<img width="427" alt="image" src="https://github.com/user-attachments/assets/26b170d2-a7ee-40b5-9a8e-cf66d0fb3da5">

The reason is tests need to give some components a bit more time to render since Ariakit uses some timers under the hood. Fixed (e52022c6bec8f9a5eba801de23c4b416bebdebcd)  by replacing RTL's `render` with `@ariakit/test`'s `render` - including the [local temporary fork with `rerender` support](https://github.com/ariakit/ariakit/issues/3939#issuecomment-2251499387) (ffe79281867cacbb99f9eef546b0dfc25e8f1b70).

After addressing, all tests pass in all v0.3.x versions.

## 0.4.x

<img width="439" alt="image" src="https://github.com/user-attachments/assets/84b3c475-67ec-48f7-a384-4ebb5088e223">

[This diff from the previous PR](https://github.com/WordPress/gutenberg/pull/62947/files/4c022ed8d80fdce62795e3c0895fd3dfcbc08421..114badda5f68770118090baaf032c1a19b4cf84a) has information about all root causes for test failures.

Essentially, we're impacted by three Ariakit changes in v0.4.0:

- [Public data attributes have now boolean values](https://ariakit.org/changelog#public-data-attributes-have-now-boolean-values) (breaking change, fixed in ce0b7f3cf9a1713a5c8f8cd38f1367e7a18c8104 & ff470ad07eabdc6f8298a12198561807673f8251)
- [Improved animation support](https://ariakit.org/changelog#improved-animation-support) (breaking change, fixed in e39dc495b6af1c1dc027eeedb6ec0190070349fb)
- [Tooltips no longer use aria-describedby to associate the tooltip content with the anchor](https://ariakit.org/changelog#other-updates-6) (non-breaking change, fixed in 5f705ebe82171a9808b808777dc08564a67161d7)

After addressing, all tests pass between v0.4.0 and v0.4.5.
