# Issue #45094: UnitControl: normalize wrapper classnames

- URL: https://github.com/WordPress/gutenberg/issues/45094
- Author: ciampo
- Created: 2022-10-19T08:16:47Z
- Updated: 2022-11-24T17:08:01Z
- Comments: 2 of 2

## Body

As discussed in https://github.com/WordPress/gutenberg/pull/41860#discussion_r996049365, we should try to normalize the way `UnitControl` applies the `className` prop to its internal markup — in particular, the general expectation is that `className` applies to the outer wrapper (which is currently not the case).

This refactor would also include changes to the recently introduced `__unstableWrapperClassName` prop.

One option that could be worth exploring could be to remove the outer wrapper altogether, which would allow us to simplify the styles with minimal disruption.
