# Issue #50738: InputControl (& related components) focus style doesn't support Windows High Contrast mode

- URL: https://github.com/WordPress/gutenberg/issues/50738
- Author: afercia
- Created: 2023-05-18T12:33:38Z
- Updated: 2023-07-24T13:05:58Z

## Body

### Description

Discovered while reviewing https://github.com/WordPress/gutenberg/pull/50609

It appears the focus style provided by `BackdropUI` [only provides a box-shadow style](https://github.com/WordPress/gutenberg/blob/6725f29434ebf538f3ba2440b5f83711a1283711/packages/components/src/input-control/styles/input-control-styles.tsx#L274-L276).

In Windows High Contrast mode box-shadows aren't visible. That's the reason why in most places we do provide a transparent outline, something along these lines:

```
// Windows High Contrast mode will show this outline, but not the box-shadow.
outline: 2px solid transparent;
```

`BackdropUI` should be updated to provide the transparent outline together with the blue box-shadow for the focus style.

### Step-by-step reproduction instructions

- Test on Windows.
- Enable Windows High Contrast mode
- Use the keyboard and move focus to any component that uses `BackdropUI`.
- Observe there's no focus style.
- Note: easiest way to test: check [the input control component in the storybook](https://wordpress.github.io/gutenberg/?path=/story/components-experimental-inputcontrol--default).
