## Body

Related: #64340

## What problem does this address?

As discussed previously in https://github.com/WordPress/gutenberg/pull/73931#discussion_r2611954098 and https://github.com/WordPress/gutenberg/pull/73931#issuecomment-3660919463, the current set of typography tokens include too few opinions around how they should be combined. There would be value in having opinionated combinations of the available typography aspects.

## What is your proposed solution?

Add new design tokens following [DTCG specification for `"$type": "typography"`](https://www.designtokens.org/tr/2025.10/format/#typography-component-references) for opinionated design system font combinations. 

At a minimum, these should cover body and heading sizes (e.g. `body-sm`, `heading-xl`, etc.).

This could be used in combination with a `Text` component to conveniently use these styles, such as through a `preset="body-sm"` or `variant="body-sm"` prop.

As discussed in #74980, we're going to start with exposing presets through component APIs rather than the base tokens themselves. This was implemented as part of #75870, where type presets are exposed through the `Texts` component's `variant` prop.

There may still be value in systematizing the font family through the tokens themselves, but with the lack of current demonstrated need and [added overhead of e.g. CSS property proliferation](https://github.com/WordPress/gutenberg/pull/74980#issuecomment-3848766980), let's close this as fulfilled for now through #75870.
