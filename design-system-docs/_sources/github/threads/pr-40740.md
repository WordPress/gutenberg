## What?

Right now, we have two popover components: 

 - The historical Popover component with its weird (bad) API and custom internals (hard to follow)
 - A potentially new Popover component called Flyout which a better but very limited API and without a clear plan to move from the old one to the new one.

This PR consolidates by removing the second one (it's unused) and refactoring the first one to use [floating-ui](https://floating-ui.com/docs/react-dom) to drastically simplify it which allows us to be iterated on in terms of props... in order to make a better component without breaking changes.

There's some remaining work to do but the biggest/hardest part is done already.

## Why?

Consolidation and a path forward for better APIs.

**Notes**

- [x] Support the third part of the "position" prop
- [x] Deprecated the position prop
- [x] Test extensively
- [x] Potentially bring back the animation
- [x] Support block multi-selection (top and bottom in anchorRef) 
- [x] Update the documentation for the Popover component

## Testing Instructions

Test position and behavior of all kind of popovers:

 - Dropdowns
 - Tooltips
 - Block Toolbar
 - Block in between inserter
 - Mobile/Desktop
 - ...
