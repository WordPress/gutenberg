### t-hamano on 2022-08-05T12:55:09Z

URL: https://github.com/WordPress/gutenberg/issues/21107#issuecomment-1206423589

I believe this is the `Notice` component, and it certainly reproduces the same layout on StoryBook.
Additionally, this also occurs when using the Notice component on the block editor:

![storybook_1](https://user-images.githubusercontent.com/54422211/183079236-256e63cc-3f57-44c4-ab9a-17dff1435db5.png)

However, I believe this is because the browser default margins are applied to the `p` tag of the child element.
If you reset the margins on the `p` tag as shown below, it will display correctly.

![storybook_2](https://user-images.githubusercontent.com/54422211/183079894-2522a388-3ce2-4438-8a5d-0b54ff8a7dbe.png)

Since any element can be specified as a child, I think their style should not be controlled by the component.
Furthermore, as noted in [this comment](https://github.com/WordPress/gutenberg/blob/19338201d8654729674fdb14f62f1a399c729747/packages/components/src/notice/style.scss#L59), the button is expected to be placed in the upper right corner, no matter how many lines of content are present.
