# Issue #55413: Modal / Popover: Losing focus when closed in iframed editor

- URL: https://github.com/WordPress/gutenberg/issues/55413
- Author: t-hamano
- Created: 2023-10-17T13:41:20Z
- Updated: 2023-10-18T11:49:02Z
- Comments: 0 of 0

## Body

### Description

`Modal` and `Popover` components can be closed using the escape key or the close button. When they are closed, the focus should return to the previously focused element, such as a button.

However, when these components are used inside the iframed editor, they seem to lose focus.

### Step-by-step reproduction instructions

First, replace the code block with the sample code below:

<details><summary>Details</summary>

```javascript
const el = wp.element.createElement;

wp.blocks.registerBlockType( 'test/popover', {
	apiVersion: 3,
	title: 'Test Popover',
	edit() {
		const [ isOpenPopover, setIsOpenPopover ] =
			wp.element.useState( false );
		return el(
			'div',
			wp.blockEditor.useBlockProps(),
			el(
				wp.components.Button,
				{
					variant: 'primary',
					onClick: () => setIsOpenPopover( true ),
				},
				'Open Popover',
				isOpenPopover &&
					el(
						wp.components.Popover,
						{ onClose: () => setIsOpenPopover( false ) },
						el(
							'div',
							{},
							'Popover content',
							el( 'input', { type: 'text' } )
						)
					)
			)
		);
	},
} );

wp.blocks.registerBlockType( 'test/modal', {
	apiVersion: 3,
	title: 'Test Modal',
	edit() {
		const [ isOpenModal, setIsOpenModal ] = wp.element.useState( false );
		return el(
			'div',
			wp.blockEditor.useBlockProps(),
			el(
				wp.components.Button,
				{
					variant: 'primary',
					onClick: () => setIsOpenModal( true ),
				},
				'Open Modal'
			),
			isOpenModal &&
				el(
					wp.components.Modal,
					{ onRequestClose: () => setIsOpenModal( false ) },
					'Modal content'
				)
		);
	},
} );
```

</details> 

- Make sure the custom field setting is disabled in the editor settings.
- Insert two custom blocks.
- Click either button.
- Press the escape key and it should lose focus.
- Enable the custom field setting and follow the same steps.
- When you press the escape key, focus should return to the button.
