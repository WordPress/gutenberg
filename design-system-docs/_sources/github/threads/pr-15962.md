### afercia on 2019-06-14T14:25:05Z

URL: https://github.com/WordPress/gutenberg/pull/15962#issuecomment-502129585

Discussed during today's accessibility bug scrub. As per the normal focus style, anything that's a visible _shape_ is fine.

For Windows high contrast mode Gutenberg is using a specific pattern: a transparent outline that's visible only in Windows high contrast mode. 

That's because Windows high contrast mode removes backgrounds and box-shadows. Only borders and outlines work. Please refer to buttons or other implementations for more details. Thanks for working on this!

### tellthemachines on 2020-03-11T03:44:28Z

URL: https://github.com/WordPress/gutenberg/pull/15962#issuecomment-597429253

Hi @senadir , thanks for working on this!

I checked your changes on Windows in high contrast mode, with both Edge and Firefox, and the outlines on focus are working fine:
![negativeoffset](https://user-images.githubusercontent.com/8096000/76379805-41a04e80-63a5-11ea-9b21-477614060231.png)

However, there's no way of telling which day is currently selected:
![selectioninvisible](https://user-images.githubusercontent.com/8096000/76379850-5c72c300-63a5-11ea-9fa3-865a0673dc00.png)

I'm not sure if that's out of scope for this PR, as design might want to have a think about the best way to handle this. One possibility would be removing borders from all but the selected date, so high contrast would then show the circular border on selection, and it would still be easily distinguishable from the outline that's used on focus. Perhaps @kjellr could help out here?

One other thing that perhaps _could_ be fixed as part of this PR is the contrast of the selected date, as reported in #15278. 
Tl,dr: the blue background on the selected date has insufficient contrast with the white text. It can be easily fixed by using a slightly darker shade of blue, same as we've done for the Publish button. That would mean changing `background` to `theme( button )` in `.CalendarDay__selected`. perhaps the hover and focus styles could also adopt that darker shade.

Thanks again, and sorry for causing scope creep 😅
