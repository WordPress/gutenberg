# Issue #38425: Snackbar: Focus restoration when not part of `SnackbarList`

## Body

## What problem does this address?

As surfaced in #38365, the [focus restoration logic after dismissing a `Snackbar`](https://github.com/WordPress/gutenberg/blob/d257d326075fafeb473adcf16c7ed1d2b54ac384/packages/components/src/snackbar/index.js#L67) only works when it is rendered inside a `SnackbarList`.

## What is your proposed solution?

### Possible solution 1: Return to the previous tabbable

Use [`tabbable.findPrevious()`](https://github.com/WordPress/gutenberg/blob/d257d326075fafeb473adcf16c7ed1d2b54ac384/packages/dom/src/tabbable.js#L164). This could perhaps replace the `listRef` logic altogether.

### Possible solution 2: Enforce usage of `SnackbarList`

It may be that we actually do not want consumers to render `Snackbar` outside of `SnackbarList`. In this case, this guideline should at least be documented better.
