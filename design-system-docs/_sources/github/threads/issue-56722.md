# Issue #56722: Enable `ch` as a unit for dimensions

- URL: https://github.com/WordPress/gutenberg/issues/56722

- Updated: 2023-12-02T12:25:58Z

## Body

## What problem does this address?
Currently (afaik) Gutenberg doesn't support the CSS `ch` unit. This is incredibly useful for defining block width in responsive layouts and global styles. MDN defines ch as "The advance measure (width) of the glyph "0" of the element's font." It's more useful than other relative units like `em` because it not only considers the `font-size` property in it's calculation but it also considers the `font-family` property. It's particularly useful for limiting the width of elements to a max character count—something that makes typography easier and gives designers more intuitive controls. 

## What is your proposed solution?
add `ch` to the list of units you can declare in your theme for dimensions.
