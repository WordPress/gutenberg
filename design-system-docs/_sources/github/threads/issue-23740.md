# Issue #23740: ToggleControl Documentation

- URL: https://github.com/WordPress/gutenberg/issues/23740
- Author: tomjn
- Created: 2020-07-07T10:07:19Z
- Updated: 2026-01-30T13:39:34Z
- Comments: 3 of 3

## Body

The `ToggleControl` documentation uses state exclusively to demonstrate something that should be a block attribute or provided as a prop from elsewhere.

As a result I just spent a while trying to undo some misconceptions on stack exchange by a very confused person who thought the way to put a toggle control in a block was to use `withState`, and didn't know how to retrieve that state in the blocks save function. https://wordpress.stackexchange.com/questions/370550/gutenberg-get-withstate-variable-in-save-function

Instead the example should be replaced with a more comprehensive/clearer version, ideally using a block as an example.

I understand in this case `withState` will have been used because it allowed for a smaller example under the premise that this would help developers. However, this has made the example actively misleading, and raised the barrier to entry to require senior developer React skills.
