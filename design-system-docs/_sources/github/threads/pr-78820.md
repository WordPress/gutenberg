## Body

## What?

Fixes the `@wordpress/ui` Button loading state in forced colors mode without changing the Button's rendered markup.

## Why?

Loading Button content was still visible in forced colors mode because it relied on `color: transparent` to hide direct text nodes. Forced colors can remap transparent text to a system color, making the label visible behind the loading spinner.

## How?

The loading text hiding continues to use `color: transparent` by default. In forced colors mode, styled loading Buttons switch the text color to `Canvas`, preventing forced color mapping from making the label visible behind the spinner.

The loading spinner also gets a forced-colors override that avoids relying on transparent borders, so the animation remains visually legible.

## Testing Instructions

1. Run `npm run storybook:e2e:dev`.
2. Open `http://localhost:50241/?path=/story/design-system-components-button--variant-states`.
3. Enable forced colors mode in the browser or OS.
4. Confirm loading Button labels are hidden while the spinner remains visible.
5. Confirm the loading spinner appears animated in forced colors mode.
6. Confirm non-loading and `unstyled` Buttons still render as expected.
