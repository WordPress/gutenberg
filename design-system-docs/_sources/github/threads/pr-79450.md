## What?
Migrates the `Flex` family away from Emotion styles and onto an SCSS Module.

## Why?
This extends the prop-driven layout pilot beyond `Spacer`. It validates dynamic flexbox styles, child item display styles, expanded row/column sizing, and shared styles across `Flex`, `FlexItem`, and `FlexBlock`.

## How?
- Replaces the shared Emotion `styles.ts` file with `style.module.scss`.
- Replaces Emotion class generation in `useFlex` and `useFlexItem` with `clsx`.
- Moves flexbox declarations and item/block styles into the module stylesheet.
- Uses scoped CSS custom properties for dynamic `align`, `direction`, `wrap`, `gap`, `justify`, and item `display` values.
- Uses data attributes for expanded row/column sizing.
- Updates tests to assert the stable DOM/custom-property contract instead of Emotion style snapshots.
