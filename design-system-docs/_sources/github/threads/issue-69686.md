# Issue #69686: Date Picker: AM/PM toggle button does not respond to keyboard (Space) interactions

- URL: https://github.com/WordPress/gutenberg/issues/69686
- Author: patil-vipul
- Created: 2025-03-24T19:07:35Z
- Updated: 2025-03-26T02:44:07Z
- Comments: 3 of 3

## Body

## What problem does this address?
In the Gutenberg date picker (used in blocks like Post Date or the Document sidebar’s scheduling feature), the AM/PM toggle button is keyboard-navigable but cannot be activated using Enter or Space keys, violating accessibility standards (WCAG 2.1).

![Image](https://github.com/user-attachments/assets/ec1755b1-f79b-4b5c-9b13-573b5fb38b14)

## What is your proposed solution?
- Add keyboard events: Bind onKeyDown to the AM/PM toggle button to trigger on Enter/Space (matching native <button> behavior).
- ARIA compliance: Ensure aria-pressed reflects the toggle state for screen readers.
