## Body

## What?
Adds a new `SelectControl` component to `@wordpress/ui`, composed from the existing primitive `Select` and `Field` components.

## Why?
This provides a complete, labeled select field API similar to `InputControl`, while keeping the lower-level select primitives available for custom composition.

## How?
- Adds `SelectControl` with integrated label, description, details, and visually hidden label, and placeholder support.
- Adds `SelectControl.Item` so custom item children inherit the control size.
- Exports `SelectControl` from the form package entrypoint.
- Adds focused unit tests and Storybook examples covering default items, disabled options, details, hidden labels, and custom trigger/item rendering.
