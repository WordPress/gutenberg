# Issue #59411: CheckboxControl: Add disabled state

- Updated: 2026-04-16T14:52:45Z

## Body

## What problem does this address?

#59364 surfaced a use case for a disabled state on CheckboxControl.

## What is your proposed solution?

- Add appropriate styling (both for `disabled` and `aria-disabled`).
- Make sure the `onChange` is bypassed correctly in the `aria-disabled` case).
- As for the [focus behavior when disabled](https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/#focusabilityofdisabledcontrols), we may need an additional `focusableWhenDisabled` prop so consumers can choose (related: #56547).
