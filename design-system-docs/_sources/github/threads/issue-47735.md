# Issue #47735: Line-height for 'body' text is inconsistent

- URL: https://github.com/WordPress/gutenberg/issues/47735
- Author: jameskoster
- Created: 2023-02-03T12:44:40Z
- Updated: 2023-07-27T07:04:05Z
- Comments: 3 of 3

## Body

We utilise 13px as the default font size in the block editor. However, different areas of the UI apply different line-height values to this 13px text. Some examples:

| UI area | Line-height value |
| --- | --- |
|  <img width="287" alt="Screenshot 2023-02-03 at 12 30 12" src="https://user-images.githubusercontent.com/846565/216604122-f4ff1305-da84-4012-a597-0b20682343a8.png"> | 1.2 |
| <img width="274" alt="Screenshot 2023-02-03 at 12 31 13" src="https://user-images.githubusercontent.com/846565/216604306-119ac95e-e5ed-4d08-a376-743c49107bac.png"> | 1.4em |
| <img width="278" alt="Screenshot 2023-02-03 at 12 31 39" src="https://user-images.githubusercontent.com/846565/216604393-abc16869-ee58-411d-be18-3a83b59025c9.png"> | 1.5 |

It's a small detail, but these inconsistencies add up to make the UI feel less structured and cohesive.

If we wanted to pick one of the existing values I'd vote for 1.5 because it arguably has the best legibility, and gets us closest to the 4px baseline grid: 13 * 1.5 = 19.5. To be more precise, a value of 1.53846153846 * 13 = 20 🙂
