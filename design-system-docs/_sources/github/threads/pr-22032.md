## Body

## Description
Adds the ability to highlight days in the calendar of the `DateTime` component. 

It exposes the function `isDayHighlighted` from the underlying library and leaves the highlighting logic to the consumer of this component. Similar to the way `isInvalidDate` function was exposed.

I'm building this with #13713 in mind as a consumer.

Using this API with `isDayHighlighted` function exposed helps us determining what month the user is looking at, since we will get the function called for days of the opened month, each time it changes. 

If events in that month are yet unknown for us, we can start fetching them from the API. Once we have fresh data, we just pass a new reference for the `isDayHighlighted` function and all currently visible days will be rechecked again.
