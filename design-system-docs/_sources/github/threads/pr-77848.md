### anomiex on 2026-04-30T19:14:49Z

URL: https://github.com/WordPress/gutenberg/pull/77848#issuecomment-4355484220

Because various files in the root use `require( 'uuid' )`, I left it at the latest version supporting CommonJS.

* https://github.com/WordPress/gutenberg/blob/5c11c928cda16b6689c2299852cdf20f25e5c109/bin/plugin/lib/utils.js#L8
* https://github.com/WordPress/gutenberg/blob/5c11c928cda16b6689c2299852cdf20f25e5c109/test/e2e/specs/editor/blocks/classic.spec.js#L7
* https://github.com/WordPress/gutenberg/blob/5c11c928cda16b6689c2299852cdf20f25e5c109/test/e2e/specs/editor/blocks/cover.spec.js#L7
* https://github.com/WordPress/gutenberg/blob/5c11c928cda16b6689c2299852cdf20f25e5c109/test/e2e/specs/editor/blocks/gallery.spec.js#L7
* https://github.com/WordPress/gutenberg/blob/5c11c928cda16b6689c2299852cdf20f25e5c109/test/e2e/specs/editor/blocks/image.spec.js#L7
* https://github.com/WordPress/gutenberg/blob/5c11c928cda16b6689c2299852cdf20f25e5c109/test/e2e/specs/editor/various/big-image-size-threshold.spec.js#L7
* https://github.com/WordPress/gutenberg/blob/5c11c928cda16b6689c2299852cdf20f25e5c109/test/e2e/specs/editor/various/upload-save-lock.spec.js#L7

On the other hand, if you're using node 20.19.0+, it may be possible to use uuid v14 despite it being esm-only thanks to the unflagging of [the require(esm) feature](https://nodejs.org/docs/latest-v20.x/api/modules.html#loading-ecmascript-modules-using-require) in that version. Jest or other stuff may still have issues with it though. I'll leave experimenting with that for someone else.
