# Issue #69252: FormTokenField does not call `__experimentalValidateInput` before tokenizing on space

- URL: https://github.com/WordPress/gutenberg/issues/69252

- Created: 2025-02-19T17:50:45Z

## Body

### Description

## Current behavior

If you add the `tokenizeOnSpace` prop, the input will start tokenizing values without calling `__experimentalValidateInput`. 

## Expected behavior

Ignore space pressing event if `__experimentalValidateInput` returns falsy.


### Step-by-step reproduction instructions

1. Add `tokenizeOnSpace`.
2. Add `__experimentalValidateInput={() => false}`
3. Type something and press space.
