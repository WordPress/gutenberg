## Description
Fix popover flickering issues on small screens.

## How has this been tested?
1.
- Open block editor
- Change browser width to ~320px
- Create paragraph block
- Type text
- Click on the Link icon in the toolbar
- Link popover shouldn't flicker anymore

2.
- Create a new post
- Change browser width to ~320px
- Type a title
- Click on the cog
- Change from Block tab to Post tab
- Click the date next to the Publish label
- Calendar popover shouldn't flicker anymore
