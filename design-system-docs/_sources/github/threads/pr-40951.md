## What?

Makes the inner component focus styles and border radii consistent.

## Why?

The small details matter.

## How?

Updated focus styles and border radii including RTL styling.

###### UnitSelect
- Fixed RTL border radii
- Fixed inconsistent focus box-shadow and border

###### BorderControlDropdown
- Fixed z-index causing focus styles to be clipped

###### InputControl's BackdropUI
- Fixed RTL border radii
- Fixed focus box-shadow

## Testing Instructions

1. Start up Storybook & visit [BorderControl page](http://localhost:50240/?path=/story/components-experimental-bordercontrol--default)
    - `npm run storybook:dev`
2. Optional: Zoom the page in as far as possible to more clearly see styling changes.
3. Select the input within the control then tab/shift-tab through the parts of the control, ensuring correct border radii and that the outline looks correct
4. Switch to RTL mode and repeat the process paying close attention to the border radii

With the UnitControl in BorderRadius, it looks like that one currently has a thicker "looking" inset style that avoids the double-border and looks a bit closer to the design in #40897 to my eyes.

For InputControl, it appears it currently achieves a 2px effective border in [backdropFocusedStyles](https://github.com/WordPress/gutenberg/blob/be92ce8d06f1e282e9cfb401e43790d60ef8f137/packages/components/src/input-control/styles/input-control-styles.tsx#L292) by doing the following:

* Sets a `1px` border with the color set to the border focus color when the component is focused
* Sets a `1px` inset box shadow with the color set to the border focus color

That way it winds up looking effectively like a 2px border, without increasing the apparent size of the element. Not to say that we need to do that necessarily for this component, too, but just thought I'd add that in here in case it helps!

#### Without inset box-shadow

- Toggle controls
- Buttons (General buttons, menu item checkboxes, tabs, dropdown buttons, panel headers)
- Font Size Picker (ToggleGroup view)
- CustomSelectControl
- TextControl (both input and textarea)
- Links
- CheckboxControl
- RangeControl drag handles

#### With inset box-shadow

- InputControl
- UnitControl
- SelectControl

Given the widespread use of UnitControl, that sort of makes the balance more even.
