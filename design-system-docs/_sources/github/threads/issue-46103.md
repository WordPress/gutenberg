# Issue #46103: Add prop for RadioControl field to align the options horizontally or vertically

- URL: https://github.com/WordPress/gutenberg/issues/46103
- Author: louwie17
- Created: 2022-11-28T08:34:22Z
- Updated: 2025-06-24T17:11:35Z
- Comments: 1 of 1

## Body

## What problem does this address?

We at WooCommerce Admin are currently making use of the RadioControl button and aligning the options horizontally.
In order to do this we have to overwrite the `flex-direction` style, this is not preferred, as the styling or the component hierarchy can change, and breaking our use case.
This happened recently after this update: https://github.com/WordPress/gutenberg/pull/43868

Here is our example use case, we are using each emoji as an option:
![202576390-a24cb84d-92eb-417b-8341-ac8cffc4c064](https://user-images.githubusercontent.com/2240960/204231372-1cb8f4bb-2823-4596-9353-5de963790ad4.png)


## What is your proposed solution?

Adding a `direction` prop that can either follow the same format as flex box, with `row` & `column` or make use of `vertical` & `horizontal`.
We can of-course default to the `row`/`vertical` option.

See the comments in the above mentioned PR for more context: https://github.com/WordPress/gutenberg/pull/43868#issuecomment-1318950758
