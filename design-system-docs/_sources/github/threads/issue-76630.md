I've been exploring this upgrade over the past week or so.

A couple issues I'm running into:

- Terrazzo 2 now alphabetizes token output by default now, which isn't great for how we have our sizing scheme `xs-2xl`. We can configure this off, but there's a bug with how that config option affects token shape (https://github.com/terrazzoapp/terrazzo/issues/734)
- Our "inline alias" plugin manipulates token values directly, but those are [now defined in Terrazzo as a getter](https://github.com/terrazzoapp/terrazzo/blob/fefd4b149d03ca2199eaddc7b197e4e081169e7f/packages/parser/src/parse/token.ts#L73-L75). Based on how this is implemented internally, we might be able to change the behavior to mutate the aliased value instead.
