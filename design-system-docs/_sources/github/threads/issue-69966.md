## Body

## What problem does this address?

The [components package readme](https://github.com/WordPress/gutenberg/blob/trunk/packages/components/README.md#usage) doesn't mention that in non-WordPress projects, the consumer needs to add their own RTL handling.

## What is your proposed solution?

We should note that in RTL contexts they should be loading the `node_modules/@wordpress/components/build-style/style-rtl.css` stylesheet instead.
