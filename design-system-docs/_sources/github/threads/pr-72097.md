## Body

This PR fixes an issue where text-decoration: underline from parent elements with flex display was propagating to Badge components, causing unwanted underlines on badges. 


## Changes
Modified Badge component styles to use display: inline-block instead of display: inline-flex to prevent text-decoration inheritance.
Adjusted padding and line-height to maintain visual consistency with the display change.
Updated title field styles to exclude badges from some style which namely changed the display using :not(.components-badge__content) selector-
Added Storybook stories (InsideAnchor and InsideDiv) demonstrating badges in different parent display contexts (flex, block, inline-block) to validate the fix.


## Technical details
The root cause was that display: inline-flex allows certain text properties like text-decoration to inherit from parent elements. Switching to inline-block prevents this inheritance while maintaining the badge's inline layout behavior.
