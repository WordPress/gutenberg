## ✍️ Dev Note

The `ButtonGroup` component has been deprecated, as it can easily lead to accessibility issues. For simpler adherence to accessibility best practices and to be consistent with the current WordPress design system, use [`ToggleGroupControl`](https://wordpress.github.io/gutenberg/?path=/docs/components-experimental-togglegroupcontrol--docs) instead.
