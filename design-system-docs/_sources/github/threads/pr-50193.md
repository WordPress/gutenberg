## Body

Closes #44123

## What?

Updates the default accent color scheme of the package from `#007cba` to `#3858e9`.

This will only affect consumers outside of a WordPress context.

## Why?

As requested by @jasmussen in https://github.com/WordPress/gutenberg/pull/43994#issuecomment-1241569396, we want to start embracing the new color scheme in the components package.

## How?

See inline comments.

## Testing Instructions

### Should update wp-component defaults

1. `npm run storybook:dev`
2. The stories for the components package should have the new default color scheme.
3. Stories for the other packages should still have the classic color scheme.

### Should not affect wp-admin usage

1. `npm run dev`
4. Go to `/wp-admin/profile.php` and set the admin color scheme to something that is not "Modern".
5. Go into the block editor and smoke test that the color scheme is correct (i.e. not Modern).

## 🛠️ How to restore previous color scheme

_This only affects those using the `@wordpress/components` package in a non-WordPress context._

The default color scheme of the `@wordpress/components` has been updated to use the new WP Blueberry (`#3858e9`).

To restore the previous color scheme in your app, create a stylesheet that imports `default-custom-properties` from the `@wordpress/base-styles` package:

```scss
@import 'node_modules/@wordpress/base-styles/default-custom-properties';

// Or, if you use Webpack for your SCSS pipeline, you can use `~` to resolve to `node_modules`:
@import '~@wordpress/base-styles/default-custom-properties';
```

Then, load this stylesheet later than the `@wordpress/components` stylesheet (`@wordpress/components/build-style/style.css`).
