# Issue #72175: `Card`: support more padding options

- URL: https://github.com/WordPress/gutenberg/issues/72175
- Author: jameskoster
- Created: 2025-10-08T16:09:16Z
- Updated: 2025-11-04T14:07:42Z
- Comments: 5 of 5

## Body

The `size` options on the [Card](https://wordpress.github.io/gutenberg/?path=/docs/components-card--docs) component often produce unequal horizontal/padding padding values. For example the `large` `size` has `24px` vertical padding and `32px` horizontal padding.

It can sometimes be desirable to create cards with equal padding, or specify per-side padding values on subcomponents like `Card.Header`. Let's explore how to offer this functionality in a sustainable way (based on presets/tokens) while considering backwards compatibility.

cc @gigitux

### jameskoster on 2025-10-09T14:25:10Z

URL: https://github.com/WordPress/gutenberg/issues/72175#issuecomment-3386135629

One idea I had for this is to introduce some new properties: `paddingTop`, `paddingRight`, `paddingBottom`, `paddingLeft`.

### Behavior
- The existing `size` prop acts as a shorthand defining top, right, bottom, and left padding values.
- When any per-side padding property is set, it overrides the corresponding side derived from `size`.
- If `size` is omitted, each padding property applies independently.
- The `padding*` props accept values from the spacing scale to maintain design consistency.

### Backwards compatibility
- All existing uses of `size` remain fully supported.
- The new properties are additive and non-breaking.

This approach loosely mirrors CSS’s padding shorthand and side-specific properties, offering developers finer control without fragmenting existing patterns or requiring new size presets.

### gigitux on 2025-10-17T13:25:53Z

URL: https://github.com/WordPress/gutenberg/issues/72175#issuecomment-3415618957

@jameskoster Instead to add a new prop, what do you think if size looks like this:

```ts
export type SizeOptions =
	| 'xSmall'
	| 'small'
	| 'medium'
	| 'large'
	| {
			paddingTop: number;
			paddingRight: number;
			paddingBottom: number;
			paddingLeft: number;
	  };
```


In this way, `Card` can be consumed in this way:

```tsx

<Card size="medium">
  <CardBody>
    <Text>Medium padding (predefined - default)</Text>
  </CardBody>
</Card>

<Card
  size={{
    paddingTop: 8,
    paddingRight: 24,
    paddingBottom: 8,
    paddingLeft: 24,
  }}
>
  <CardBody>
    <Text>Custom horizontal padding (8px vertical, 24px horizontal)</Text>
  </CardBody>
</Card>
```
