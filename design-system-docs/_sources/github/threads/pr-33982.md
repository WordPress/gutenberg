## Description
<!-- Please describe what you have changed or added -->

A [recent change](https://github.com/emotion-js/emotion/pull/2441) in Emotion exposed the `__unsafe_useEmotionCache()` hook.

This PR updates the package versions of `@emotion/react` and `@emotion/cache` and uses this newly exposed function in the `useCx` hook, instead of exposing the private `CacheProvider._context` variable directly.
