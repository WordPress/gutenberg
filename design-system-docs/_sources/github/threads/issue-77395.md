# Issue #77395: `@wordpress/ui` adds a transitive peer dependency on `date-fns`, `@date-fns/tz`

- URL: https://github.com/WordPress/gutenberg/issues/77395
- Author: anomiex
- Created: 2026-04-15T20:24:08Z
- Updated: 2026-04-22T15:08:55Z
- Comments: 7 of 7

## Body

`@base-ui/react` v1.4.0 added peer dependencies on `date-fns` ^4.0.0 and `@date-fns/tz` ^1.2.0. This is causing a few problems for us:

1. `@wordpress/ui` does not satisfy this peer dependency. Anything using that package now needs to add `date-fns` and `@date-fns/tz` as a dependency to satisfy it.
2. `@wordpress/editor` and `@wordpress/components` depend on `date-fns` ^3.6.0, which satisfies this transitive peer dependency with a wrong version of `date-fns`.

Please add the necessary dependencies to `@wordpress/ui`.

It would also be nice to update `@wordpress/editor` and `@wordpress/components`, but as currently their only dependency on `@base-ui/react` is via `@wordpress/ui`, it's not necessary to solve the problem as long as `@wordpress/ui` itself supplies the correct dependencies.
