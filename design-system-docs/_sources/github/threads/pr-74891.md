## Body

## What?

Adds a new `combobox` DataForm control.

## Why?

The `select` control does not scale well to handle hundreds of elements, but the combobox does, so it's convenient to have this new control available. It's also one of the [last validated controls](https://wordpress.github.io/gutenberg/?path=/docs/components-validated-form-controls-overview--docs) we have not ported to DataForm (the other is the range, but we don't have yet use cases for it).

## How?

- Add a new `combobox` DataForm control.
- Update the validation story to include it.
- Update the field types story to include it as an edit storybook control.
