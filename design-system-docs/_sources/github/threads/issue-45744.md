# Issue #45744: Popover Component does not close when clicking outside Popover

## Body

### Description

When a Popover is opened, if the user clicks outside the Popover's contents, it should close without having to re-trigger the open/close function. The "context" menu (three vertical dots) on BlockControls works this way already, which is the expected behavior.

### Step-by-step reproduction instructions

1. Create a block using create-block package
2. Implement a Popover 
3. Click to open the Popover
4. Click anywhere else, the Popover will remain open

### t-hamano on 2022-11-14T01:50:11Z

URL: https://github.com/WordPress/gutenberg/issues/45744#issuecomment-1312933475

Hi @cheestudio,

I think that nothing should happen when you click outside the popover unless you explicitly close it by `onClose`.

A basic implementation would be as follows:

```javascript
const [ isOpen, setIsOpen ] = useState( false );

<Button onClick={() => setIsOpen( true ) }>Toggle Popover</Button>

{ isOpen && (
	<Popover
		onClose={() => setIsOpen( false ) }
	>
		Popover Content
	</Popover>
) }
```
