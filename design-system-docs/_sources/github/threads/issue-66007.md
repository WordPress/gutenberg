# Issue #66007: Button: Transition doesn't work for secondary variation

- URL: https://github.com/WordPress/gutenberg/issues/66007
- Author: t-hamano
- Created: 2024-10-10T09:39:00Z
- Updated: 2024-10-14T09:41:54Z

## Body

### Description

When the `Button` component is focused, a transition is expected to be applied to the `box-shadow` via the following CSS:

https://github.com/WordPress/gutenberg/blob/7ea28adb62b8333714ec916ed6b6688181731a26/packages/components/src/button/style.scss#L19

This transition works for the `primary`/`tertiary` variations but not the `secondary` variation.

My guess is that transitions won't work between insets and outsets. For example, if I remove the `inset` from [this line](https://github.com/WordPress/gutenberg/blob/7ea28adb62b8333714ec916ed6b6688181731a26/packages/components/src/button/style.scss#L136), the transition will work on the `secondary` variation.

However, simply removing the `inset` may not be an ideal solution, since removing the `inset` increases the default border size by 1px.

### Step-by-step reproduction instructions

- Open https://wordpress.github.io/gutenberg/?path=/story/components-button--secondary
- Focus on the button
