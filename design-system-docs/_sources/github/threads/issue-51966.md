# Issue #51966: DatePicker: Event dots are adjacent to the inside of the button

- URL: https://github.com/WordPress/gutenberg/issues/51966
- Author: t-hamano
- Created: 2023-06-27T09:55:58Z
- Updated: 2024-01-21T03:28:42Z
- Comments: 3 of 3

## Body

## What problem does this address?

The `DatePicker` component adds a background color to the current or selected date. In addition, days that have events will have a small dot under the number.

When these two overlap, the dot is adjacent to the inside of the background color, which looks unnatural to me.

![scale](https://github.com/WordPress/gutenberg/assets/54422211/5d966f09-61d1-4b3e-a697-5021330bc026)

## What is your proposed solution?
By shifting this dot slightly (about 2px) upward, I think it looks just fine.
