## Body

**Describe the bug**
A clear and concise description of what the bug is.

Hey all - I have a custom block that uses the QueryControls component and withSelect. The code looks like this:

```
 <QueryControls
            {...{ order, orderBy, category }}
            numberOfItems={postsToShow}
            categoriesList={categoriesList}
            selectedCategoryId={category}
            onOrderChange={value => setAttributes({ order: value })}
            onOrderByChange={value => setAttributes({ orderBy: value })}
            onNumberOfItemsChange={value =>
              setAttributes({ postsToShow: value })
            }
            onCategoryChange={value =>
              setAttributes({ category: '' !== value ? value : null })
            }
          />

export default withSelect((select, props) => {
  const { postsToShow, startAt, order, orderBy, category } = props.attributes;

  // shorthand
  const { getEntityRecords } = select('core');

  const caseStudiesQuery = pickBy(
    {
      category,
      order,
      orderby: orderBy,
      per_page: postsToShow,
      offset: startAt, // dont know why this is out
    },
    value => !isUndefined(value),
  );

  const categoriesListQuery = {
    per_page: 50,
    hide_empty: true,
  };

  return {
    caseStudies: getEntityRecords('postType', 'case-study', caseStudiesQuery),
    categoriesList: getEntityRecords(
      'taxonomy',
      'case-study-category',
      categoriesListQuery,
    ),
  };
})(BlogArchiveEdit);
```

This works fine up to version 5.5. But then breaks from 5.5 up with the following error:
e is null

**Desktop (please complete the following information):**
 - OS: MacOS
 - Browser firefox, chrome
 - Version latest

**Additional context**
- Gutenberg versions 5.5 - 6.3

Ok I figured this one out, the issue is that the categoriesList variable is initially null or undefined and the QueryControls component requires an array. To fix this i added:

```
    const {
      attributes: {
        numberCols,
        postsToShow,
        startAt,
        order,
        orderBy,
        category,
      },
      className,
      setAttributes,
      caseStudies,
      categoriesList = [], // this is needed to prevent crashing
    } = this.props;
```

I will go ahead and close this issue
