I don't think it's something related to Base UI — this is related to how we're handling overflowing horizontal tabs (ie. we make them scroll). Relatively recently, most browsers have started [making scrolling containers tabbable](https://developer.chrome.com/blog/keyboard-focusable-scrollers) as an accessibility improvement.

But we felt that was unnecessary for Tabs, since users can already use arrows to move the focus across tabs in the tablist, which will cause the tablist itself to scroll if necessary.

We could potentially look at using Base UI's `ScrollArea` here, but I remember some previous push back when discussing using that component vs native browser scrollbars.
