I have checked this PR against the latest trunk.
It appears that some of the changes this PR is attempting have already been made in trunk.

- Add support for `disabled` prop in `QueryControls`:
- ✅ Add support for `disabled` prop in `ToggleControl`:
    https://github.com/WordPress/gutenberg/tree/trunk/packages/components/src/toggle-control#disabled
- ✅ Add a Storybook story for `ToggleControl`:
    https://wordpress.github.io/gutenberg/?path=/story/components-togglecontrol--default

Therefore, what is proposed by this PR is only to add support for `disabled` prop to the `QueryControl` component.

`QueryControl` has changed since that time, so it will need to follow trunk and make some adjustments. I have tried making the changes suggested by this PR on the latest trunk and it seems to work well to me.
