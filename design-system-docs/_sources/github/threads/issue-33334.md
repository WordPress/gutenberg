# Issue #33334: Allow `FormTokenField` suggestions to use keywords

## Body

## What problem does this address?
<!--
Please describe if this feature or enhancement is related to a current problem
or pain point. For example, "I'm always frustrated when ..." or "It is currently
difficult to ...".
-->
Right now the autocomplete `FormTokenField` only returns values based on the passed array of string suggestions. It would be great to be able to also return values based on an array of keywords, or other object parameters that are passed.

## What is your proposed solution?
<!--
Please outline the feature or enhancement that you want and how it addresses any
problem identified above.
-->
Possible API. Either just use `keywords`, or have a property to set which object keys should be matched against.

```js
<FormTokenField
  searchKeys={ ['keywords', 'title'] }
  suggestions={ [
    {
      value: 'mt-0',
      keywords: ['margin', 'top', 'zero'],
    },
    {
      value: 'd-flex-lg',
      keywords: ['display flex large'],
      title: 'Something else to search by',
    },
  ] }/>
```
