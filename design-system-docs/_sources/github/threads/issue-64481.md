## Body

As can be seen in the screenshot below, or viewing [this example](https://wordpress.github.io/gutenberg/?path=/story/components-rangecontrol--with-integer-step-and-marks) in storybook, positioning of marks in the `RangeControl` component have regressed from the [original implementation](https://github.com/WordPress/gutenberg/pull/19916).
