# Issue #24201: Gradient RGBA/HSLA inputs are not wide enough in WordPress 5.5

- URL: https://github.com/WordPress/gutenberg/issues/24201
- Author: sabernhardt
- Created: 2020-07-24T19:26:02Z
- Updated: 2020-07-27T12:38:36Z
- Comments: 4 of 4

## Body

**Description**
When adding a gradient with RGBA or HSLA color values to a block, the increment buttons of number inputs cover up the inputs' values. The design worked well enough with 3 inputs (RGB/HSL) in WordPress 5.4, but there is a fourth input now in 5.5.

Originally reported by MarkS99 on Trac: https://core.trac.wordpress.org/ticket/50689

**Steps to reproduce**
1. Create a Group block (or another block that supports gradient backgrounds).
2. Expand Color Settings and choose Gradient.
3. Click an existing gradient control point or create a new one (circles along the pill-shaped bar).
4. Click the chevron icon next to the hexadecimal input to see the RGBA or HSLA inputs.
5. Type any value in each input. If your browser/user agent has increment buttons, those likely will overlap the value.

- My screenshots are from a more recent trunk version (still 5.5) on Windows 10, without the plugin, but I still see it with Gutenberg 8.6.0 activated.

The simplest fix for the width might be to add a `min-width` on the container.

```
.components-color-picker__inputs-wrapper {
    min-width: 25em;
}
```

I like 25em for larger screens (medium breakpoint up), though it might need to be 20em or a similar pixel value for narrower screens.
