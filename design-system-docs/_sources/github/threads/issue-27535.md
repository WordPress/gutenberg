# Issue #27535: DayPicker Navigation button problem in RTL

- URL: https://github.com/WordPress/gutenberg/issues/27535

- Created: 2020-12-06T16:12:41Z
- Updated: 2021-01-25T14:10:44Z

## Body

DayPicker Navigation button has a problem in RTL, in WordPress 5.5.3, please see the attachment image.

![image](https://user-images.githubusercontent.com/935397/101285300-a801b280-37f9-11eb-9855-f47c05236f3b.png)

The problem came from:
```
.components-datetime__date .DayPickerNavigation_leftButton__horizontalDefault {
    right: 0;
}
```

It must changes to:
```
.components-datetime__date .DayPickerNavigation_leftButton__horizontalDefault {
    right: auto;
}
```

After this change:
![image](https://user-images.githubusercontent.com/935397/101285390-28281800-37fa-11eb-8e04-5b0f7b699a13.png)

### noisysocks on 2021-01-06T03:23:41Z

URL: https://github.com/WordPress/gutenberg/issues/27535#issuecomment-755051800

@gaavar: There's a few approaches.

You can check for the presence of the `.rtl` class on `<body>` which is added by WordPress when the current language is a RTL language.

Alternatively, an even better idea is to use a rtlcss directive. 

```css
.components-datetime__date .DayPickerNavigation_leftButton__horizontalDefault {
    right: 0 /*rtl:auto*/;
}
```

https://rtlcss.com
