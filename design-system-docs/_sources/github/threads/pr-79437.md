## Body

## What?
Follow-up to https://github.com/WordPress/gutenberg/pull/76545, in particular https://github.com/WordPress/gutenberg/pull/76545#issuecomment-4092207253. Also follows up on the token migration discussion in https://github.com/WordPress/gutenberg/pull/79254.

Adds two larger WPDS element size tokens:

- `--wpds-dimension-size-xl`: `48px`
- `--wpds-dimension-size-2xl`: `64px`

## Why?
The migration work in #79254 surfaced a few element sizes that do not map to the current public `--wpds-dimension-size-*` scale. Adding 48px and 64px gives those larger media/interface elements semantic size tokens instead of local constants.

## How?
- Adds the missing size entries to `packages/theme/tokens/dimension.json`.
- Adds a `64px` primitive spacing entry so the new semantic token can follow the existing token reference pattern.
- Regenerates the theme token CSS, JS fallback map, token list, TypeScript token type, and token docs.
