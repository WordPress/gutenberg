## Description
Fixes: https://github.com/WordPress/gutenberg/issues/19276


This PR refactors the FontSizePicker component and totally removes local state from the component, simplifying its code.
The PR ends up fixing issue https://github.com/WordPress/gutenberg/issues/19276 which was caused by the fact the component contained local state that was not properly updated during an undo operation.

cc: @andreilupu 
## How has this been tested?
I verified font size picking still works as expected.
I repeated the steps referred on https://github.com/WordPress/gutenberg/issues/19276 and verified the issue was not happening anymore.
