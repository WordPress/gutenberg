# Issue #22950: ComboboxControl: Display all available options on focus

- URL: https://github.com/WordPress/gutenberg/issues/22950
- Author: jeryj
- Created: 2020-06-05T21:22:29Z
- Updated: 2020-12-22T23:15:19Z
- Comments: 1 of 1

## Body

The behavior of the ComboBox implemented from https://github.com/WordPress/gutenberg/pull/19657 does not open the available options when the combobox is focused. Thus, there is no way to know what options are available to you to know what to search for in the combobox search.

The combobox may have many, many options which could be overwhelming. To prevent this, I suggest limiting the options list to show 5 - 10 items max. The rest of the options can be hidden via an overflow scroll container.

Further explanation and context here: https://github.com/WordPress/gutenberg/pull/19657#issuecomment-638412385
