# Issue #69874: Snackbar notification required after copying custom color

- URL: https://github.com/WordPress/gutenberg/issues/69874

- Created: 2025-04-10T07:01:46Z
- Updated: 2025-04-10T11:11:39Z

## Body

## What problem does this address?
Currently, when a user tries to copy a custom color from the color panel, there is no visual indication to confirm whether the color has been successfully copied or not.

![Image](https://github.com/user-attachments/assets/48a6aa52-595b-4e0e-ba33-aea32dae895a)

## What is your proposed solution?
It would be a great improvement to display a `Snackbar` notification to inform the user that the color has been copied. 
However, I'm not sure that using notices would be allowed in the `Color Picker` component, so any better approach or some feedback on this would be appreciated! 👍🏻
