# Issue #25847: Dropdown menu options not read by JAWS (screenreader)

- URL: https://github.com/WordPress/gutenberg/issues/25847
- Author: talldan
- Created: 2020-10-06T03:24:12Z
- Updated: 2020-10-07T15:02:06Z
- Comments: 3 of 3

## Body

**Describe the bug**
As noted a couple of times in a talk for WP Accessibility Day 2020 (https://youtu.be/-fKkptFna9E?t=20368, https://youtu.be/-fKkptFna9E?t=20887), dropdown menus options don't seem to be read by JAWS.

I'm not sure if this relates to just these two menus or other menus as well. Looking at the markup for these menus, I can't see any obvious issues.

**To reproduce**
Steps to reproduce the behavior:
I haven't tested this myself, but judging by the video:

**Block transform menu**
1. Add a paragraph block
2. Shift tab to the toolbar
3. Press space to open the menu
4. Use up/down arrow keys to cycle through the options

**Preview menu**
1. Add some content to a post
2. Navigate to the Preview button
3. Press space to open the menu
4. Use up/down arrow keys to cycle through the options

**Expected behavior**
The screenreader reads the menu options

**Screenshots**
See the video examples at these links:
- https://youtu.be/-fKkptFna9E?t=20368
- https://youtu.be/-fKkptFna9E?t=20887
