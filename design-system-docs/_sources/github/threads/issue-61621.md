### t-hamano on 2025-04-30T02:07:36Z

URL: https://github.com/WordPress/gutenberg/issues/61621#issuecomment-2840625555

I can still reproduce this issue. Note that this issue needs to be tested in the `:focus` state, not the `:focus-visible` state.

Additionally, this issue does not seem to be related to the `NavigatorButton` component. You should be able to reproduce this issue on Stoybook without making any changes.

https://wordpress.github.io/gutenberg/?path=/story/components-experimental-itemgroup--default

You can emulate the `:focus` state using your browser's developer tools or by holding down the primary touchpad key on the button.

![Image](https://github.com/user-attachments/assets/e851c1f0-de5e-4b14-b9c1-db6a93c44f09)

Here's the style that's causing this issue:

https://github.com/WordPress/gutenberg/blob/59a230c1e692ed78d0abfebce3c6ff5b429c1a4b/packages/components/src/item-group/styles.ts#L68-L70

I don't know why only the focus state is excluded, but making the following changes seems to solve the problem.

```diff
--- a/packages/components/src/item-group/styles.ts
+++ b/packages/components/src/item-group/styles.ts
@@ -65,7 +65,7 @@ export const separated = css`
                border-bottom: 1px solid ${ CONFIG.surfaceBorderColor };
        }
 
-       > *:last-of-type > *:not( :focus ) {
+       > *:last-of-type > * {
                border-bottom-color: transparent;
        }
 `;
```

### im3dabasia on 2025-04-30T10:11:03Z

URL: https://github.com/WordPress/gutenberg/issues/61621#issuecomment-2841483830

Correct @t-hamano. The border was removed previously only when the state was not focused. i.e., other than when the item is focused, the border was removed. To correct this, we need to remove the border styling for all pseudo events and not just target `:not( :focus )`. 

I'll shortly raise a PR for this fix and we can discuss there.
