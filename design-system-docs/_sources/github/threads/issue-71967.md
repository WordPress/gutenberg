# Issue #71967: FontSizePicker incorrectly measures units for selecting elements

## Body

### Description

I see that WordPress show incorrect information of units of [FontSizePicker](https://wordpress.github.io/gutenberg/?path=/docs/components-fontsizepicker--docs) if user choose default to the labels 'S / M / L / XL / XXL'.

Example my component
```jsx
<FontSizePicker
	__next40pxDefaultSize
	fontSizes={ [
		{
			name: 'Small',
			size: 12,
			slug: 'small',
		},
		{
			name: 'Normal',
			size: 16,
			slug: 'normal',
		},
		{
			name: 'Big',
			size: 26,
			slug: 'big',
		},
	] }
	value={ titleFontSize ? parseFloat( titleFontSize ) : undefined }
	onChange={ ( newSize ) => {
		if ( newSize === undefined ) {
			setAttributes( {
				titleFontSize: '16',
				titleFontUnit: 'px',
			} );
			return;
		}
		setAttributes( {
			titleFontSize: String( newSize ),
			titleFontUnit: 'px',
		} );
	} }
	withSlider
/>;
```
