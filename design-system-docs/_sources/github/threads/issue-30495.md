URL: https://github.com/WordPress/gutenberg/issues/30495#issuecomment-815396783

The select list isn't meant to change the style of the selected block. It's meant to change the style of any new blocks added afterward.

That setting is unlike everything else in the block settings sidebar so I see the potential for misunderstanding. Maybe a better place for that setting could be found.
