# Issue #23285: QueryControls component has breaking changes

- URL: https://github.com/WordPress/gutenberg/issues/23285
- Author: AnthonyLedesma
- Created: 2020-06-18T17:49:53Z
- Updated: 2020-07-02T14:36:45Z
- Comments: 0 of 0

## Body

**Describe the bug**
The QueryControls component has had breaking changes that are accessible when running Gutenberg plugin 8.3.0 but not yet available on the current Core version of WordPress 5.4.2.

The changes were made in PR [#20832](https://github.com/WordPress/gutenberg/commit/e17d104ee3fe6eb8d81373226ab73096f59f9ba3?diff=unified#diff-c6f3671ccf8423e13dd7607ed845c6aaL28-L29) and eventually resulted in bug reports on the CoBlocks GitHub such as [this issue](https://github.com/godaddy-wordpress/coblocks/issues/1530)

In order to resolve this issue on the CoBlocks side, we needed to pass in both deprecated props and the new props for proper backward compatibility. 

**Expected behavior**
Expect breaking changes in core components to handle changes in prop names more gracefully without the need for external deprecations.

**Editor version (please complete the following information):**
- WordPress version: 5.4.2
- Does the website has Gutenberg plugin installed, or is it using the block editor that comes by default? Yes, the Gutenberg plugin active to replicate this report.
- If the Gutenberg plugin is installed, which version is it? Gutenberg 8.3.0

**Desktop (please complete the following information):**
Occurs across all OS and Browsers.

**Smartphone (please complete the following information):**
Occurs across all mobile devices and browsers.

**Additional context**
Please get a look at the [PR on the CoBlocks GitHub](https://github.com/godaddy-wordpress/coblocks/pull/1547) regarding the fix.
