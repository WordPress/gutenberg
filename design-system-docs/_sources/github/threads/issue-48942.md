## Body

## What problem does this address?
<!--
Please describe if this feature or enhancement is related to a current problem
or pain point. For example, "I'm always frustrated when ..." or "It is currently
difficult to ...".
-->
https://github.com/Automattic/jetpack/issues/28375
We have a problem with the VideoPress block where a video can have a rating of `R-17`, where the user needs to input their birthdate for age verification:
![2023-03-08_17-31-12](https://user-images.githubusercontent.com/8486249/223843047-f3b301fd-f72b-4944-a7c5-6f6cda7e42ff.png)

The VideoPress block renders the VideoPress player inside an iframe via the `SandBox` component [here](https://github.com/Automattic/jetpack/blob/trunk/projects/packages/videopress/src/client/block-editor/blocks/video/components/player/index.tsx#L231), but the SandBox component does not allow for form submission, so the block is stuck like that when using the editor.

## What is your proposed solution?
<!--
Please outline the feature or enhancement that you want and how it addresses any
problem identified above.
-->
I believe that adding `allow-forms` [here](https://github.com/WordPress/gutenberg/blob/980100c2546213237ae88f783ce6ac7fbb986346/packages/components/src/sandbox/index.tsx#L283) would solve that, or maybe a _prop_ to allow that when needed.
