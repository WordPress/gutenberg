# Issue #76929: UI: Update components to use Text component in place of ad hoc styles

- URL: https://github.com/WordPress/gutenberg/issues/76929
- Author: aduth
- Created: 2026-03-31T13:50:20Z
- Updated: 2026-04-27T13:43:44Z
- Comments: 12 of 12

## Body

## What problem does this address?

Related to: #64340 (discussion starting at https://github.com/WordPress/gutenberg/issues/64340#issuecomment-4091539530)

The [`Text` component](https://wordpress.github.io/gutenberg/?path=/docs/design-system-components-text--docs) added in #75870 provides a convenient abstraction for adopting design system typographical pairings, and should be the preferred way to style typography in UI components.

## What is your proposed solution?

Update existing usage of typography styles to adopt the `Text` component instead:

- [x] [`Card.Title`](https://github.com/WordPress/gutenberg/blob/26f64ca808f83edf8a58456c2ee6b82e8ecae5b3/packages/ui/src/card/style.module.css#L42-L45) (#76642)
- [ ] [`Breadcrumbs`](https://github.com/WordPress/gutenberg/blob/35881d8643d21fa393309db9973c189c75a90f94/packages/admin-ui/src/breadcrumbs/style.scss#L4-L8) (`@wordpress/admin-ui`)
   - Closest variant: `heading-lg` (though note the `Text` variant uses `line-height-sm` not `line-height-lg`, so the line-height pairing may need reconciling). Unclear if "heading" is correct semantics to use here.
- [ ] [`Page`](https://github.com/WordPress/gutenberg/blob/35881d8643d21fa393309db9973c189c75a90f94/packages/admin-ui/src/page/style.scss#L26-L45) (`@wordpress/admin-ui`)
   -  For title, same notes as `Breadcrumbs`. For subtitle, closest match is `body-md`.
- [x] [`Badge`](https://github.com/WordPress/gutenberg/blob/35881d8643d21fa393309db9973c189c75a90f94/packages/ui/src/badge/style.module.css#L8-L11)
   - Exact match for `body-sm`
- [ ] [`Notice.ActionLink`](https://github.com/WordPress/gutenberg/blob/35881d8643d21fa393309db9973c189c75a90f94/packages/ui/src/notice/style.module.css#L67-L70)
   - Exact match for `body-md`
- [ ] [`field` utility styles](https://github.com/WordPress/gutenberg/blob/35881d8643d21fa393309db9973c189c75a90f94/packages/ui/src/utils/css/field.module.css#L7-L10)
   - Exact match for `body-sm`
   - Unclear how feasible it is to update call-sites to use `Text` components instead of utility styles without adding additional layer of DOM nesting, and if we're comfortable if an extra element is needed 
- [x] [`Dialog.Title`](https://github.com/WordPress/gutenberg/blob/29202c80a73f5d98c0c46e54b91f8c2a5f89d815/packages/ui/src/dialog/style.module.css#L102-L104)
   - Closest variant: `heading-xl` (current styles use `line-height-xl` but `Text`'s `heading-xl` is `line-height-md`)

This list is compiled based on existing usage of typography tokens in component stylesheets. While there's a long tail of components which _could_ be updated to use the `Text` component, as well as usage of `@wordpress/component`'s `Text` component, it's not considered part of the scope of this issue.

Additional candidates to consider, though unclear if they should use Text component because their typographical styling is limited and it may incur additional DOM nesting complications:

- [`Button`](https://github.com/WordPress/gutenberg/blob/35881d8643d21fa393309db9973c189c75a90f94/packages/ui/src/button/style.module.css#L47-L50)
- [`Tabs`](https://github.com/WordPress/gutenberg/blob/35881d8643d21fa393309db9973c189c75a90f94/packages/ui/src/tabs/style.module.css#L125-L126)
- [`Tooltip`](https://github.com/WordPress/gutenberg/blob/35881d8643d21fa393309db9973c189c75a90f94/packages/ui/src/tooltip/style.module.css#L14-L16)
- [`InputLayout`](https://github.com/WordPress/gutenberg/blob/35881d8643d21fa393309db9973c189c75a90f94/packages/ui/src/form/primitives/input-layout/style.module.css#L14-L16)
- [`item-popup` utility styles](https://github.com/WordPress/gutenberg/blob/35881d8643d21fa393309db9973c189c75a90f94/packages/ui/src/utils/css/item-popup.module.css#L19-L21)
- [`EmptyState.Root`](https://github.com/WordPress/gutenberg/blob/35881d8643d21fa393309db9973c189c75a90f94/packages/ui/src/empty-state/style.module.css#L11)
