### diegohaz on 2024-04-26T20:44:28Z

URL: https://github.com/WordPress/gutenberg/pull/60992#issuecomment-2080093840

Looks like most of the failing tests are due to a change on `data-*` attributes: [Public data attributes have now boolean values](https://ariakit.org/changelog#public-data-attributes-have-now-boolean-values)

Also, tooltips no longer assign `aria-labelledby`/`aria-describedby` attributes: https://github.com/ariakit/ariakit/pull/3318

Other failures appear to prompt `act` warnings, potentially indicating an internal change in sync/async stuff. Typically, replacing `getBy` with `findBy`, or `waitFor` a change on the screen before making an assertion resolves the problem. Alternatively, you can use `@ariakit/test` events, which may also be beneficial and prevent these warnings from recurring since it doesn't depend on `act`. More context: https://github.com/WordPress/gutenberg/pull/54225#issuecomment-1711949971
