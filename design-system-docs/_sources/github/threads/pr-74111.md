## Body

## What?

Closes #74079

Updates the animation of `Menu`, and `CustomSelectControl` (v1 & 2) to the new motion specs.

## Why?

Animation like this is inconsistent throughout the component system, and sometimes feels a bit laggy. We need a refreshed animation that can be applied globally.

## How?

There is some refactoring done to allow config sharing across the components, including `Popover` that was done in #74082.

## Testing Instructions

See Storybook for the affected components. `Menu` should also support other `placement`s, such as `"right"`. There should be no regressions in the `Popover`-based components changed in #74082, for example `DropdownMenu`.
