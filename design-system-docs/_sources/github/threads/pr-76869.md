## What?

Update the Page component background color from `--wpds-color-bg-surface-neutral-strong` to `--wpds-color-bg-surface-neutral`.

Storybook:

<img width="851" height="219" alt="image" src="https://github.com/user-attachments/assets/ba98e6bc-6018-4f11-9b44-f617107f97ff" />



## Why?

This follows up on #76548, which originally attempted this change but was rolled back to avoid unintentional design side effects on existing pages (e.g. Styles). The TODO left in that PR is now being fulfilled.

The TODO comment is retained to flag the need for revisiting contrast handling across existing pages.

## How?

- Updated the TODO comment to reflect the current state

It's been helpful for me to follow this logic so far:

- The page surface always has `--wpds-color-bg-surface-neutral` / `#fcfcfc` background.
