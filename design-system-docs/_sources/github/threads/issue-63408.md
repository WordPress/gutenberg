# Issue #63408: ComboboxControl: the Reset button doesn't work when using the keyboard

- URL: https://github.com/WordPress/gutenberg/issues/63408
- Author: afercia
- Created: 2024-07-11T08:44:36Z
- Updated: 2024-07-15T12:49:33Z
- Comments: 0 of 0

## Body

### Description

Discovered while testing the 'Parent' setting for a post of type page.

![Screenshot 2024-07-11 at 10 06 45](https://github.com/WordPress/gutenberg/assets/1682452/10431d50-6841-4add-9519-d4acb4fc37da)

Can be reproduced on the [storybook](https://wordpress.github.io/gutenberg/?path=/story/components-comboboxcontrol--default&args=allowReset:!true) as well, by enabling the `allowReset` prop.

When using the keyboard, pressing the `Enter` key on the optional Reset button doesn not reset the combobox. Pressing the Spacebar key does work.

Turns out when pressing the `Enter` key, the `keydown` event attached on the container div element fires and actually _sets_ the currently selected suggestion.

### Step-by-step reproduction instructions

- Edit a page and use the `Parent` setting with the keyboard.
- Alternatively, test on the storybook, make sure the `allowReset` prop is set to `true`: https://wordpress.github.io/gutenberg/?path=/story/components-comboboxcontrol--default&args=allowReset:!true
- Select a suggestion.
- Click the reset button with your mouse.
- The combobox is reset.
- I would expect the same behavior when using the keyboard.
- Select a suggestion.
- Move focus to the Reset button.
- Press the Spacebar key and observe it does reset the combobox.
- Repeat, but this time press the Enter key and observe it does _not_ reset the comobox.
