# Issue #12583: Allow the PanelColorSettings to be visible if no colors and but with children

- URL: https://github.com/WordPress/gutenberg/issues/12583
- Author: bfintal
- Created: 2018-12-04T11:22:44Z
- Updated: 2026-06-15T03:04:32Z
- Comments: 6 of 6

## Body

**Is your feature request related to a problem? Please describe.**
With the PanelColorSettings, if the color prop is empty, the entire panel stops rendering. However, if PanelColorSettings has children, they won't show anymore also if the color prop is empty. I expect that the panel would still show up if it has children even with no color options available.

**Describe the solution you'd like**
The PanelColorSettings should only hide if there are no color options AND no children. Right now is only checks the number of color options.

**Describe alternatives you've considered**
I tried creating my own PanelColorSettings component to address this, but it uses a lot of unexposed / private components.
