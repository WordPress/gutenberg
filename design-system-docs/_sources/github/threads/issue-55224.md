# Issue #55224: Migrate `Composite` consumers from `reakit` to `ariakit`

- URL: https://github.com/WordPress/gutenberg/issues/55224
- Author: andrewhayward
- Created: 2023-10-10T20:02:57Z
- Updated: 2024-02-08T16:53:21Z
- Comments: 2 of 2

## Body

## What problem does this address?

As per #53278, we need to move away from `reakit` to use `ariakit` instead. #54225 started on migrating [the `Composite` component](https://github.com/WordPress/gutenberg/tree/trunk/packages/components/src/composite), by adding the equivalent `ariakit` modules as a `v2`. This work needs to be completed by migrating all `Composite` consumers to use the `v2` alternative.

## What is your proposed solution?

We need to...
- [x] ...identify all `Composite` consumers across Gutenberg
- [x] ...iteratively refactor all usages of the `reakit` implementation.
  - [See below 👇](#issuecomment-1756246824)

When all consumers are migrated, we should then...
- [x] ...remove the `reakit` version of `Composite`
- [ ] ...make the `ariakit`-based version standard
- [ ] ...move all consumer away from the private API
- [ ] ...remove the private API export
