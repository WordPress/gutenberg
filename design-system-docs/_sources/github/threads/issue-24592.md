# Issue #24592: Popover from @wordpress/components has sizing issues at small screen sizes

- URL: https://github.com/WordPress/gutenberg/issues/24592
- Author: samueljseay
- Created: 2020-08-17T02:40:47Z
- Updated: 2020-12-16T10:45:12Z
- Comments: 6 of 6

## Body

**Describe the bug**
It seems that if a `Popover` has some content that is a bit wide and you narrow the screen size down (even to a screen size that is much wider than the content), it has trouble deciding what size to adjust to and it starts to flicker badly on the screen and become unusable.

**To reproduce**
We've seen this in woocommerce-admin [here](https://github.com/woocommerce/woocommerce-admin/pull/4907) but I wanted to try create a minimal reproduction. Here is a sandbox with `@wordpress/components` and it's stylesheet loaded. I set some inner content to have a width of 500px and if you shrink the preview screen it starts to flicker from any width below about `850px`.

Also note that its not just when resizing the screen. If the screen size is too small on load the flicker will still occur so this is quite problematic.

I also wonder but have not confirmed, if it's possible that #24532 could be related.

Ooh boy. This isn't good 😅 . I worked with the Popover here and there. I believe this flickering is caused by the Popover attempting to **MATH** it's way into a proper size, causing it to go into an infinite **MATH** loop.

We may be hitting some edges/limitations for the Popover component. There's a Github issue (https://github.com/WordPress/gutenberg/issues/21275) that explores improving the underlying mechanics and adding features (like additional alignment positions). In theory, if those are addressed, it should resolve this flickering issue.

In the meantime, we could totally take a look at resolving this flickering issue independently 👍 .
