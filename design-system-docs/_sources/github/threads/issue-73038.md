# Issue #73038: Add isBusy prop to ConfirmDialog

- Updated: 2025-11-10T20:24:44Z

## Body

## What problem does this address?

When a `ConfirmDialog` action takes a while to complete (for example, deleting a large number of records), there’s no indication that the process is underway. This leaves users unsure whether anything is happening. From a UX perspective, it would be helpful to provide clear feedback that the action has started and is still in progress.

## What is your proposed solution?

Introduce an isBusy prop to the component. When enabled, the dialog buttons would be disabled, and the confirm button would display a busy state. This would give users a clear visual cue that the action is processing, while still allowing them to dismiss the dialog by clicking outside of it if needed.
