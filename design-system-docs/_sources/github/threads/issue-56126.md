# Issue #56126: Snackbar component displays the icon outside of its container

- URL: https://github.com/WordPress/gutenberg/issues/56126
- Author: jaredKreate
- Created: 2023-11-14T19:50:02Z
- Updated: 2024-01-03T15:07:36Z

## Body

### Description

### Description
The `snackbar` component has the option to show an icon along with the notice. That icon's display is currently showing too far to the right and down from the expected inline positioning.

### Expectation
The expected behavior for the icon is to show inline with the text that is shown in the `snackbar` component.

### Potential Fix
I believe that the issue lies within the styling for the `snackbar` component elements, below is an example fix based on the story:
```
.components-snackbar__content {
    display: flex;
    justify-content: space-between;
    line-height: 1.4;
    position: relative;
    align-items: center;
    gap: 1rem;
}
```
The above fix removes the need for:
```
.components-snackbar .components-snackbar__content-with-icon {
    margin-left: 24px;
}

.components-snackbar .components-snackbar__icon {
    position: absolute;
    top: 24px;
    left: 28px;
}
```

### Step-by-step reproduction instructions

1. Go to https://wordpress.github.io/gutenberg/?path=/story/components-snackbar--with-icon
2. Notice the icons alignment in relation to the text.
