## Body

## What problem does this address?

The [current `<ThemeProvider>` documentation](https://github.com/WordPress/gutenberg/blob/trunk/packages/theme/README.md#theme-provider) references a `scheme` value which is not actually supported by the component. 

## What is your proposed solution?

The documentation should be updated to reflect expected usage, specifically by providing `{ color: { bg: '...', primary: '...' } }` value.
