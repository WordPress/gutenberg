# Issue #16598: Button Background Styling In The Inserter

- URL: https://github.com/WordPress/gutenberg/issues/16598
- Author: tomjn
- Created: 2019-07-15T20:52:21Z
- Updated: 2019-10-01T09:44:22Z
- Comments: 3 of 3

## Body

**Describe the bug**

The `<button>` background style is inherited, meaning it is overriden by other unrelated styles easily. This can lead to unviewable buttons in the inserter when used outside of a post edit screen context.

For example in twentynineteen, this results in black text on a black background. I can avoid this issue with the following CSS rule:

```css
button.editor-block-types-list__item:hover {
	background: transparent;
}
```

### tomjn on 2019-07-16T11:34:10Z

URL: https://github.com/WordPress/gutenberg/issues/16598#issuecomment-511778828

TwentyNineteen contains this style:

```css
.button:hover, button:hover, input[type="button"]:hover, input[type="reset"]:hover, input[type="submit"]:hover {
    background: #111;
    cursor: pointer;
}
```

Which means that when you hover over a button in the block inserter it's not possible to see the result:

<img width="444" alt="Screenshot 2019-07-16 at 12 32 39" src="https://user-images.githubusercontent.com/58855/61291256-ee4e1000-a7c5-11e9-9deb-d04e010036d1.png">


I added a rule to override this and enforce the original background style by setting it to `transparent`
