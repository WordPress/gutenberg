# Issue #50448: Modal headings and labels missing editor text color

- URL: https://github.com/WordPress/gutenberg/issues/50448
- Author: richtabor
- Created: 2023-05-08T21:01:43Z
- Updated: 2025-09-04T16:06:36Z
- Comments: 4 of 4

## Body

The text contents within modals are missing proper text colors used throughout the editor. Headings for example are styled using values (#1d2327) from wp-admin common.css, where they should be using the $gray-900 (#1e1e1e). The toggle labels from the Preferences modal are also using a style (#3c434a) from common.css. 

We have `.interface-complementary-area { color: #1e1e1e;}` that applies the standard coloring to other areas of the editor.
