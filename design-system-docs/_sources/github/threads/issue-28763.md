## Description
The RadioControl documentation at https://developer.wordpress.org/block-editor/components/radio-control/ shows the following example screenshot:

![](https://make.wordpress.org/design/files/2018/11/radio-usage-do.png)

This is not a RadioControl; it's something custom: https://github.com/WordPress/gutenberg/blob/004a32ec09d5b789be694d85725fe49cca385f08/packages/editor/src/components/post-visibility/index.js#L94-L124

The key difference that led me to notice and file this bug is that the image shows labels with a header text followed by a description. While this is doable by passing HTML into the label property of each option, it's not behavior that is described on the page, and the example code shown results in something that looks different.

## Step-by-step reproduction instructions

1. Visit https://developer.wordpress.org/block-editor/components/radio-control/

## Expected behaviour
The RadioControl docs should use a RadioControl as an example.

## Actual behaviour
The RadioControl docs screenshot a component that is not a RadioControl.
