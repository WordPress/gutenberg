## What?

Closes #77348

Migrates the Menu component to the `@wordpress/ui` package, utilizing`@base-ui/react/menu` as the underlying headless primitive.
## Why?
Moving to Base UI removes legacy dependencies, fixes modal stacking/inert issues natively, and ensures strict adherence to the new --wpds-* design system tokens.

## How?
Replaced the Ariakit engine with `@base-ui/react/menu`, utilizing its native Portal and Positioner primitives for cross-bundle rendering.

## Testing Instructions
To verify the component's functionality, visual parity, and accessibility:
1. Check out this branch and start the local Storybook server by running:
```bash
npm run storybook:dev
```
2. Open Storybook in your browser (usually http://localhost:50242).
3. In the left sidebar, navigate to Design System -> Components -> Menu.
4. Open the stories and verify interactivity, keyboard navigation, visual parity and layout for all stories.
