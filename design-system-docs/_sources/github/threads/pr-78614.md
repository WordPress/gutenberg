## Body

## What?

  Closes #78595.

  Fixes `Button.Icon` so it no longer crops icons with non-standard `viewBox` values.

  ## Why?

  `Button.Icon` was forcing every icon into `viewBox="4 4 16 16"`. That worked as a sizing shortcut for some icons, but it clipped icons whose visible artwork sits outside that inset area, including several icons from `@wordpress/icons`.

  ## How?

  - Stop overriding the icon's own `viewBox`.
  - Render the default button icon at the normal 24px icon size.
  - Use a small negative margin so the icon keeps the same footprint inside the button.
  - Add a regression test for a non-standard icon viewBox.

  ## Testing Instructions

  1. Run `npm run test:unit -- packages/ui/src/button/test/icon.test.tsx --runInBand`.
  2. Open the Button story in Storybook.
  3. Render `Button.Icon` with an icon that uses a non-standard viewBox, such as `wordpress` or `keyboardClose`.
  4. Confirm the icon is not clipped inside the button.

  ### Testing Instructions for Keyboard

  1. Tab to a button that contains `Button.Icon`.
  2. Confirm the button receives focus normally.
  3. Confirm the icon remains visible and does not affect keyboard focus behavior.
