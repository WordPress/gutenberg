I see! From what I can tell from the [docs](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files) and actual behavior though, the new file access restrictions are only for private repositories, not public ones like Gutenberg. The URLs we get are now `github.com/WordPress/gutenberg/assets/*` that redirect to the actual file, instead of a direct `user-images.githubusercontent.com` link.

For example, I attached your images to this comment, and the URLs should be accessible in an Incognito tab without authentication:

![Radio buttons](https://github.com/WordPress/gutenberg/assets/555336/4a373812-d85c-4f10-83b9-775c1b575bce)
![Checkboxes](https://github.com/WordPress/gutenberg/assets/555336/8d86ea71-4f33-4aac-980d-05425b0f40d3)

We are [starting to use](https://github.com/search?q=repo%3AWordPress%2Fgutenberg+user-images.githubusercontent&type=code) more GitHub hosted images for our docs, since it's a lot easier to maintain.
