# Issue #13207: Option to remove Modal Header

- URL: https://github.com/WordPress/gutenberg/issues/13207
- Author: HardeepAsrani
- Created: 2019-01-05T11:46:56Z
- Updated: 2020-04-20T16:34:18Z
- Comments: 2 of 2

## Body

As of now, Modal component doesn't allow you to disable its header, in case if you wanted to build your own header to match with your details, something I'm trying to do.

This limits the flexibility of the component, and there should be an option to disable the header of the modal.

We can right now disable the close button and leave the title empty, but then it just leaves an empty `div` tag which isn't ideal.

I've prepared a PR for this and can send if this is something people consider to be useful.
