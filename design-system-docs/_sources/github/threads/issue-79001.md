### Description

This is a follow-up issue from https://github.com/WordPress/gutenberg/pull/78397. The PR adopted WPDS color tokens so the themed site-editor chrome inherits the user's admin color scheme automatically.

However, a few hardcoded colors were intentionally left out of scope to keep the PR focused. This issue tracks them:

- Convert remaining `$gray-300` borders to an appropriate token consistently. #78397 converted only the instance in `packages/edit-site/src/components/layout/style.scss` (to `--wpds-color-stroke-surface-neutral`). There are a few more borders across `@wordpress/components` that should be updated together to keep borders consistent. See this thread: https://github.com/WordPress/gutenberg/pull/78397#discussion_r3361624143
