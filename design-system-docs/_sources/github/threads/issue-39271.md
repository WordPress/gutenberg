# Issue #39271: BaseControl help text not screen reader accessible

- URL: https://github.com/WordPress/gutenberg/issues/39271
- Author: tellthemachines
- Created: 2022-03-08T00:10:37Z
- Updated: 2022-03-08T23:44:28Z

## Body

### Description

The BaseControl component accepts a `help` prop, that renders as an additional description for the control. That description is wrapped in a `p` tag, but it is not linked to the control in any way, so screen readers ignore it.

One way to fix this is adding `aria-describedby` to the control itself, pointing to the `id` of the description.

### Step-by-step reproduction instructions

1. In the post editor, click the top right hand side "Options" button, and then click the last button on the dropdown, "Preferences". This should open a modal dialog with three tabs of editor preferences.
2. Under General > Publishing, there is a toggle with the label Include pre-publish checklist" and help text: "Review settings, such as visibility and tags."
3. Using a screen reader, focus this control. Note the label is read out but the help text is ignored.
