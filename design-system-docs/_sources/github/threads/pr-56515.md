## What?
<!-- In a few words, what is the PR actually doing? -->

Improve the animation and the high-contrast mode styles for `FormToggle` component, which is also used in the `ToggleControl` component

## Why?
<!-- Why is this PR necessary? What problem is it solving? Reference any existing previous issue(s) or PR(s), but please add a short summary here, too -->

In the current version of the component, the track border and the thumb color are not animated when the toggle is flipped.

An improved animation gives a better sense of polish to the component and the UI in general.

Improvements to how the component is rendered in High Contrast mode benefit assistive technology users.

## How?
<!-- How is your PR addressing the issue at hand? What are the implementation details? -->

By applying a few tweaks to `FormToggle`'s styles:

- added transition for the track border
- added transition for the track background color
- refactored how track and thumb were styles for high-contrast mode in the process
- aligned all animation durations to the same value

## Testing Instructions
<!-- Please include step by step instructions on how to test this PR. -->
<!-- 1. Open a post or page. -->
<!-- 2. Insert a heading block. -->
<!-- 3. etc. -->

- Make sure that the new toggle animation looks good. This can be checked:
  - in the `FormToggle` and `ToggleControl` storybook examples
  - In the block editor, interact with any instance of `FormToggle` or `ToggleControl`
    - For example, add a Group Block, and open the sidebar. There is a "Inner blocks use content width" toggle control
 - Make sure that the new animation is completely deactivated when the user prefers reduced motion (that can be simulated via the browser dev tools)
 - Make sure that the component looks good also in High Contrast mode (that can be simulated via the browser dev tools)
