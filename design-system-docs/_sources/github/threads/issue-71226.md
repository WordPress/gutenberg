# Issue #71226: Add isDestructive support to ConfirmDialog.

- Created: 2025-08-15T12:04:59Z

## Body

## What problem does this address?
Currently when using the ConfirmDialog component (experimental), there's no way to designate that the action is a destructive action. For example, when trashing a post, the dialog box just contains a blue button:

<img width="401" height="188" alt="Image" src="https://github.com/user-attachments/assets/32af8402-0560-4ed7-adfb-168b95788f66" />

If this button were red, it could provide more contextual information that an action is destructive, as per this mockup:

<img width="409" height="198" alt="Image" src="https://github.com/user-attachments/assets/cc09ef91-f44a-4c7e-9af9-4f20e27152a5" />

## What is your proposed solution?
Add a prop to the component called `isDestructive` and pass it through to the primary button.

#58390 

If this is agreed, I'm happy to work on a PR for this myself.
