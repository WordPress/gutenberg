# Issue #46814: `@wordpress/components`: add `type="button"` to vanilla `<button />` elements

## Body

## Update 9 Jan 2023

As [agreed](https://github.com/WordPress/gutenberg/issues/46814#issuecomment-1372216151), we should add `type="button` to all vanilla `<button />` elements in the `@wordpress/components` package.

## Original issue description:

In https://github.com/Automattic/isolated-block-editor/issues/197 it is flagged that the `button` element rendered by the `Button` component doesn't always have `type="button"`, which leads to forms being submitted involontarily.

By having a quick look at the code, it looks like the `type="button"` attribute should be always assigned by default to all rendered `buttons` (in fact, it's not assigned only when `Button` renders an anchor tag, which seems correct):

https://github.com/WordPress/gutenberg/blob/1645fb2292ce2064b6a74f09be1069b794106cca/packages/components/src/button/index.js#L116-L123

We should investigate better the issue reported in https://github.com/Automattic/isolated-block-editor/issues/197 and understand why the `Button` component is not behaving as expected.
