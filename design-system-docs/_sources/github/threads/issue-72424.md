# Issue #72424: SelectControl component with "minimal" variation does not have right padding on Chrome on Windows

- URL: https://github.com/WordPress/gutenberg/issues/72424
- Author: epeicher
- Created: 2025-10-17T09:29:54Z
- Updated: 2026-04-16T22:30:37Z
- Comments: 2 of 2

## Body

### Description

The SelectControl component when using with variant="minimal" does not add right padding to the options when displayed on Chrome on Windows machines.

Further context about this issue here https://github.com/WordPress/gutenberg/pull/63265#issuecomment-3408039140

### Step-by-step reproduction instructions

1. On a Windows machine using Chrome browser
2. Open `SelectControl` component on StoryBook https://wordpress.github.io/gutenberg/?path=/docs/components-selectcontrol--docs
3. On the first example, scroll down on the props, find the `variant` and select `minimal` <img width="1150" height="250" alt="Image" src="https://github.com/user-attachments/assets/9f997ba7-f08c-4292-8715-30fcd17e4267" />
4. Scroll up to see the component and expand the dropdown
5. Observe that the first option (labeled `Select an Option`) does not have right margin
