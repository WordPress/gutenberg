## What?

Fixes the icon positioning in the `Snackbar` component, and updates the Storybook story to reflect how it is intended to be used per the WordPress design system (24px icon with a solid color fill).

As seen on [Figma](https://www.figma.com/file/e4tLacmlPuZV47l7901FEs/WordPress-Design-Library?type=design&node-id=28926-23409&mode=design&t=1r9uJhspY48trhqo-4):

## Testing Instructions

See the "Snackbar - With Icon" story in Storybook. The icon should be positioned properly in different situations, e.g. when the content is long and wraps, when there is an `explicitDismiss` button, or when there are actions.
