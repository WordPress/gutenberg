# Icons

Icons should clarify an action or object. They should not be the only way important information is conveyed.

## Rules

- Pair icons with text when space allows.
- For icon-only actions, use an accessible label and a visible tooltip only as a supplement.
- Do not use icons inside badges by default. Badge icon usage is unresolved and currently discouraged because it complicates status meaning and layout.
- Do not rely on tooltip discovery on touch devices.
- Use the shared icon package rather than recreating icons inside components.

See [Icon buttons](icon-buttons.md) for icon-only controls and [Tooltip](../library/ui/tooltip.md) for label behavior.
