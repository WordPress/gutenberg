# Automattic Design System Reference Drafts

This directory contains a local source archive and a curated markdown draft for the design system reference site at <https://system.automattic.design/>.

The public-facing draft follows the site's current top-level navigation:

- [Get started](get-started/index.md)
- [Foundations](foundations/index.md)
- [Icons](icons/index.md)
- [Library](library/index.md)

The raw GitHub corpus is under [_sources/github](_sources/github/). It includes the labeled Gutenberg issues and PRs, their issue comments, PR review threads, changed-file metadata, and direct PR diffs where fetched. The authored pages intentionally do not repeat every discussion. They turn recurring decisions into rules and link to the source material when the history matters.

Use [navigation.md](navigation.md) as the proposed site map.
