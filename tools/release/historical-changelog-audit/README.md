# Historical package changelog audit

This directory records the evidence used to regenerate the historical package
changelog corrections associated with
[WordPress/gutenberg#81561](https://github.com/WordPress/gutenberg/pull/81561).
The pull request is treated as a candidate, not as evidence.

## Frozen inputs

-   Trunk baseline: `cd0c368a2e5e2d046306031ddd824d3f5eda60bd`
-   Candidate merge base: `150cd6da989707269f3fa5cc79eae7630895450b`
-   Candidate head: `91d773465a4cb3372d8dc33c6baa055be46d5f9c`
-   Audit start: `2019-03-06`

`release-lanes.json` freezes the immutable package-release lane tips used by
the audit. The other input manifests record reviewed event pairing, shipment,
and independent-review decisions. All reviewed decisions are bound to the
frozen baseline and are revalidated when the ledger is built.

`publish-inventory.json` is the derived per-event inventory. Each stable
publish row records its tags, classification, release-side snapshots, trunk
pairing or reviewed exclusion, and previous/next event on every matching
release lane. Its SHA-256 is
`69bc7039d3fd633df419f27ee2237afe2fafae50a2e27324a52b54a460d46c91`.

## Regenerate and verify

Run the audit from a full Gutenberg clone containing the historical package
tags:

```bash
node tools/release/audit-historical-package-changelogs.js \
	--trunk-ref cd0c368a2e5e2d046306031ddd824d3f5eda60bd \
	--event-resolutions tools/release/historical-changelog-audit/event-resolutions.json \
	--release-lanes tools/release/historical-changelog-audit/release-lanes.json \
	--output tools/release/historical-changelog-audit/publish-inventory.json \
	> /dev/null
```

Run the structural audits and build the correction ledger:

```bash
node tools/release/audit-historical-package-changelogs.js \
	--trunk-ref cd0c368a2e5e2d046306031ddd824d3f5eda60bd \
	--event-resolutions tools/release/historical-changelog-audit/event-resolutions.json \
	--release-lanes tools/release/historical-changelog-audit/release-lanes.json \
	--immediate --secondary --frozen --ledger --prove-shipments \
	--shipment-resolutions tools/release/historical-changelog-audit/shipment-resolutions.json \
	--review-resolutions tools/release/historical-changelog-audit/review-resolutions.json \
	--summary-only \
	--summary-output tools/release/historical-changelog-audit/audit-summary.json \
	--ledger-output tools/release/historical-changelog-audit/correction-ledger.json
```

Regenerate the changelogs from the ledger:

```bash
node tools/release/generate-historical-package-changelogs.js \
	--ledger tools/release/historical-changelog-audit/correction-ledger.json \
	--write \
	--report tools/release/historical-changelog-audit/generation-report.json
```

Run the generator again. It must report zero written files, 105 unchanged
files, 650 verified corrections, and zero malformed or duplicate headings.
The generator fails if a target differs from both the frozen baseline and the
generated bytes.

Compare the frozen candidate with the generated result:

```bash
node tools/release/compare-historical-package-changelogs.js \
	--ledger tools/release/historical-changelog-audit/correction-ledger.json \
	--candidate-merge-base 150cd6da989707269f3fa5cc79eae7630895450b \
	--candidate 91d773465a4cb3372d8dc33c6baa055be46d5f9c \
	--report tools/release/historical-changelog-audit/candidate-comparison.json
```

## Recorded result

The committed inventory records all 531 stable publish events, of which 496
are in scope, plus all 7,143 excluded prerelease tags. The audit accounts for
all 2,963 mutations to 5,346 frozen released entry blocks.
The ledger contains 650 proposed corrections across 105 changelogs, three
already-corrected rows, 1,804 accepted exceptions, and no unresolved
corrections, pending shipment proofs, or pending independent reviews.

The generated tree differs materially from the frozen candidate. The candidate
satisfies 91 corrections exactly and 10 equivalently, omits 549, makes eight
partially unauthorized changes, and contains 39 entirely unlisted structural
changes. `candidate-comparison.json` maps and explains every candidate change.

Future-release prevention is intentionally separate from this historical
correction and is tracked by
[WordPress/gutenberg#81566](https://github.com/WordPress/gutenberg/pull/81566).

At the final historical-audit check on 2026-08-17, prevention head
`d91e2278d97119a7c72781a3a95217edea7ebcfa` passed all eight GitHub Actions
workflows. An independent detached-worktree run also passed all 149
`tools/release` unit tests, four snapshots, targeted JavaScript lint, and
`git diff --check`. The pull request was still open, unmerged, and awaiting its
first human review. These results verify the proposed mechanism but do not
claim that `trunk` is protected before it merges.
