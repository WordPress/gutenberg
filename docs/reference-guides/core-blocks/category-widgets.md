# Widgets Blocks

- [Archives](./archives.md) — `core/archives`: Display a date archive of your posts.
- [Calendar](./calendar.md) — `core/calendar`: A calendar of your site’s posts.
- [Terms List](./categories.md) — `core/categories`: Display a list of all terms of a given taxonomy.
- [Custom HTML](./html.md) — `core/html`: Add custom HTML code and preview it as you edit.
- [Latest Comments](./latest-comments.md) — `core/latest-comments`: Display a list of your most recent comments.
- [Latest Posts](./latest-posts.md) — `core/latest-posts`: Display a list of your most recent posts.
- [Page List](./page-list.md) — `core/page-list`: Display a list of all pages.
- [Page List Item](./page-list-item.md) — `core/page-list-item`: Displays a page inside a list of all pages.
- [RSS](./rss.md) — `core/rss`: Display entries from any RSS or Atom feed.
- [Search](./search.md) — `core/search`: Help visitors find your content.
- [Shortcode](./shortcode.md) — `core/shortcode`: Insert additional custom elements with a WordPress shortcode.
- [Social Icon](./social-link.md) — `core/social-link`: Display an icon linking to a social profile or site.
- [Social Icons](./social-links.md) — `core/social-links`: Display icons linking to your social profiles or sites.
- [Tag Cloud](./tag-cloud.md) — `core/tag-cloud`: A cloud of popular keywords, each sized by how often it appears.
