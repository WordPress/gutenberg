# Widgets Blocks

- [Archives](../../../packages/block-library/src/archives/README.md) — `core/archives`: Display a date archive of your posts.
- [Calendar](../../../packages/block-library/src/calendar/README.md) — `core/calendar`: A calendar of your site’s posts.
- [Terms List](../../../packages/block-library/src/categories/README.md) — `core/categories`: Display a list of all terms of a given taxonomy.
- [Custom HTML](../../../packages/block-library/src/html/README.md) — `core/html`: Add custom HTML code and preview it as you edit.
- [Latest Comments](../../../packages/block-library/src/latest-comments/README.md) — `core/latest-comments`: Display a list of your most recent comments.
- [Latest Posts](../../../packages/block-library/src/latest-posts/README.md) — `core/latest-posts`: Display a list of your most recent posts.
- [Page List](../../../packages/block-library/src/page-list/README.md) — `core/page-list`: Display a list of all pages.
- [Page List Item](../../../packages/block-library/src/page-list-item/README.md) — `core/page-list-item`: Displays a page inside a list of all pages.
- [RSS](../../../packages/block-library/src/rss/README.md) — `core/rss`: Display entries from any RSS or Atom feed.
- [Search](../../../packages/block-library/src/search/README.md) — `core/search`: Help visitors find your content.
- [Shortcode](../../../packages/block-library/src/shortcode/README.md) — `core/shortcode`: Insert additional custom elements with a WordPress shortcode.
- [Social Icon](../../../packages/block-library/src/social-link/README.md) — `core/social-link`: Display an icon linking to a social profile or site.
- [Social Icons](../../../packages/block-library/src/social-links/README.md) — `core/social-links`: Display icons linking to your social profiles or sites.
- [Tag Cloud](../../../packages/block-library/src/tag-cloud/README.md) — `core/tag-cloud`: A cloud of popular keywords, each sized by how often it appears.
