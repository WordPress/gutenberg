# Theme Blocks

- [Avatar](../../../packages/block-library/src/avatar/README.md) — `core/avatar`: Add a user’s avatar.
- [Breadcrumbs](../../../packages/block-library/src/breadcrumbs/README.md) — `core/breadcrumbs`: Display a breadcrumb trail showing the path to the current page.
- [Comment Author Avatar (deprecated)](../../../packages/block-library/src/comment-author-avatar/README.md) — `core/comment-author-avatar`: This block is deprecated. Please use the Avatar block instead.
- [Comment Author Name](../../../packages/block-library/src/comment-author-name/README.md) — `core/comment-author-name`: Displays the name of the author of the comment.
- [Comment Content](../../../packages/block-library/src/comment-content/README.md) — `core/comment-content`: Displays the contents of a comment.
- [Comment Date](../../../packages/block-library/src/comment-date/README.md) — `core/comment-date`: Displays the date on which the comment was posted.
- [Comment Edit Link](../../../packages/block-library/src/comment-edit-link/README.md) — `core/comment-edit-link`: Displays a link to edit the comment in the WordPress Dashboard. This link is only visible to users with the edit comment capability.
- [Comment Reply Link](../../../packages/block-library/src/comment-reply-link/README.md) — `core/comment-reply-link`: Displays a link to reply to a comment.
- [Comments](../../../packages/block-library/src/comments/README.md) — `core/comments`: An advanced block that allows displaying post comments using different visual configurations.
- [Comments Pagination](../../../packages/block-library/src/comments-pagination/README.md) — `core/comments-pagination`: Displays a paginated navigation to next/previous set of comments, when applicable.
- [Comments Next Page](../../../packages/block-library/src/comments-pagination-next/README.md) — `core/comments-pagination-next`: Displays the next comment's page link.
- [Comments Page Numbers](../../../packages/block-library/src/comments-pagination-numbers/README.md) — `core/comments-pagination-numbers`: Displays a list of page numbers for comments pagination.
- [Comments Previous Page](../../../packages/block-library/src/comments-pagination-previous/README.md) — `core/comments-pagination-previous`: Displays the previous comment's page link.
- [Comments Title](../../../packages/block-library/src/comments-title/README.md) — `core/comments-title`: Displays a title with the number of comments.
- [Login/out](../../../packages/block-library/src/loginout/README.md) — `core/loginout`: Show login & logout links.
- [Navigation](../../../packages/block-library/src/navigation/README.md) — `core/navigation`: A collection of blocks that allow visitors to get around your site.
- [Pattern Placeholder](../../../packages/block-library/src/pattern/README.md) — `core/pattern`: Show a block pattern.
- [Author (deprecated)](../../../packages/block-library/src/post-author/README.md) — `core/post-author`: This block is deprecated. Please use the Avatar block, the Author Name block, and the Author Biography block instead.
- [Author Biography](../../../packages/block-library/src/post-author-biography/README.md) — `core/post-author-biography`: The author biography.
- [Author Name](../../../packages/block-library/src/post-author-name/README.md) — `core/post-author-name`: The author name.
- [Comment (deprecated)](../../../packages/block-library/src/post-comment/README.md) — `core/post-comment`: This block is deprecated. Please use the Comments block instead.
- [Comments Count](../../../packages/block-library/src/post-comments-count/README.md) — `core/post-comments-count`: Display a post's comments count.
- [Comments Form](../../../packages/block-library/src/post-comments-form/README.md) — `core/post-comments-form`: Display a post's comments form.
- [Comments Link](../../../packages/block-library/src/post-comments-link/README.md) — `core/post-comments-link`: Displays the link to the current post comments.
- [Content](../../../packages/block-library/src/post-content/README.md) — `core/post-content`: Displays the contents of a post or page.
- [Date](../../../packages/block-library/src/post-date/README.md) — `core/post-date`: Display a custom date.
- [Excerpt](../../../packages/block-library/src/post-excerpt/README.md) — `core/post-excerpt`: Display the excerpt.
- [Featured Image](../../../packages/block-library/src/post-featured-image/README.md) — `core/post-featured-image`: Display a post's featured image.
- [Post Navigation Link](../../../packages/block-library/src/post-navigation-link/README.md) — `core/post-navigation-link`: Displays the next or previous post link that is adjacent to the current post.
- [Post Template](../../../packages/block-library/src/post-template/README.md) — `core/post-template`: Contains the block elements used to render a post, like the title, date, featured image, content or excerpt, and more.
- [Post Terms](../../../packages/block-library/src/post-terms/README.md) — `core/post-terms`: Post terms.
- [Time to Read](../../../packages/block-library/src/post-time-to-read/README.md) — `core/post-time-to-read`: Show minutes required to finish reading the post. Can also show a word count.
- [Title](../../../packages/block-library/src/post-title/README.md) — `core/post-title`: Displays the title of a post, page, or any other content-type.
- [Query Loop](../../../packages/block-library/src/query/README.md) — `core/query`: An advanced block that allows displaying post types based on different query parameters and visual configurations.
- [No Results](../../../packages/block-library/src/query-no-results/README.md) — `core/query-no-results`: Contains the block elements used to render content when no query results are found.
- [Pagination](../../../packages/block-library/src/query-pagination/README.md) — `core/query-pagination`: Displays a paginated navigation to next/previous set of posts, when applicable.
- [Next Page](../../../packages/block-library/src/query-pagination-next/README.md) — `core/query-pagination-next`: Displays the next posts page link.
- [Page Numbers](../../../packages/block-library/src/query-pagination-numbers/README.md) — `core/query-pagination-numbers`: Displays a list of page numbers for pagination.
- [Previous Page](../../../packages/block-library/src/query-pagination-previous/README.md) — `core/query-pagination-previous`: Displays the previous posts page link.
- [Query Title](../../../packages/block-library/src/query-title/README.md) — `core/query-title`: Display the query title.
- [Query Total](../../../packages/block-library/src/query-total/README.md) — `core/query-total`: Display the total number of results in a query.
- [Read More](../../../packages/block-library/src/read-more/README.md) — `core/read-more`: Displays the link of a post, page, or any other content-type.
- [Site Logo](../../../packages/block-library/src/site-logo/README.md) — `core/site-logo`: Display an image to represent this site. Update this block and the changes apply everywhere.
- [Site Tagline](../../../packages/block-library/src/site-tagline/README.md) — `core/site-tagline`: Describe in a few words what this site is about. This is important for search results, sharing on social media, and gives overall clarity to visitors.
- [Site Title](../../../packages/block-library/src/site-title/README.md) — `core/site-title`: Displays the name of this site. Update the block, and the changes apply everywhere it’s used. This will also appear in the browser title bar and in search results.
- [Template Part](../../../packages/block-library/src/template-part/README.md) — `core/template-part`: Edit the different global regions of your site, like the header, footer, sidebar, or create your own.
- [Term Count](../../../packages/block-library/src/term-count/README.md) — `core/term-count`: Displays the post count of a taxonomy term.
- [Term Description](../../../packages/block-library/src/term-description/README.md) — `core/term-description`: Display the description of categories, tags and custom taxonomies when viewing an archive.
- [Term Name](../../../packages/block-library/src/term-name/README.md) — `core/term-name`: Displays the name of a taxonomy term.
- [Term Template](../../../packages/block-library/src/term-template/README.md) — `core/term-template`: Contains the block elements used to render a taxonomy term, like the name, description, and more.
- [Terms Query](../../../packages/block-library/src/terms-query/README.md) — `core/terms-query`: An advanced block that allows displaying taxonomy terms based on different query parameters and visual configurations.
