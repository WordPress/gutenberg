# Theme Blocks

- [Avatar](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-avatar/) — `core/avatar`: Add a user’s avatar.
- [Breadcrumbs](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-breadcrumbs/) — `core/breadcrumbs`: Display a breadcrumb trail showing the path to the current page.
- [Comment Author Avatar (deprecated)](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comment-author-avatar/) — `core/comment-author-avatar`: This block is deprecated. Please use the Avatar block instead.
- [Comment Author Name](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comment-author-name/) — `core/comment-author-name`: Displays the name of the author of the comment.
- [Comment Content](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comment-content/) — `core/comment-content`: Displays the contents of a comment.
- [Comment Date](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comment-date/) — `core/comment-date`: Displays the date on which the comment was posted.
- [Comment Edit Link](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comment-edit-link/) — `core/comment-edit-link`: Displays a link to edit the comment in the WordPress Dashboard. This link is only visible to users with the edit comment capability.
- [Comment Reply Link](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comment-reply-link/) — `core/comment-reply-link`: Displays a link to reply to a comment.
- [Comments](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comments/) — `core/comments`: An advanced block that allows displaying post comments using different visual configurations.
- [Comments Pagination](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comments-pagination/) — `core/comments-pagination`: Displays a paginated navigation to next/previous set of comments, when applicable.
- [Comments Next Page](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comments-pagination-next/) — `core/comments-pagination-next`: Displays the next comment's page link.
- [Comments Page Numbers](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comments-pagination-numbers/) — `core/comments-pagination-numbers`: Displays a list of page numbers for comments pagination.
- [Comments Previous Page](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comments-pagination-previous/) — `core/comments-pagination-previous`: Displays the previous comment's page link.
- [Comments Title](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-comments-title/) — `core/comments-title`: Displays a title with the number of comments.
- [Login/out](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-loginout/) — `core/loginout`: Show login & logout links.
- [Navigation](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-navigation/) — `core/navigation`: A collection of blocks that allow visitors to get around your site.
- [Pattern Placeholder](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-pattern/) — `core/pattern`: Show a block pattern.
- [Author (deprecated)](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-author/) — `core/post-author`: This block is deprecated. Please use the Avatar block, the Author Name block, and the Author Biography block instead.
- [Author Biography](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-author-biography/) — `core/post-author-biography`: The author biography.
- [Author Name](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-author-name/) — `core/post-author-name`: The author name.
- [Comment (deprecated)](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-comment/) — `core/post-comment`: This block is deprecated. Please use the Comments block instead.
- [Comments Count](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-comments-count/) — `core/post-comments-count`: Display a post's comments count.
- [Comments Form](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-comments-form/) — `core/post-comments-form`: Display a post's comments form.
- [Comments Link](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-comments-link/) — `core/post-comments-link`: Displays the link to the current post comments.
- [Content](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-content/) — `core/post-content`: Displays the contents of a post or page.
- [Date](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-date/) — `core/post-date`: Display a custom date.
- [Excerpt](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-excerpt/) — `core/post-excerpt`: Display the excerpt.
- [Featured Image](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-featured-image/) — `core/post-featured-image`: Display a post's featured image.
- [Post Navigation Link](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-navigation-link/) — `core/post-navigation-link`: Displays the next or previous post link that is adjacent to the current post.
- [Post Template](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-template/) — `core/post-template`: Contains the block elements used to render a post, like the title, date, featured image, content or excerpt, and more.
- [Post Terms](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-terms/) — `core/post-terms`: Post terms.
- [Time to Read](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-time-to-read/) — `core/post-time-to-read`: Show minutes required to finish reading the post. Can also show a word count.
- [Title](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-post-title/) — `core/post-title`: Displays the title of a post, page, or any other content-type.
- [Query Loop](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-query/) — `core/query`: An advanced block that allows displaying post types based on different query parameters and visual configurations.
- [No Results](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-query-no-results/) — `core/query-no-results`: Contains the block elements used to render content when no query results are found.
- [Pagination](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-query-pagination/) — `core/query-pagination`: Displays a paginated navigation to next/previous set of posts, when applicable.
- [Next Page](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-query-pagination-next/) — `core/query-pagination-next`: Displays the next posts page link.
- [Page Numbers](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-query-pagination-numbers/) — `core/query-pagination-numbers`: Displays a list of page numbers for pagination.
- [Previous Page](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-query-pagination-previous/) — `core/query-pagination-previous`: Displays the previous posts page link.
- [Query Title](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-query-title/) — `core/query-title`: Display the query title.
- [Query Total](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-query-total/) — `core/query-total`: Display the total number of results in a query.
- [Read More](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-read-more/) — `core/read-more`: Displays the link of a post, page, or any other content-type.
- [Site Logo](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-site-logo/) — `core/site-logo`: Display an image to represent this site. Update this block and the changes apply everywhere.
- [Site Tagline](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-site-tagline/) — `core/site-tagline`: Describe in a few words what this site is about. This is important for search results, sharing on social media, and gives overall clarity to visitors.
- [Site Title](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-site-title/) — `core/site-title`: Displays the name of this site. Update the block, and the changes apply everywhere it’s used. This will also appear in the browser title bar and in search results.
- [Template Part](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-template-part/) — `core/template-part`: Edit the different global regions of your site, like the header, footer, sidebar, or create your own.
- [Term Count](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-term-count/) — `core/term-count`: Displays the post count of a taxonomy term.
- [Term Description](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-term-description/) — `core/term-description`: Display the description of categories, tags and custom taxonomies when viewing an archive.
- [Term Name](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-term-name/) — `core/term-name`: Displays the name of a taxonomy term.
- [Term Template](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-term-template/) — `core/term-template`: Contains the block elements used to render a taxonomy term, like the name, description, and more.
- [Terms Query](/block-editor/reference-guides/core-blocks/core-blocks-theme/core-block-terms-query/) — `core/terms-query`: An advanced block that allows displaying taxonomy terms based on different query parameters and visual configurations.
