# Design Blocks

- [Accordion](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-accordion/) — `core/accordion`: Displays a foldable layout that groups content in collapsible sections.
- [Accordion Heading](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-accordion-heading/) — `core/accordion-heading`: Displays a heading that toggles the accordion panel.
- [Accordion Item](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-accordion-item/) — `core/accordion-item`: Wraps the heading and panel in one unit.
- [Accordion Panel](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-accordion-panel/) — `core/accordion-panel`: Contains the hidden or revealed content beneath the heading.
- [Button](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-button/) — `core/button`: Prompt visitors to take action with a button-style link.
- [Buttons](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-buttons/) — `core/buttons`: Prompt visitors to take action with a group of button-style links.
- [Column](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-column/) — `core/column`: A single column within a columns block.
- [Columns](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-columns/) — `core/columns`: Display content in multiple columns, with blocks added to each column.
- [Comment Template](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-comment-template/) — `core/comment-template`: Contains the block elements used to display a comment, like the title, date, author, avatar and more.
- [Group](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-group/) — `core/group`: Gather blocks in a layout container.
- [Home Link](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-home-link/) — `core/home-link`: Create a link that always points to the homepage of the site. Usually not necessary if there is already a site title link present in the header.
- [More](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-more/) — `core/more`: Content before this block will be shown in the excerpt on your archives page.
- [Custom Link](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-navigation-link/) — `core/navigation-link`: Add a page, link, or another item to your navigation.
- [Navigation Overlay Close](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-navigation-overlay-close/) — `core/navigation-overlay-close`: A customizable button to close overlays.
- [Submenu](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-navigation-submenu/) — `core/navigation-submenu`: Add a submenu to your navigation.
- [Page Break](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-nextpage/) — `core/nextpage`: Separate your content into a multi-page experience.
- [Separator](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-separator/) — `core/separator`: Create a break between ideas or sections with a horizontal separator.
- [Spacer](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-spacer/) — `core/spacer`: Add white space between blocks and customize its height.
- [Tab](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-tab/) — `core/tab`: Content for a tab in a tabbed interface.
- [Tab Panel](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-tab-panel/) — `core/tab-panel`: Container for tab panel content in a tabbed interface.
- [Table of Contents](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-table-of-contents/) — `core/table-of-contents`: Summarize your post with a list of headings. Add HTML anchors to Heading blocks to link them here.
- [Tabs](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-tabs/) — `core/tabs`: Display content in a tabbed interface to help users navigate detailed content with ease.
- [Tabs Menu](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-tabs-menu/) — `core/tabs-menu`: Display the tab buttons for a tabbed interface.
- [Tab Menu Item](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-tabs-menu-item/) — `core/tabs-menu-item`: A single tab button in the tabs menu.
- [Text Columns (deprecated)](/block-editor/reference-guides/core-blocks/core-blocks-design/core-block-text-columns/) — `core/text-columns`: This block is deprecated. Please use the Columns block instead.
