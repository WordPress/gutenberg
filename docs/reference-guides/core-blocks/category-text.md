# Text Blocks

- [Code](./code.md) — `core/code`: Display code snippets that respect your spacing and tabs.
- [Details](./details.md) — `core/details`: Hide and show additional content.
- [Footnotes](./footnotes.md) — `core/footnotes`: Display footnotes added to the page.
- [Classic](./freeform.md) — `core/freeform`: Use the classic WordPress editor.
- [Heading](./heading.md) — `core/heading`: Introduce new sections and organize content to help visitors (and search engines) understand the structure of your content.
- [List](./list.md) — `core/list`: An organized collection of items displayed in a specific order.
- [List Item](./list-item.md) — `core/list-item`: An individual item within a list.
- [Math](./math.md) — `core/math`: Display mathematical notation using LaTeX.
- [Unsupported](./missing.md) — `core/missing`: Your site doesn’t include support for this block.
- [Paragraph](./paragraph.md) — `core/paragraph`: Start with the basic building block of all narrative.
- [Preformatted](./preformatted.md) — `core/preformatted`: Add text that respects your spacing and tabs, and also allows styling.
- [Pullquote](./pullquote.md) — `core/pullquote`: Give special visual emphasis to a quote from your text.
- [Quote](./quote.md) — `core/quote`: Give quoted text visual emphasis. "In quoting others, we cite ourselves." — Julio Cortázar
- [Table](./table.md) — `core/table`: Create structured content in rows and columns to display information.
- [Poetry](./verse.md) — `core/verse`: Insert poetry. Use special spacing formats. Or quote song lyrics.
