# Text Blocks

- [Code](../../../packages/block-library/src/code/README.md) — `core/code`: Display code snippets that respect your spacing and tabs.
- [Details](../../../packages/block-library/src/details/README.md) — `core/details`: Hide and show additional content.
- [Footnotes](../../../packages/block-library/src/footnotes/README.md) — `core/footnotes`: Display footnotes added to the page.
- [Classic](../../../packages/block-library/src/freeform/README.md) — `core/freeform`: Use the classic WordPress editor.
- [Heading](../../../packages/block-library/src/heading/README.md) — `core/heading`: Introduce new sections and organize content to help visitors (and search engines) understand the structure of your content.
- [List](../../../packages/block-library/src/list/README.md) — `core/list`: An organized collection of items displayed in a specific order.
- [List Item](../../../packages/block-library/src/list-item/README.md) — `core/list-item`: An individual item within a list.
- [Math](../../../packages/block-library/src/math/README.md) — `core/math`: Display mathematical notation using LaTeX.
- [Unsupported](../../../packages/block-library/src/missing/README.md) — `core/missing`: Your site doesn’t include support for this block.
- [Paragraph](../../../packages/block-library/src/paragraph/README.md) — `core/paragraph`: Start with the basic building block of all narrative.
- [Preformatted](../../../packages/block-library/src/preformatted/README.md) — `core/preformatted`: Add text that respects your spacing and tabs, and also allows styling.
- [Pullquote](../../../packages/block-library/src/pullquote/README.md) — `core/pullquote`: Give special visual emphasis to a quote from your text.
- [Quote](../../../packages/block-library/src/quote/README.md) — `core/quote`: Give quoted text visual emphasis. "In quoting others, we cite ourselves." — Julio Cortázar
- [Table](../../../packages/block-library/src/table/README.md) — `core/table`: Create structured content in rows and columns to display information.
- [Poetry](../../../packages/block-library/src/verse/README.md) — `core/verse`: Insert poetry. Use special spacing formats. Or quote song lyrics.
