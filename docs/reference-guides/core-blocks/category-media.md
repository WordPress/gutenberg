# Media Blocks

- [Audio](/block-editor/reference-guides/core-blocks/core-blocks-media/core-block-audio/) — `core/audio`: Embed a simple audio player.
- [Cover](/block-editor/reference-guides/core-blocks/core-blocks-media/core-block-cover/) — `core/cover`: Add an image or video with a text overlay.
- [File](/block-editor/reference-guides/core-blocks/core-blocks-media/core-block-file/) — `core/file`: Add a link to a downloadable file.
- [Gallery](/block-editor/reference-guides/core-blocks/core-blocks-media/core-block-gallery/) — `core/gallery`: Display multiple images in a rich gallery.
- [Icon](/block-editor/reference-guides/core-blocks/core-blocks-media/core-block-icon/) — `core/icon`: Insert an SVG icon.
- [Image](/block-editor/reference-guides/core-blocks/core-blocks-media/core-block-image/) — `core/image`: Insert an image to make a visual statement.
- [Media & Text](/block-editor/reference-guides/core-blocks/core-blocks-media/core-block-media-text/) — `core/media-text`: Set media and words side-by-side for a richer layout.
- [Playlist](/block-editor/reference-guides/core-blocks/core-blocks-media/core-block-playlist/) — `core/playlist`: Embed a simple playlist.
- [Playlist track](/block-editor/reference-guides/core-blocks/core-blocks-media/core-block-playlist-track/) — `core/playlist-track`: Playlist track.
- [Video](/block-editor/reference-guides/core-blocks/core-blocks-media/core-block-video/) — `core/video`: Embed a video from your media library or upload a new one.
