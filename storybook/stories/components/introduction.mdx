# Components

WordPress components currently live in two npm packages while the component library moves incrementally toward a cohesive design system. Both packages remain in use because `@wordpress/ui` doesn't provide an equivalent for every component in `@wordpress/components`.

When choosing a component, start with [`@wordpress/ui`](?path=/docs/design-system-components-introduction--docs). If it doesn't include a suitable recommended component, check [`@wordpress/components`](?path=/docs/components-introduction--docs).

Recommendations are made component by component, not for an entire package. Each component page displays a status icon and, where needed, notes that explain the recommendation:

- ✅ **Recommended**: Preferred for new work.
- ⚠️ **Use with caution**: Review the notes before using it.
- 🚫 **Not recommended**: Choose the recommended alternative.
- ❓ **Unaudited**: The component hasn't been reviewed yet.
