## Setup

<InstallGrid>

<Tool label="Claude Code" logo={ claudeCodeLogo }>

```bash
claude mcp add wordpress-design-system -- npx -y --ignore-scripts --min-release-age=2 @wordpress/design-system-mcp@latest
```

1. Open a terminal and run the command above. See the [Claude Code MCP documentation](https://code.claude.com/docs/en/mcp) for more options.
2. Start Claude Code and run `/mcp` to confirm `wordpress-design-system` is connected.

</Tool>

<Tool label="OpenAI Codex" logo={ openaiLogo }>

```bash
codex mcp add wordpress-design-system -- npx -y --ignore-scripts --min-release-age=2 @wordpress/design-system-mcp@latest
```

1. Install the [Codex CLI](https://developers.openai.com/codex/cli) if you have not already.
2. Open a terminal and run the command above.
3. Start Codex and run `/mcp` to confirm `wordpress-design-system` is connected.

</Tool>

<Tool label="Cursor" logo={ cursorLogo }>

In `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "wordpress-design-system": {
      "command": "npx",
      "args": [
        "-y",
        "--ignore-scripts",
        "--min-release-age=2",
        "@wordpress/design-system-mcp@latest"
      ]
    }
  }
}
```

<InstallButton href={ CURSOR_URL } image="https://cursor.com/deeplink/mcp-install-dark.svg">Add to Cursor</InstallButton>

1. Click “Add to Cursor”, or add the configuration above to your Cursor [MCP settings](https://cursor.com/docs/mcp).
2. Open Cursor Settings, go to MCP, and confirm `wordpress-design-system` is enabled.

</Tool>

<InstallButton href={ VSCODE_URL }>Install in VS Code</InstallButton>

1. Click “Install in VS Code”, or add the configuration above to your [`mcp.json` file](https://code.visualstudio.com/docs/agent-customization/mcp-servers#_configure-the-mcpjson-file).
2. Start the server from the MCP view, or from the `MCP: List Servers` command.

</Tool>

<Tool label="JetBrains" logo={ jetbrainsLogo }>

```json
{
  "mcpServers": {
    "wordpress-design-system": {
      "command": "npx",
      "args": [
        "-y",
        "--ignore-scripts",
        "--min-release-age=2",
        "@wordpress/design-system-mcp@latest"
      ]
    }
  }
}
```

1. In PhpStorm, WebStorm, or another JetBrains IDE, open Settings, Tools, AI Assistant, [Model Context Protocol (MCP)](https://www.jetbrains.com/help/ai-assistant/configure-an-mcp-server.html), and click Add.
2. Paste the configuration above into the JSON configuration field, then click OK and Apply.
3. Check that `wordpress-design-system` shows as connected in the Status column.

</Tool>
