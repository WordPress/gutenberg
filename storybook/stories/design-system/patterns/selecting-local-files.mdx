# Selecting local files

Use a labeled file input when choosing files is part of a form. A button or menu item can also open the native picker. Keep the file input mounted until the user finishes choosing a file.

## In a form

Use `InputControl` with `type="file"`. Read the selected files from `event.currentTarget.files` in the `onChange` handler. Use `accept` to suggest file types and `multiple` to allow more than one file. If you provide your own label, you can use the [Input file example](?path=/story/design-system-components-form-primitives-input--file-input).

<Canvas of={ InputControlStories.FileInput } />

## From a button

When the visible control should be a button, use `Button` to open a hidden `Input type="file"`. Call the input's `click()` method in the button's `onClick` handler. Read the file in the input's `onChange` handler to display its name beside the button.

## From a menu item

Keep the hidden `Input` outside `Menu.Popup` and open it from the `Menu.Item` click handler. The popup closes when the item is activated. The input stays mounted to receive the selected file.
