# Selecting local files

Use `FormFileUpload` from `@wordpress/components` to open the native file picker. It provides a button and a hidden file input, and handles browser-specific picker hints such as `accept="audio/*"`.

## From a button

Read the selected `File` from `event.currentTarget.files`. Keep the result visible beside the button. Once you have the file, clear the input so choosing the same file again triggers another change. Leave the previous result in place when the picker closes without a selection. If a form submits the native file input, keep its value until the form is submitted.

## From a menu item

Wrap the whole menu in `FormFileUpload`. Its `render` prop supplies `openFileDialog` to the menu item. The item closes the popup when activated. Both the input and the selection feedback stay mounted.

## From a drop area

Pair `DropZone` with a button so people can choose a file with a keyboard or a single click. Position the drop area’s container so the overlay covers that area. Send picked and dropped files through the same handler. Here the picker suggests PNG files, and the handler checks the number of files and their filename extension. Show the error beside the control and keep the last accepted file visible.
