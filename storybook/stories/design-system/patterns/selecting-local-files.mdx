# Selecting local files

Use a labeled file input when choosing files is part of a form. When the action lives in a menu, keep the file input mounted after the popup closes so it can receive the selection.

## In a form

Use `InputControl` with `type="file"`. Read the selected files from `event.currentTarget.files` in the `onChange` handler. Use `accept` to suggest file types and `multiple` to allow more than one file. If you provide your own label, you can use the [Input file example](?path=/story/design-system-components-form-primitives-input--file-input).

## From a menu item

Render the menu through the `render` prop of `FormFileUpload` and pass `openFileDialog` to the item's `onClick`. Putting `FormFileUpload` inside `Menu.Popup` would remove its hidden input when the menu closes, before the user finishes choosing a file.
