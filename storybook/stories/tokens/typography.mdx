# Typography tokens

`@wordpress/theme` publishes typography tokens as CSS custom properties. See the generated [Design Tokens Reference](https://github.com/WordPress/gutenberg/blob/trunk/packages/theme/docs/tokens.md) for the canonical token list and guidance on choosing tokens.

See the [`@wordpress/theme` package README](https://github.com/WordPress/gutenberg/blob/trunk/packages/theme/README.md) for setup and usage instructions.
