# Pattern-First Editing/Content Only Editing Usability Testing Plan

## What do we hope to answer?

Is the editing experience easier with Simplified site editing and contentOnly: make patterns contentOnly by default upon insertion?

## How will we know if we’ve answered it?

-   People can perform all basic operations within contentOnly mode
    -   What is “basic”? This depends on the person, but let’s define it as 80% of their desires.
-   People report a preference for the simplified editing mode
-   People can easily exit contentOnly to make design edits as needed
